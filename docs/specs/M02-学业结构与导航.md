# M02 学业结构与导航（Program / Term / Course）

> 依赖：M00、M01、M11（偏好：当前 Program、默认值）。被依赖：几乎所有业务模块。
> 本模块解决旧版"实体层级混乱"的问题，是新版最核心的重设计之一。

## 1. 目标与功能对齐
旧版功能：Program 列表与切换、Program 概览（KPI、按学期的 GPA/学分图表、Focus Board 置顶学期/课程卡片、学期列表、全部课程表格及 GPA 筛选）、Program 设置、学期 CRUD、学期创建向导（草稿可恢复）、课程 CRUD、"未分配学期的课程"（年课 workaround）、学科代码颜色（新学科自动分配不冲突颜色、已有学科颜色稳定）、课程别名与分类、学期中按快捷键 `Cmd/Ctrl + ↑↓` 切换同学期课程并保持当前页面、首次使用引导。

新版设计：
- 层级只有一条路径：**User → Program → Term / Course**，Course 通过关联表覆盖 1..n 个 Term。去掉"Workspace"、"未分配课程"、学期草稿状态。
- 一个账户可以有多个 Program（硕士、双学位），注册后自动引导创建第一个；只有一个 Program 时界面不显示 Program 切换器。
- 本模块同时负责**作用域导航外壳**（侧边栏、作用域页头、页面切换），因为层级导航本身就是学业结构的 UX。

## 2. 领域模型
```
academics_programs
  id, user_id, name, institution?, timezone (IANA, 默认浏览器时区),
  default_course_credits (float, 默认 0.5), credit_requirement? (float),
  subject_colors JSON {"APS": {"palette": 3} | {"hex": "#2563eb"}},
  sort_order, created_at, updated_at

academics_terms
  id, user_id, program_id, name, start_date, end_date,
  breaks JSON [{id, name, start_date, end_date}],     # 阅读周、假期
  count_break_weeks (bool, 默认 false),                 # 周次是否把假期周算进去
  created_at, updated_at
  CHECK start_date <= end_date；breaks 必须落在学期范围内且互不重叠（service 校验）

academics_courses
  id, user_id, program_id,
  code (如 "APS105H1"，可空), title, alias? (短名),
  subject_code (默认从 code 解析，可手改，如 "APS"),
  color? JSON {"palette": n} | {"hex": "..."}  # 为空则用学科颜色
  credits (float), include_in_gpa (bool, 默认 true),
  instructors JSON [{name, email?, role?}], description?, website_url?,
  sort_order (显示顺序，之后按 code、title), created_at, updated_at

academics_course_terms
  course_id, term_id, user_id, PRIMARY KEY (course_id, term_id)
  # 年课关联 2 个（或更多）连续学期；半年课关联 1 个
```
规则：
- 一门课至少关联一个 Term，且所有 Term 属于同一 Program。关联多个时必须是该 Program 中按 `start_date` 排序**相邻**的学期（不能跳学期）。
- `course.end_term` = 关联学期中最晚的那个；成绩计入规则由 M03 使用该字段。
- 课程在每个关联学期中都会显示，并带"年课"标记（显示 `秋季–冬季` 这样的跨度）。
- 学科代码解析：取 code 开头的连续字母并大写（`"aps105h1"` → `"APS"`；无字母时为空）。
- **学科颜色分配**：新出现的 subject_code 自动分配调色板中当前 Program 使用次数最少的颜色（相同时取序号最小），写入 `subject_colors`；已有学科颜色不随课程增删变化。用户可在 Program 设置中修改任一学科的颜色。
- 课程颜色优先级：`course.color` > `program.subject_colors[subject_code]` > 按 subject_code 哈希的调色板色。前端统一使用 `courseColor(course, program)`。

## 3. 业务规则
- **删除 Program**：级联删除其所有 Term、Course 及各模块数据（通过事件 `academics.program.deleting` 让各模块在同一事务内清理）；若删除的是当前 Program，切换到剩余的第一个；删除最后一个 Program 后进入 onboarding。
- **删除 Term**：只属于该 Term 的课程一并删除；跨学期课程只解除与该 Term 的关联。确认对话框显示"将删除 N 门课程，M 门年课会保留"。
- **修改 Term 日期**：若导致某门年课的关联学期不再相邻（例如插入了新学期），返回 `academics.course_terms_not_adjacent`，列出受影响课程，前端引导用户调整。
- **创建 Term 时的年课延续**：若新学期紧接在某个学期之后，而该学期有"标记为年课但只关联了一个学期"的课程（见下），向导提示是否把它们延续到新学期。
- 课程可以设置"预计跨学期数"`planned_terms`：创建年课时如果后续学期还不存在，课程先只关联当前学期并记录 `planned_terms=2`，后续学期创建时自动提示延续。字段：`academics_courses.planned_terms (int, 默认 1)`。
- 学期排序按 `start_date`；当前学期 = 今天落在范围内的学期，若没有则取下一个即将开始的，再没有则取最近结束的。
- 周次计算：第 1 周 = `start_date` 所在的周（周起始日取用户偏好，默认周一）；`count_break_weeks=false` 时假期周不计入编号，假期周显示为假期名称。函数 `term_week_of(term, date) -> int | Break | None` 放在本模块 service，前后端共用后端结果（前端通过 `academics.term.get_weeks` 获取每周的编号映射）。

## 5. 前端
### 5.1 导航外壳（AppShell）
- **左侧边栏**（可折叠为图标栏，状态存 UI 偏好）。用户 99% 的时间在当前学期里工作，所以侧边栏就是"当前学期的工作区"（2026-10-31 改版，方案甲）：
  1. 顶部：Program 切换器（始终是下拉：列出 Program，选中即进入其起始页；含"新建 Program"，只有一个 Program 时也在这里）。
  2. 无标题组：搜索/命令面板入口（M10）与 Sem（M12）。Sem 行右侧的 chevron 折叠/展开最近对话（UI 偏好 `academics.sidebar_recent_chats`，默认收起），**不随页面切换自动展开或收起**，侧边栏不会因为打开某个页面而变形；侧面板按钮在 chevron 左边、悬停时出现。
  3. **工作区组**（`shell/SidebarWork.tsx`）：组标题是"侧边栏所示学期"的名字（当前学期后面带"· 第 N 周"），点开是学期列表（新的在上，当前学期标"当前"），选一个学期即打开它的同一页面（不在学期页时打开其概览）。其下是 Program 级 Page 与该学期的学期级 Page 合成的一组入口（`shell/sidebar-pages.ts` 的 `useSidebarPages`）：默认顺序今天、概览、日历、待办、成绩、文件（按 `PageContribution.order` 排：今天 -10、概览 0、日历 10、待办 20、成绩 20、文件 30；两级都有的 Page（待办）用 Program 级的，它覆盖所有学期）。顺序与隐藏存在 Program 的 M10 nav 里（"⋯"→"管理页面"，命令面板同样可开）；以前在学期标签里隐藏的页面仍隐藏；旧版 Program nav（只列 Program 级 Page，其中的 `overview` 指原 Program 看板）只用来排 Program 级 Page 之间的先后，学期级 Page 留在默认位置。概览不能隐藏。命令面板的“导航”组也列出这组入口（M02 贡献的 `navigationSources`，学期级的副标题是学期名），与作用域自己的页面按目标地址去重。没有学期时组标题是"页面"，入口末尾是"新建学期"。
  4. **"侧边栏所示学期"**（`viewing-term.ts`）：打开某学期的页面或课程页后，该学期（课程页取面包屑所示的学期：有 `fromTerm` 且课程在其中就用它，否则课程的当前学期，再否则最后一个学期）成为侧边栏所示学期并记住（UI 偏好 `academics.viewing_term.<programId>`，null 为当前学期），在其它页面上也保持，直到用户点组标题右侧的"回到当前学期"按钮（在学期页上打开当前学期的同一页面，在课程页上打开当前学期的概览，由新页面自己清掉记忆）。当前学期默认按日期（`useCurrentTerm`，`modules/academics/current-term.ts`：服务端的 `is_current`，没有则下一个即将开始的，再没有则最近结束的），用户可手动指定（UI 偏好 `academics.current_term.<programId>`，null 为按日期），只影响侧边栏和"学期与课程"页的默认选中，今天页与周数仍按真实日期；指定的学期被删除后自动按日期。
  5. **"课程"组**：侧边栏所示学期的课程（彩色圆点 + alias 或 code），折叠成图标栏时隐藏。
  6. **"已置顶"组**（`shell/SidebarPins.tsx`，没有可显示的置顶就不出现）：置顶的学期（可展开看课程）和课程（平铺）混排，按用户顺序；可拖动排序（dnd-kit，纯指针拖动），"⋯"菜单提供上移/下移（键盘可用）、取消置顶，学期另有删除。置顶在学期、课程页头的图钉。侧边栏正在显示的学期已在上方，它的置顶项在此期间不显示；置顶的课程照常显示。
  7. 底部：**学业概况**（Program 的卡片看板，Page id `summary`，地址 `/p/<id>/summary`）与"学期与课程"。
  8. 页脚"系统"组：后台任务状态条（M10，同样是 `SidebarMenu`，折叠时只剩图标）、设置；其下是账户菜单（含退出登录，经 `SignOutDialog` 确认）。
  - **去重规则**：同一个入口不同时出现在侧边栏和页面标签里。Program 与学期的页面只在侧边栏、没有标签栏，课程页保持自己的标签栏；设置只在作用域页头（齿轮），置顶的图钉在学期与课程页头（含义是"置顶到侧边栏"）；"新建 Program"只在 Program 切换器。模块不再往侧边栏里塞子导航（原 `PageContribution.sidebarNav` 已删除，待办的列表回到页面里，见 M05）。
- **起始页**：`/p/<id>`（`/` 与安装的应用都到这里）按账户偏好 `start_page`（M11）跳转：`last`（上次离开的页面，只在选了它时由 `AppShell` 记到 UI 偏好 `academics.last_page.<programId>`，只记侧边栏能打开的页面：Program 级 Page、Sem、学期与课程、学期页与课程页，不记向导、导入、对话与设置；跳转前重新确认学期或课程还在，不在就去今天）、`today`（默认）、`overview`/`calendar`/`grades`/`files`（侧边栏所示学期的该页面，没有学期时今天）、`tasks`、`assistant`、`summary`。解析在 `start-page.ts`。手机上由 M17 外壳在它有的页面（今天、待办、Sem）里选，没有就打开第一个标签。
- **页头**：所有右侧页面共用 `app/host/PageHeader`（标题 `h1` + 一行副标题 + 右侧图标按钮 + 可选标签栏），高度固定，副标题行始终保留。作用域页头 `ScopeHeader` 在其上：Program 与学期页面的标题是 Page 的标题，学期页的副标题是"学期名 · 起止日期 · 第 N 周"，Program 页的副标题由 `PageContribution.headerSubtitle` 提供（缺省为学期/课程数）；课程页的标题是课程名（旁边的下拉切换同学期的课程），面包屑只显示上级（学期与课程 / 学期，不含 Program），下面是课程的 Page 标签栏（由所有模块的 `PageContribution` 生成，顺序与隐藏由 M10 管理）。右侧按钮顺序为编辑布局、置顶、设置，纯图标按钮一律用 shadcn `Tooltip`。
- 课程页快捷键 `Cmd/Ctrl + ↑/↓` 切换同学期上一门/下一门课程，**保持当前 Page**（目标课程没有该 Page 时回到概览）；按住时节流 150ms；目标课程数据预取。快捷键提示在面包屑下拉中以 `kbd` 显示。
- 窄屏（<768px）：不显示侧边栏，换成 M17 的手机外壳（底部标签栏：今天、待办、更多）；没有手机版的 Page 显示"请在电脑上打开"。

### 5.2 Program 概览（`/p/$programId`）
- 页头：Program 名称、学校、学期数与课程数。
- **卡片网格**（program 作用域的 Card，可编辑布局，见 M10）。本模块提供：
  - `academics.terms`：学期时间轴列表（名称、日期、课程数、当前学期高亮、"新建学期"按钮）。
  - M03 会贡献 GPA/学分 KPI 与按学期图表卡片。
- 默认布局：KPI（M03）→ 图表（M03）；`academics.terms` 仍可手动添加。置顶数据（UI 偏好 `academics.pinned.<programId>`）现在属于侧边栏（§5.1），原 `academics.pinned` 卡片已删除，已存看板里的旧卡片会被忽略。

### 5.3 学期与课程（`/p/$programId/academics`）
- 一个页面两个子模块（shadcn `Tabs`，状态在 URL：`?tab=terms|courses`、`?term=<id>`）；页头用 `PageHeader`（标题"学期与课程"，副标题"N 个学期 · M 门课程"，右侧 `[添加课程] [新建学期]`）。旧路径 `/p/$programId/courses` 重定向到 `?tab=courses`。
- **学期**（默认）：左右两栏。左栏是学期列表（新的在上；名称、起止日期、课程数、"本学期"标记、已置顶图钉；悬停出现"设为当前学期""置顶到侧边栏"）；右栏是选中学期（默认当前学期，其次最新学期）的标题与操作（打开学期页、设为当前学期 / 恢复自动、置顶、删除学期）和**该学期的课程表**。<1024px 时左栏变成顶部下拉。没有学期时显示页面级空状态。
- **课程**：全部课程表，与"学期"子模块共用 `?term=`（这里它是学期筛选）。
- 课程表（`components/CoursesTable.tsx`，TanStack Table）：列 = 颜色点、code、title、学科、学分、学期（年课显示跨度；学期子模块里隐藏）、计入 GPA、置顶按钮；扩展点 **`academics.courseColumns`**：`{ id, header, cell(course), sortValue?(course), filter? }`，M03 贡献"成绩"、"GPA"列及筛选器（GPA=满分、≥满分的 87.5%、≥满分的 75%）。支持按学期、学科筛选，按任意列排序，搜索框模糊匹配；行点击进入课程页；多选后批量删除/修改学分/计入 GPA。
- **筛选**：工具栏 = 搜索框 + 每个类别一个下拉（学期、学科，以及每个贡献了 `filter` 的扩展列各一个，下拉标签取列名，选项为"全部 {列名}" + 该列的筛选项，同一列一次只选一项；不可用的选项不显示，全部不可用时不显示该下拉）。常用筛选都直接放在外面；以后类别多了再加"高级筛选"下拉。
- **勾选不改变高度**：搜索框固定在左侧，选中行时不变；右侧的筛选下拉组在原位换成批量操作组（`role="toolbar"`）：「已选 N 门 · 修改学分 · 计入 GPA ▾ · 删除 · ✕」。两组叠在同一个 grid 单元格里（`col-start-1 row-start-1`，隐藏的一组 `invisible` + `inert`），行高与表格位置不变；删除为 destructive 并经 `ConfirmDialog` 确认；`Esc` 或 ✕ 清除选择，筛选组随即回来。选中的行用 `data-state="selected"` 高亮。
- **列放不下时**：圆角框只裁切（`overflow-hidden`），表格在 `Table` 自带的容器里横向滚动；置顶列 `sticky right-0`，背景不透明（与表头、悬停行、选中行一致，选中优先于悬停），左侧一条 1px 阴影作分隔，不改变列宽。
- "当前学期"：默认按日期（`is_current`），用户可以手动指定（`useCurrentTerm`，UI 偏好 `academics.current_term.<programId>`），只影响侧边栏与本页默认选中；今天页、周次仍按真实日期。置顶沿用 `usePins`（`academics.pinned.<programId>`），位置是侧边栏。

### 5.4 学期页（`/p/$programId/t/$termId/$page`）
- 默认 Page `overview`（本模块提供）：卡片网格（term 作用域 Card）。本模块贡献 `academics.termCourses` 卡片：本学期课程列表（颜色、code、title、学分；扩展点 `academics.courseColumns` 中标记 `showInTermCard` 的列也会显示，例如成绩），点击进入课程；"添加课程"按钮。
- **添加课程**（学期与课程页的页头、学期子模块的表格末行与空状态、`academics.termCourses` 卡片、学期页命令面板）一律是同一个菜单 `AddCoursesMenu`：「手动填写」（打开对话框，复用向导第二步的课程行表格 `CourseRowsEditor`，`course.create_many`）、「从上学期延续」（列出待延续的年课，点一门即 `course.set_terms` 加上本学期）、「从已有资料添加」（与向导同一个扩展点 `academics.termWizardImportSources`，审核后直接建课，再调来源的 `onCoursesCreated`）。命令面板另有「新建学期」。
- 学期设置（M11 term 级设置分区，本模块提供"基本信息"分区）：名称、日期、假期（增删改）、周次是否计假期、删除学期。

### 5.5 课程页（`/p/$programId/c/$courseId/$page`）
- URL 不含学期（年课属于多个学期）；面包屑中的学期段显示"从哪个学期进入"（router search param `fromTerm`，缺省为课程当前学期）。
- 默认 Page `overview`：卡片网格（course 作用域 Card）。本模块贡献 `academics.courseInfo` 卡片：code、title、讲师、学分、学期跨度、网站链接、描述。
- 课程设置（course 级设置分区，本模块提供"基本信息"）：所有字段、颜色选择器（调色板 12 色 + 自定义 hex + "使用学科颜色"）、学期关联（"年课"开关 + 学期多选，校验相邻）、删除课程。

### 5.6 创建学期向导（`/p/$programId/terms/new`）
- 两步：**学期信息** → **课程**，第 2 步底部直接"创建学期"（单次 `academics.term.create`），旁边一行摘要（名称 · N 门新课程 · M 门延续）；表单提交就是确认，不设单独的确认步骤。
  - 学期信息：日期是一个范围选择器（`components/DateRangeField.tsx`，照 shadcn date-picker-range：outline 按钮 + 浮层里两个月的 `Calendar mode="range"`，展开收起布局不变；按钮右侧显示周数，假期在日历里划掉）与名称并排；名称在选好日期后自动建议（如 "Fall 2026"/"2026 秋季"），之前占位写"选好日期后自动建议"。假期是 `SettingsTable`（`components/BreaksTable.tsx`，列"名称 | 日期 | 删除"，日期也是范围选择器，限制在学期内），学期设置里复用同一张表。"假期周也计入周次"是设置样式的 `SettingRow` + `Switch`。第 1 步左下是"取消"（onboarding 里不显示）。
  - 课程：TanStack 表格逐行添加 code/title/学分（留空用 Program 默认学分，占位写"默认 X"）；右上"从已有资料添加"列出扩展点 **`academics.termWizardImportSources`** 的来源（M08 贡献文件识别，M09 贡献"从 LMS 导入"），导入行在名称右侧显示来源图标；没有课程时显示 `Empty`（"添加课程" + 同一个导入菜单）。待延续的年课作为只读行排在最前，带"从上学期延续"标记，删除即不延续（行变灰划线，可恢复）。
- 所有 `Calendar` 都传 `lib/calendar.ts` 的 `calendarLocale()`（react-day-picker 的 locale + 设置里的每周起始日）。
- 向导状态保存在 `sessionStorage`（按 programId），刷新可恢复；离开时如有未提交内容，确认"保留草稿/丢弃"。
- 扩展点类型：`TermWizardImportSource { id, title, icon, description, launch(ctx): Promise<CourseDraft[]> }`，`CourseDraft { code?, title, credits?, instructors?, description?, source?: {kind, ref} , extras?: Record<string, unknown> }`。`extras` 由来源模块定义（例如 ICS 导入带上课时间），学期创建成功后，向导对每个带 extras 的草稿调用来源模块的 `onCoursesCreated(mapping)` 回调完成后续写入（例如 M04 写入课表）。

### 5.7 Onboarding（`/onboarding`）
首次登录且没有 Program 时进入：
1. 欢迎 + 选择界面语言（写入 M11 偏好）。
2. 创建 Program：名称、学校、时区（自动检测）、默认课程学分；扩展点 **`academics.programSetupFields`**（M03 贡献"GPA 换算预设"选择）。
3. 创建第一个学期：嵌入学期向导；第 1 步左下角"稍后添加"可跳过（还没开学的新生），Program 先不带学期。
4. 可选：配置 AI（M06 贡献的步骤，扩展点 `academics.onboardingSteps`），可跳过。
5. 完成后进入学期页（跳过了学期则进入"今天"页，完成页文案提示之后在"学期与课程"里添加），并启动 5 步界面导览（driver.js 风格的高亮提示：侧边栏、学期切换、卡片编辑、命令面板、AI 助手），可跳过；完成状态存 UI 偏好 `onboarding.tour_done`。

## 对接 M11 的实现约定（M11 落地时补充）
- 在模块 `register` 里调用 `semestra.modules.settings.set_scope_resolver(resolver)`：`resolver(ctx, scope_type, scope_id)` 返回 `ScopeChain(program_id, term_id, course_id)`，作用域不存在或不属于当前用户时抛 `common.not_found`。课程的 `term_id` 取包含今天的学期（年课程）或其唯一学期，没有则 `None`。注册之前 M11 对所有非账户作用域一律拒绝。
- M11 订阅的是提交后的 `academics.{program,term,course}.deleted`（payload 必须带 `program_id` / `term_id` / `course_id`，事件带 `user_id`）。删除 Program 或学期时，被级联删除的学期与课程也要各发一次 `deleted`，设置才会被清理。
- 作用域设置页直接渲染 `SettingsPage`（`@/app/settings`），传入 `level`、`scope`、`groupId`、`title`、`hrefFor`、`fallbackHref`；路由形状由 M02 决定。
- `week_start` 偏好为 0 时一周起始日跟随语言（中文周一，英文周日），不是固定周一；用 `lib/format.ts` 的 `firstDayOfWeek()` 取值。


## 实现说明（M02 落地时补充）
以下是实现时做出的取舍与对上文的细化，以代码为准。

**后端**
- `*.deleting` 用 M00 §3.8 新增的事务内事件（`events.publish_in_transaction` / `@events.subscribe(..., in_transaction=True)`）派发；提交后另发 `*.deleted`。删除 Program 时依次为每门课程、每个学期、最后为 Program 各发一次 `deleting` 与 `deleted`；删除学期时，只属于它的课程各发一次 `course.deleting/deleted`，保留的年课发 `course.terms_changed`。所有 `deleted` 的 payload 都带 `program_id`（学期带 `term_id`，课程带 `course_id`），满足 M11 的清理约定。
- `academics.program.create` 的输入多一个 `setup: dict`，onboarding 中 `academics.programSetupFields` 收集的值原样放进 `academics.program.created` 事件的 `setup` 字段（M03 从这里读 GPA 换算预设）。
- 字段选择（`fields`）由注册表统一处理，只作用于 agent/MCP 调用；HTTP 始终返回完整模型（见 M00 §3.6）。
- `academics.course.list` 的 `cursor` 是偏移量字符串，`limit` 默认 200、最大 500；Program 与学期列表数量很小，不分页。
- 假期周判定：一周中落在学期内的天数里，超过一半是假期才算假期周（单日节假日不会让整周失去编号）。周起始日按 M11 约定：偏好为 0 时跟随语言（中文周一，英文周日）。
- 学期修改日期后若年课的学期不再相邻，直接拒绝（`academics.course_terms_not_adjacent`，params 带 `course_ids`），不做自动调整。
- 学期内课程不单独排序（原 `academics.course.reorder` 与表 `academics_term_course_order` 已删除，迁移 0020）：侧边栏、课程切换、学期页都按 `sort_order`、code、title 的默认顺序列出。旧备份里的 `term_course_order` 导入时忽略。
- 学科代码一律大写保存；修改课程代码时，如果学科原本是从旧代码解析出来的，学科跟随新代码更新，手改过的学科保持不变。
- 课程返回 `resolved_color`（`subject-N` 或 `#rrggbb`，按 §2 的优先级在后端算好）、`term_ids`（按时间排序）与 `end_term_id`；前端 `courseColor(course)` 只把它映射成 CSS 颜色，不再需要传 Program。
- 时区校验用 `zoneinfo`，并加了 `tzdata` Python 依赖，保证没有系统时区库的环境（如精简镜像、Windows）也能用。

**前端**
- 路由：`/` 跳到上次打开的 Program（M11 `active_program_id`），没有则第一个，一个都没有进 `/onboarding`；`/p/$programId` 是带侧边栏的布局，它自己的地址跳到起始页（§5.1），`$page`、`t/$termId[/$page]`、`c/$courseId[/$page]`（`?fromTerm=`）以及各自的 `settings/$group`，另有 `/p/$programId/academics`（学期与课程；旧 `/courses` 重定向到它）与 `/p/$programId/terms/new`（向导）。
- 扩展点类型定义在 `modules/academics/types.ts`：`academics.courseColumns`、`academics.termWizardImportSources`（含 `onCoursesCreated`）、`academics.programSetupFields`、`academics.onboardingSteps`、`academics.courseInfoFills`（M08 加：课程设置基本信息上方的「从 syllabus 识别」，`onApplied` 后表单重新挂载）。`CourseDraft.plannedTerms`（M08 加）≥ 2 时向导里的这一行默认是全年课程。
- 侧边栏的置顶学期展开状态、折叠状态、置顶、当前学期、侧边栏所示学期、Sem 最近对话的折叠、全部课程表的排序都存 UI 偏好（`academics.sidebar_expanded.<programId>`、`layout.sidebar_collapsed`、`academics.pinned.<programId>`、`academics.current_term.<programId>`、`academics.viewing_term.<programId>`、`academics.sidebar_recent_chats`、`academics.courses_sort`）。已置顶项的菜单有上移/下移/取消置顶，学期另有删除；设置与置顶在学期与课程页头的齿轮、图钉按钮。侧边栏的组件在 `shell/AppSidebar.tsx`（顶部、Sem、页脚）、`shell/SidebarWork.tsx`（学期切换、工作区入口、课程、底部链接）与 `shell/SidebarPins.tsx`（已置顶）。
- Program 级 Page 按 `useScopePages` 的顺序出现在"页面"组（概览的链接是 `/p/$programId`）；"学期与课程"链接目前指向 `allCoursesPath`（全部课程页），新页面落地时在 `paths.ts` 改指过去；命令面板与 AI 助手入口等 M10、M12 落地时再加，界面导览会自动跳过页面上还不存在的目标。
- 窄屏下只有带 `mobile` 的 Program Page（今天、待办）可用，其它页面显示"请在电脑上打开"（M17）。
- 向导草稿存 `sessionStorage` 的 `semestra.termWizard.<programId>`；离开时（路由跳转）询问"保留草稿 / 丢弃 / 留在此页"。onboarding 进度存 `semestra.onboarding`，切换语言重挂载应用后从原步骤继续；完成时把 `onboarding.tour_done` 设为 `false` 触发导览，看完或跳过后设为 `true`。
