# M05 待办（Tasks）

> 依赖：M00、M02、M04（日历源、"今天"扩展点）、M11。可选联动：M03（考核生成任务）。被依赖：M08/M09（导入为任务）、M12。
> 核心模块（`kind: 'core'`）。替代旧版 `builtin-event-core` 中的 Todo。

## 1. 目标与功能对齐
旧版功能（保留）：
- 学期级待办，类 Apple 提醒事项：分组（section）、任务（标题、备注、截止日期与时间、优先级 LOW/MEDIUM/HIGH/URGENT、完成状态、关联课程）。
- 分组内行内快速创建；行内编辑标题与课程标签；分组显示/隐藏与排序偏好持久化。
- 已完成汇总，一键清除已完成；破坏性操作二次确认。
- 课程页显示该课程的待办（与学期待办是同一份数据的过滤视图）。
- Program 级待办默认设置。
- 待办出现在日历中。

新版变化：
- 任务属于 **Program**，可选关联学期与课程（关联课程时学期自动取课程在任务截止日所在的学期，否则取当前学期）。这样年课的任务不会被困在某一个学期里。
- 智能列表：今天、计划中（有截止日期）、全部、已完成、按课程。
- 可选：考核自动生成任务（每个考核对应一个任务，截止日期随考核同步，完成任务不影响成绩）。

## 2. 领域模型
```
tasks_lists
  id, user_id, program_id, term_id? (空 = Program 级列表，所有学期可见),
  name, color?, icon?, position, created_at, updated_at
  UNIQUE(program_id, term_id, name)

tasks_items
  id, user_id, program_id, term_id?, course_id? (ON DELETE SET NULL), list_id? (ON DELETE SET NULL),
  title, notes (markdown, 默认 ""), due_date?, due_time? (Program 时区本地时间),
  priority ('none'|'low'|'medium'|'high'|'urgent'), flagged (bool),
  completed_at? (UTC), position (列表内手动排序，浮点/分数索引),
  source_kind? ('assessment'|'lms'|'syllabus'|'agent'|'manual'), source_ref?,
  UNIQUE(user_id, source_kind, source_ref) WHERE source_kind IN ('assessment','lms')
  created_at, updated_at

```
Program 级默认不建表，走 M11 设置命名空间 `tasks`（Program 级）：`auto_tasks_from_assessments`（默认 false）、`default_priority`（默认 none）、`show_completed_in_lists`（默认 false）。没有"默认列表"：未指定列表的任务归入"未归类"。

## 3. 业务规则
- 创建任务时：给了 `course_id` 未给 `term_id` → 取课程关联学期中包含截止日期的那个，没有截止日期则取包含今天的，否则取课程最早的学期。
- `list_id` 为空的任务显示在"未归类"（每个 Program 的虚拟列表，API 视图名仍是 `inbox`）。
- 完成：设置 `completed_at`；取消完成：清空。"清除已完成"删除指定范围（列表/学期/全部）内已完成任务，返回数量。
- 自动任务（`auto_tasks_from_assessments=true`）：订阅 `grading.assessment.created|updated|deleted`：创建/更新对应任务（标题 `"<课程 code> · <考核标题>"`，截止取考核 due，priority=medium，source_kind=assessment）；考核删除时删除未完成的对应任务、保留已完成的；考核录入分数后自动标记任务完成。开关从关闭到打开时，为该 Program 所有未出分且有截止日期的考核补建任务。
- 考核生成的任务跟随考核：标题、截止日期与课程不能在待办里改（`tasks.item.update` 改动这些字段返回 409 `tasks.managed_by_assessment`，前端详情面板与行内编辑把它们设为只读并链接到课程成绩册）；完成状态、优先级、标记、列表和备注可以改。Agent/MCP 不能把 `source_kind` 设为 `assessment` 或 `lms`（不传时记为 `agent`）。
- 排序：列表内默认按 `position`；可选按截止日期、优先级、创建时间、标题（偏好）。
- 逾期：未完成且截止时间早于现在（Program 时区）。

| `tasks.item.update` | write | PATCH /tasks/{task_id} | |
| `tasks.item.complete` | write | POST /tasks/{task_id}:complete | 参数 `completed: bool` |
| `tasks.item.move` | write | POST /tasks/{task_id}:move | 换列表/位置 |

| `tasks.item.find` | read | （agent/mcp） | 模糊找任务（"那个 lab 报告"） |

日历源：`tasks.due`（有截止日期的未完成任务，kind=task，已完成任务在 `include_completed=true` 时返回且 status=done）。
"今天"页面（M04 的 `today` Board）通过卡片 `tasks.today` 展示今日与逾期任务（可直接勾选完成）。
事件：`tasks.item.*`、`tasks.list.*`，并发布 `calendar.changed`。
订阅：`academics.course.deleting`（清空 course_id）、`academics.term.deleting`（删除该学期的列表，任务的 term_id 置空并移入未归类）、`academics.program.deleting`、`grading.assessment.*`（自动任务）。
前端失效：`tasks.*` → `tasksItem*`、`tasksList*`、`tasksItemCount*`。

## 5. 前端
### 5.1 学期 Page `tasks`（也可从 Program 级入口进入，显示 Program 全部）
- 左栏：智能列表（今天、计划中、全部、已标记、已完成，带数量）+ 未归类 + 用户列表（学期列表在上，Program 级列表在下）+ "按课程"折叠组（本学期课程，颜色点）。新建列表、拖拽排序。
  （UI/UX 第五轮）页面不再有自己的左栏：Program 待办页的这些入口在应用侧边栏「待办」项下展开（`PageContribution.sidebarNav`，"按课程"默认折叠）；学期待办页和侧边栏收成图标栏时，页面标题变成列表下拉菜单，当前列表旁的 ⋯ 提供重命名、上移/下移、删除。
- 右栏：顶部是快速添加输入框（空列表时也在同一位置，列表从空到有内容不跳动；回车创建、自然语言解析："周五 lab 报告 !!!" → 截止周五、优先级高；解析在前端用 `chrono-node` 中英文规则，解析结果以标签预览在输入框同一行，可撤回），下面是任务列表，列表末尾有一行空心圆圈，点它直接输入新任务（回车添加并留在这一行继续输入，Esc 放弃）。每行：圆形勾选框、标题（单击标题或备注即把这一行就地展开编辑，参照 Apple 提醒事项：标题可改，下面是灰色占位的「备注」和一排属性小块：日期、时间（有日期时）、优先级、课程、标记，小块改动立即保存；同一时间只展开一行，点另一行时前一行先保存再收起；回车或点击行外保存并收起，Esc 放弃标题与备注的修改；标题清空后收起即直接删除、不确认；展开收起不做高度动画）、优先级记号放在标题前（照 Apple 提醒事项：`!` 低=灰色、`!!` 中=`warning`、`!!!` 高=`destructive`，都不跟随强调色；无优先级不显示）、已标记旗子、截止（相对时间，逾期红色）、课程标签（课程颜色，点击更换）；行尾的标记（旗子）按钮和 `⋯` 菜单（编辑详情、优先级、删除）在悬停、聚焦或选中该行时出现，触屏（`pointer-coarse`）上常显。
- `⋯` 菜单的"编辑详情"（或选中行后按 `Enter`）打开右侧详情边栏：备注、截止日期时间选择器、优先级（带 `!` 记号的 `ToggleGroup`：无 / 低 / 中 / 高）、标记、列表（空值叫"未归类"）、课程、来源（若来自考核/LMS）、删除。点"保存"（或 `Cmd+Enter`）后边栏关闭；保存失败时保持打开。
- 勾选完成：先不保存，这一行留在原位显示为已完成 5 秒（`completion.ts`，模块级等待表，列表行、卡片和空格键共用），5 秒内再点一次即撤销、不发请求；到时前 0.25 s 行淡出，然后调用 `tasks.item.complete` 移到已完成区。离开页面不影响等待，标签页隐藏或关闭时立即保存。勾选时的动画：圆圈轻弹、对勾画出、标题删除线从左到右划过，外加一圈淡淡的强调色涟漪（样式在 `theme.css` 的 `[data-completing]`）；减少动态效果时没有动画，等待照旧。取消已完成任务的勾选立即生效。
- 已完成区：列表底部折叠"已完成 N 项"，展开查看与恢复；"清除已完成"（确认）。
- 键盘：`N` 新建、`↑↓` 选择、`空格` 完成、`Enter` 打开详情（`空格`/`Enter` 只在没有聚焦任何控件时作用于选中的任务，否则交给聚焦的按钮/链接）、`Delete` 删除（确认）、`Cmd+Enter` 保存详情。
- 显示偏好（排序方式、是否显示已完成、分组折叠状态）存 `useUiPref('tasks.view.<listKey>')`。

### 5.2 课程 Page `tasks`
- 同一组件，固定过滤 `course_id`，快速添加时自动带上课程。

### 5.3 Cards
- `tasks.today`（today/program/term，m/l；today 作用域默认 l）：今日与逾期任务，可勾选完成，快速添加。
- `tasks.list`（term/course，m/l，`multiple=true`）：设置中选择要显示的列表或智能视图。
- `tasks.counter`（term，s）：未完成/逾期数量。

### 5.4 设置分区（Program 级"待办"）
默认列表、默认优先级、列表中是否显示已完成、考核自动生成任务开关（打开时说明会补建多少个任务）。

## 6. Agent 集成
- 全部 capability 暴露。
- Skill `manage-tasks.md`：创建任务时尽量带上课程与截止日期（从对话或 scope 推断，推断不了就问）；"这周要交什么"优先用 `calendar.occurrence.list` 合并考核与任务，而不是只查任务；批量创建用 `create_many`。

## 7. 错误码
`tasks.list_name_conflict`、`tasks.course_not_in_program`、`tasks.invalid_due`（只有时间没有日期）。

## 8. 测试
- 学期自动推断（年课、无截止日期、截止日期在学期外）。
- 自动任务：开关补建数量、考核改期同步、出分自动完成、考核删除保留已完成任务、重复事件不重复建。
- 智能视图边界：今天 vs 逾期（Program 时区，跨午夜）。
- 删除学期后任务移入未归类。
- 前端：自然语言快速添加解析中英文（"明天下午3点 复习"、"Fri 5pm essay !!!"）。

## 10. 实现说明（偏离与补充）
- 设置：用 M11 的 `register_settings(namespace="tasks", levels=("program",))`，不建 `tasks_preferences` 表，也没有 `tasks.preferences.*` capability、`default_list_id`；前端设置分区由 manifest 的 `settingsSections` 自动生成。
- 学期视图包含没有学期的任务（Program 级任务在每个学期页都可见）；`tasks.item.count` 支持 `course_id`。
- 日历源 `tasks.due` 只返回未完成任务（`include_completed` 不返回已完成），`meta.term_id` 给出任务的学期；由考核生成的任务（`source_kind=assessment`）不进日历源，因为 `grading.assessments` 已经显示了该考核，否则同一考核会出现两次。
- 优先级：界面只提供四档（无 / 低 / 中 / 高），用彩色 `!`/`!!`/`!!!` 记号表示（和快速添加的写法一致）。后端仍保留 `urgent`（Agent/API 可写入），界面把它显示为"高"，用户不改优先级时保存不会把它降级；按优先级排序时 `urgent` 仍排在 `high` 前。设置里的"默认优先级"也只有四档，已存的 `urgent` 读作 `high`。快速添加照 Apple 提醒事项：`!` 低、`!!` 中、`!!!` 高，解析规则见 `parse.ts`。
- "已标记"（`flagged`）用旗子图标（同提醒事项）；优先级不用旗子，避免混淆（Jinyuan 2026-10-20）。字段名与智能列表不变。
- "收件箱"改名"未归类"（Unsorted）：入口、卡片设置选项、详情里列表选择的空值都叫这个名字；API 视图名、`tasks.counts.inbox` 与卡片设置的取值 `inbox` 不变。
- 列表重名检查在同一学期（或同为 Program 级）内忽略大小写与首尾空格。
- 自动任务由 `auto.py` 直接读取 M03 的考核模型；设置从关到开时补建。
- 删除学期/课程/Program 的清理订阅 `academics.*.deleting`（同事务）。
- 前端 `chrono-node` 做自然语言解析，拖拽排序用 dnd-kit，仅在"手动"排序的列表/未归类里可拖。
- Page 的页头由宿主 `ScopeHeader` 渲染，页面本身不再画标题。
- `tasks.item.query` 多了 `only_completed`：只返回该视图下已完成的任务。列表主体只查未完成，已完成折叠区单独查，已完成任务堆积不会挤掉未完成任务。
- 清除已完成：按钮只在"已完成"智能列表、某个用户列表和"按课程"里出现，那里列出的已完成任务正是会被删除的；学期范围和学期视图一致，包含没有学期的任务；确认框写出数量。
- 详情在右侧 `Sheet` 里打开，不再占用页面的一列；单击行只选中（键盘操作的对象），不打开边栏。
- "今天"、逾期和"明天"等相对日期按 Program 时区计算（`useProgramToday`），与后端一致。
- 勾选和拖动排序对已缓存的列表做乐观更新，失败时回滚。
- 用语：模块名叫"待办"，页面内的具体对象统一叫"任务"，这是有意的。
- 已知取舍：用户删掉某个自动生成的任务后，该考核下一次变动会把它重新建回来（只有考核变动和开关从关到开会补建，改别的待办设置不会；`settings.values.updated` 带 `changed`）。
- 开关只决定是否新建：关掉后，已有的自动任务仍跟随考核同步（改期、改名、出分完成、考核删除时删掉未完成的）。删除课程时（考核被一并删除且不发事件），该课程未完成的自动任务直接删除，已完成的改成普通任务（`source_kind=manual`）。
- `tasks.item.query` 的视图、日期、排序和分页都在 SQL 里完成，返回 `total`；只有模糊搜索和按标题排序（需要归一化）才在 Python 里处理全部匹配行。前端已完成区折叠时只请求一行拿 `total`，展开后按页加载（「显示更多」）；未完成列表一页 500 条，同样可以加载更多。
- 学期自己的列表（`term_id` 非空）显示它的全部任务，即使任务因年课被推断到别的学期；Program 级列表在学期页仍只显示该学期和无学期的任务。`task-counts` 的列表角标与此一致。
- 删除列表并删除任务、清除已完成：一条 SQL 删除，发一次带 `task_ids` 的 `tasks.item.deleted`（LMS 据此忘掉导入记录）。由考核生成的任务变动不发 `calendar.changed`（它们不在 `tasks.due` 里）。
- 手动排序的浮点位置在某个缝隙用尽时（中点不再严格位于两邻居之间）把整个列表按 1024 的间距重排。
- 列表按学期分组：Program 页的侧边栏和标题菜单按学期（学期名为组标题）列出，Program 级列表单独一组（「所有学期」）；学期页是本学期一组加「所有学期」一组。只有一组时不显示组标题；拖动和上移/下移只在组内。
- 快速添加按 Program 时区的当前时刻解析相对时间（"2 小时后"），只写时间且已过去的会落到明天（chrono 的 `forwardDate`）；保存中也能继续回车添加。"今天"与"计划中"里添加的任务默认今天到期。学期看板上的"今天"卡片只显示该学期（与无学期）的任务。
- 卡片设置表单（`settings.component`）由看板传入 `scope`，"列表"卡片据此只列出该学期能看到的列表。
