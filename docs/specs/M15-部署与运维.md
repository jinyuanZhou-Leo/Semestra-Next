# M15 部署与运维

> 依赖：M00（可在 M00 完成后立即开始，随其它模块推进补充配置）。
> 目标形态：托管版（前端 Vercel `semestra.jyleo.cc` + 后端 Google Cloud VM `api.semestra.jyleo.cc`）与自部署版（单机 Docker Compose 一条命令启动）。

## 1. 产物
1. **API 镜像** `ghcr.io/jinyuanzhou-leo/semestra-api:<version>`：多阶段构建（uv 安装依赖 → 精简运行镜像，Python 3.15 slim），非 root 用户，入口：`alembic upgrade head` 后启动 `uvicorn semestra.main:app --host 0.0.0.0 --port 8000 --proxy-headers`（单进程；worker 并发由 M00 job 配置控制）。包含 PDF 处理所需的系统库；LibreOffice 不包含（可选镜像 `-office` 变体包含，用于转换旧版 Office 格式）。
2. **Web 静态产物**：`pnpm --filter web build` 输出 `apps/web/dist`。
3. **自部署一体镜像** `semestra-allinone`：在 API 镜像基础上内置 web 静态文件，由 FastAPI 以 `StaticFiles` + SPA fallback 在同源提供（`SEMESTRA_SERVE_WEB=true`），此时 `PUBLIC_WEB_ORIGIN == PUBLIC_API_ORIGIN`，Cookie 不需要跨子域配置。

## 2. 托管版
### 2.1 后端（GCP VM）
- 规格建议：e2-small（2 vCPU 共享、2GB 内存）起步，Debian 12，持久盘 20GB 挂载到 `/srv/semestra`。
- `deploy/hosted/docker-compose.yml`：
  - `api`（镜像，卷 `/srv/semestra/data:/data`，环境文件 `.env`）
  - `caddy`（反向代理 + 自动 HTTPS，`api.semestra.jyleo.cc`；SSE 路由关闭缓冲；请求体上限 60MB；安全头）
  - `litestream`（持续复制 `/data/semestra.db` 与 `/data/agent_checkpoints.sqlite` 到 GCS bucket `semestra-backups`，保留 30 天；VM 使用服务账号授权，不放密钥文件）
- 文件存储：`/data/storage`；每日 `gsutil rsync` 到同一 bucket 的 `storage/` 前缀（cron 容器或 systemd timer）。
- DNS：`api.semestra.jyleo.cc` A 记录指向 VM 静态外部 IP；防火墙只开放 80/443。
- 部署：GitHub Actions 在 tag `v*` 时构建并推送镜像，然后通过 SSH（使用 GitHub Environment `production` 的密钥，需手动批准）执行 `docker compose pull && docker compose up -d`；部署后检查 `/readyz`，失败自动回滚到上一个镜像 tag。
- 恢复演练文档：`deploy/hosted/RESTORE.md`（从 Litestream 恢复数据库、从 GCS 恢复文件的步骤）。

### 2.2 前端（Vercel）
- 项目根目录 `apps/web`，构建命令 `pnpm build`，输出 `dist`；`vercel.json` SPA rewrite 到 `index.html`；静态资源长缓存，`index.html` 不缓存。
- 环境变量：`VITE_API_ORIGIN=https://api.semestra.jyleo.cc`、`VITE_GOOGLE_CLIENT_ID`。
- 自定义域名 `semestra.jyleo.cc`；预览部署指向 staging API（可选，见 2.4）。
- 安全头：CSP（`connect-src` 包含 API 域名与 Google 登录域；`script-src 'self'` + Google Identity 域）、`X-Frame-Options: DENY`、`Referrer-Policy: strict-origin-when-cross-origin`。

### 2.3 关键环境变量（`deploy/.env.example` 完整列出并注释）
`SEMESTRA_ENV=prod`、`SEMESTRA_SECRET_KEY`、`SEMESTRA_ENCRYPTION_KEY`（Fernet，**丢失将无法解密用户密钥**，需离线备份）、`SEMESTRA_PUBLIC_WEB_ORIGIN=https://semestra.jyleo.cc`、`SEMESTRA_PUBLIC_API_ORIGIN=https://api.semestra.jyleo.cc`、`SEMESTRA_CORS_ORIGINS=https://semestra.jyleo.cc`、`SEMESTRA_COOKIE_DOMAIN=.semestra.jyleo.cc`、`SEMESTRA_EMAIL_BACKEND=resend`、`SEMESTRA_RESEND_API_KEY`、`SEMESTRA_EMAIL_FROM`、`SEMESTRA_GOOGLE_CLIENT_ID`、`SEMESTRA_USER_STORAGE_QUOTA_BYTES=52428800`、`SEMESTRA_JOB_CONCURRENCY=2`、`SEMESTRA_SENTRY_DSN`（可选）。

### 2.4 Staging（可选但推荐）
同一 VM 上第二套 compose（`api-staging.semestra.jyleo.cc`，独立数据目录），`main` 分支每次合并自动部署，用于 Vercel 预览环境联调。

## 3. 自部署版
- `deploy/selfhost/docker-compose.yml`：`semestra`（一体镜像）+ 可选 `caddy`（有域名时自动 HTTPS）+ 可选 `ollama`（profile `ai-local`，提供本地 chat/embedding 模型，并通过 `SEMESTRA_INSTANCE_AI_*` 配置为实例级提供方）。
- 首次启动：若未设置 `SECRET_KEY`/`ENCRYPTION_KEY`，自动生成并写入 `/data/secrets.env`（日志提示备份该文件）。
- 默认 `EMAIL_BACKEND=console`：验证码打印在容器日志中；文档说明如何配置 SMTP。也提供 `SEMESTRA_SINGLE_USER=true` 模式：首次访问创建管理员账户（邮箱 + 密码），之后关闭注册。
- 配额默认不限（`USER_STORAGE_QUOTA_BYTES=0`），允许私网出站（`ALLOW_PRIVATE_EGRESS=true`，方便连接内网 Ollama/Canvas）。
- 文档 `deploy/selfhost/README.md`（中英）：一条命令启动、升级（`docker compose pull && up -d`，迁移自动执行）、备份（复制 `/data` 目录或启用内置每日备份到挂载目录）、配置 AI。

## 4. 可观测性与运维
- 日志：JSON 到 stdout，Docker 日志轮转（10MB × 5）。
- 错误追踪：Sentry（后端 `sentry-sdk`，前端 `@sentry/react`），DSN 为空时不启用；不上传请求体与用户内容（`send_default_pii=False`，beforeSend 过滤）。
- 健康检查：`/healthz`、`/readyz`；托管版用 UptimeRobot（或 GCP Uptime Check）监控两个域名。
- 指标（可选）：`/metrics`（Prometheus 格式，仅内网/需 token）：请求数与延迟、job 队列长度与失败数、AI 调用量。
- 数据库维护：每周 `VACUUM`/`ANALYZE` 定时任务（M00 periodic，夜间执行）。

## 5. CI/CD 汇总（`.github/workflows/`）
- `ci.yml`：PR 与 main 上运行 M00 定义的 api/web/contract 检查。
- `e2e.yml`：PR 上可手动触发，main 上每次运行：启动一体镜像 + Playwright 冒烟。
- `release.yml`：tag `v*` → 构建三个镜像推送 GHCR → 部署托管版（需批准）→ 创建 GitHub Release（自动生成变更日志）。
- `vercel`：通过 Vercel Git 集成，`apps/web` 目录变更时构建。

## 6. 安全清单（上线前逐项确认，写入 `deploy/SECURITY-CHECKLIST.md`）
- [ ] 所有密钥只在 VM `.env` 与 GitHub Environments 中，仓库中无明文。
- [ ] `ENCRYPTION_KEY` 已离线备份。
- [ ] Cookie `Secure`、`HttpOnly`、`SameSite=Lax`，CSRF 检查生效。
- [ ] CORS 只允许正式前端域名。
- [ ] Caddy 安全头与请求体上限。
- [ ] 出站请求私网拦截在托管版开启。
- [ ] 备份恢复演练完成一次。
- [ ] 限流（登录、发码、上传、AI）生效。

## 7. 验收
- 托管版：推送 tag 后经一次人工批准即完成部署，`https://semestra.jyleo.cc` 可注册登录并使用全部功能。
- 自部署版：在一台空白 Linux 机器上 `docker compose up -d` 后 2 分钟内可以访问并注册使用。
- 删除 VM 后能按 RESTORE.md 在新 VM 上恢复全部数据。
