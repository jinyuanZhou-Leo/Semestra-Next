# M14 小插件合集（计数器、习惯打卡、番茄钟、便签、世界时钟）与插件模板

> 依赖：M00、M10（Card、安装）、M11（插件设置）、M13（导出适配器）。可与其它业务模块并行开发。
> 每个插件独立目录：后端 `modules/plugins_builtin/<id>/`（仅需要持久化数据的插件才有后端）、前端 `modules/plugin-<id>/`。都是 `kind: 'plugin'`，`default_installed` 见各节。
> 旧版的 course-list 小部件在新版中是 M02 的核心卡片 `academics.termCourses`，不在本模块。

## 0. 公共要求
- 个人类卡片（counter、habit.board/habit.ring、pomodoro.timer、sticky.note、clock.world）的 `scopes` 都包含 `today`（M04 的"今天"页面，program 级 Board），默认模板里可以不放，用户自行添加；课程相关的卡片不需要。
- 卡片外框、尺寸、设置入口、删除由 M10 宿主提供；插件只实现内容区与设置 schema。
- 所有文案中英双语；所有颜色使用 token；遵循减少动效设置。
- 卡片在 s 尺寸下也必须可用（信息精简），在每个声明的尺寸下都要有设计。
- 每个插件的 capability（如有）都带 `plugin_id`，并注册 M13 导出适配器。
- 测试：每个卡片在所有尺寸下的渲染测试、设置校验测试、多实例互不干扰测试。

## 1. 计数器 `counter`（default_installed: false）
- 卡片 `counter.counter`（scopes: term/course/program，sizes: s/m，multiple）。
- 功能：标题、当前值、最小值/最大值/步长、加减按钮、可选环形进度（值在 min–max 间的比例）、头部"重置"操作（确认）。
- 设置 schema：`{ label: str, min: int = 0, max: int = 10, step: int = 1, initial: int = 0, show_ring: bool = true }`；校验 min < max、step > 0、initial 在范围内；修改范围时当前值夹到范围内并在表单中提示。
- 数据：当前值存卡片设置中的 `value` 字段（`layouts.card.settings.update`，乐观更新，300ms 防抖）。
- 可访问性：加减按钮 `aria-label`（"增加/减少 <label>"），数值 `aria-live="polite"`。

## 2. 习惯打卡 `habit-streak`（default_installed: true）
- 两张卡片，数据模型相同、展示不同：
  - `habit.board`（sizes: m/l/xl）：类 Duolingo 日历格子，按周排列最近 N 周（m=5 周、l=10 周、xl=20 周），已打卡格子高亮，今天的格子可点击打卡，连续天数里程碑（7、30、100 天）粒子动画。
  - `habit.ring`（sizes: s/m）：圆环显示当前周期目标进度与连续天数，点击打卡；里程碑时显示鼓励提示（toast，可在设置中关闭）。
- 设置：`{ name: str, icon: lucide 名, goal: 'daily'|'weekly', weekly_target: int (1-7, weekly 时), color: token, show_toast: bool }`。
- 后端数据：
  ```
  plugin_habit_checkins  id, user_id, instance_id, date (Program 时区本地日期), created_at  UNIQUE(instance_id, date)
  ```
  capability：`habit.checkin.toggle(instance_id, date)`（只允许今天与过去 7 天）、`habit.checkins.list(instance_id, from, to)`、`habit.stats(instance_id)`（当前连续、最长连续、总次数）。
- 连续天数计算在后端（daily：连续自然日；weekly：连续达标周）；同一天重复点击为取消打卡（确认后）。
- 卡片删除事件 → 删除打卡记录；导出适配器包含记录。
- Agent：`habit.checkin.toggle`（"帮我在阅读习惯上打卡"），用 `layouts.board.get` 找实例。

## 3. 番茄钟 `pomodoro`（default_installed: true）
- 卡片 `pomodoro.timer`（sizes: s/m/l）。
- 功能：专注/短休息/长休息三种模式（默认 25/5/15 分钟，每 4 个专注后长休息）、开始/暂停/跳过/重置（重置回初始专注）、模式标签、剩余时间大号显示、今日完成个数；l 尺寸额外显示今日专注时间与可选关联课程选择。
- 计时可靠性：状态 `{mode, ends_at | remaining_ms, cycle_index}` 存 `useUiPref('pomodoro.<instanceId>')`，以 `ends_at` 计算剩余时间（刷新、切换页面、后台标签页不漂移）；同一实例在多个标签页打开时以最新写入为准。
- 完成提醒：声音（可关）+ 浏览器通知（首次使用时请求权限，可关）+ 标签页标题显示剩余时间。
- 状态条：计时进行中（含暂停）时贡献 `statusItems` 项 `pomodoro.running`，显示模式与剩余时间，点击回到所在页面；没有计时时返回 `null`。
- 设置：`{ focus_min: 25, short_break_min: 5, long_break_min: 15, long_break_every: 4, auto_start_next: false, sound: true, notify: true }`。
- 后端数据（用于统计与 Agent 查询）：
  ```
  plugin_pomodoro_sessions  id, user_id, instance_id, course_id?, started_at, ended_at, duration_sec, mode
  ```
  capability：`pomodoro.session.record`（专注完成时前端调用）、`pomodoro.stats(range, course_id?)`（每日专注时长、按课程汇总）。
- Agent：`pomodoro.stats`（"我这周在 APS105 上专注了多久"）。

## 4. 便签 `sticky-note`（default_installed: true）
- 卡片 `sticky.note`（scopes: program/term/course，sizes: s/m/l/xl，multiple）。
- 功能：卡片内直接编辑的 markdown 便签（轻量编辑器：粗体、斜体、列表、复选框列表、链接；用 `@tiptap/react` 的最小配置或 textarea + 渲染切换，二选一以包体积小者为准），背景色可选 6 种便签色 token。
- 数据：内容存卡片设置 `{ content: str (≤ 10k 字符), color: token }`，输入 800ms 防抖保存，显示保存状态点。
- Agent：通过 `layouts.card.settings.update` 读写便签内容需要知道 instance；为此提供 `sticky.note.list(scope)` 与 `sticky.note.update(instance_id, content)` capability（"在这门课的便签里记一下期中考范围"）。

## 5. 世界时钟 `world-clock`（default_installed: false）
- 卡片 `clock.world`（sizes: s/m，multiple）。
- 功能：显示所选时区的时间与日期（按用户 locale 与 12/24 小时偏好格式化），可选显示秒（每秒刷新，否则每分钟对齐刷新），可选显示与本地时差；m 尺寸可显示最多 3 个时区。
- 设置：`{ zones: [IANA tz] (1-3), show_seconds: bool, show_offset: bool, label?: str }`，时区选择器支持搜索城市名（中英文）。
- 无后端。

## 6. 插件模板 `_template`（不注册到目录，仅作为开发参考）
- 目录 `apps/web/src/modules/_template-plugin/` 与 `apps/api/src/semestra/modules/plugins_builtin/_template/`：演示一个 Page、一张带设置的 Card、一个设置命名空间（account 与 course 级）、一个 read 和一个 write capability、一个 skill、导出适配器、中英文案。
- `docs/plugin-authoring.md`：插件开发指南（目录结构、manifest 字段、后端注册、Card 尺寸设计要求、设置 schema、测试要求、发布清单）。

## 7. 验收
- 五个插件都可在插件管理中安装/卸载；卸载后卡片消失、重装后数据恢复（选择删除数据时不恢复）。
- 番茄钟在刷新页面和切换标签后剩余时间准确。
- 习惯打卡连续天数在跨时区出行（修改 Program 时区不影响已记录日期）时保持正确。
