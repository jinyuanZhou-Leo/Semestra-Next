# M14 小插件合集（计数器、习惯打卡、番茄钟、便签、世界时钟）与插件模板

> 依赖：M00、M10（Card、安装）、M11（插件设置）、M13（导出适配器）。可与其它业务模块并行开发。
> 每个插件独立目录：后端 `modules/plugins_builtin/<id>/`（仅需要持久化数据的插件才有后端）、前端 `modules/plugin-<id>/`。都是 `kind: 'plugin'`，`default_installed` 见各节。
> 旧版的 course-list 小部件在新版中是 M02 的核心卡片 `academics.termCourses`，不在本模块。

## 0. 公共要求
- 个人类卡片（counter、habit.ring、pomodoro.timer、sticky.note、clock.world）的 `scopes` 都包含 `today`（M04 的"今天"页面，program 级 Board），默认模板里可以不放，用户自行添加；课程相关的卡片不需要。
- 卡片外框、尺寸、设置入口、删除由 M10 宿主提供；插件只实现内容区与设置 schema。
- 所有文案中英双语；所有颜色使用 token；遵循减少动效设置。
- 卡片在 s 尺寸下也必须可用（信息精简），在每个声明的尺寸下都要有设计。
- 每个插件的 capability（如有）都带 `plugin_id`，并注册 M13 导出适配器。
- 测试：每个卡片在所有尺寸下的渲染测试、设置校验测试、多实例互不干扰测试。

## 1. 计数器 `counter`（default_installed: false）
- 卡片 `counter.counter`（scopes: term/course/program，sizes: s/m，multiple）。
- 功能：标题、当前值、最小值/最大值/步长、加减按钮、可选环形进度（值在 min–max 间的比例）、头部"重置"操作（确认）。
- 设置 schema：`{ label: str, min: int = 0, max: int = 10, step: int = 1, initial: int = 0, show_ring: bool = true }`；校验 min < max、step > 0、initial 在范围内；修改范围时当前值夹到范围内并在表单中提示。
- 数据：当前值存卡片设置中的 `value` 字段（`layouts.card.update_settings`，乐观更新，300ms 防抖）。
- 可访问性：加减按钮 `aria-label`（"增加/减少 <label>"），数值 `aria-live="polite"`。

## 2. 习惯打卡 `habit-streak`（default_installed: true）
- 一张卡片 `habit.ring`（sizes: s/m/l）：圆环显示当前周期目标进度，是唯一的打卡入口（点击打卡今天，取消要确认），里程碑（7、30、100）时粒子动画并显示鼓励提示（toast，可在设置中关闭）。
  - s：圆环 + 名称 + 连续天数。
  - m：圆环、名称与统计在左，右侧是只读的打卡记录（按周排列的格子，最近一周在最右，列数按宽度放满，最多 52 周）。
  - l：上方圆环与统计（含累计次数），下方更大的格子与"最近 N 周"说明。
  - 原来的日历卡片 `habit.board`（格子可点击打卡）在 2026-10-31 并入：日历只负责回顾，打卡只在圆环上。迁移 0028 把已有的 `habit.board` 改成 `habit.ring`（xl 改成 l），卡片设置与打卡记录保持不变；M13 导入旧备份时同样改名。
- 设置：`{ name: str, icon: lucide 名, goal: 'daily'|'weekly', weekly_target: int (1-7, weekly 时), color: token, show_toast: bool, remind: bool, remind_at: 'HH:MM' }`。
- 每日提醒（`habit_streak/reminders.py`，M18 §4.5）：`remind` 开启后，在 `remind_at`（Program 时区）今天还没打卡、每周目标还没达标时发系统通知；设置表单在本设备没开通知时提示去设置 → 通知开启。默认关闭。
- 后端数据：
  ```
  plugin_habit_checkins  id, user_id, instance_id, date (Program 时区本地日期), created_at  UNIQUE(instance_id, date)
  ```
  capability：`habit.checkin.toggle(instance_id, date)`（只允许今天与过去 7 天）、`habit.checkin.list(instance_id, from, to)`、`habit.streak.get(instance_id)`（当前连续、最长连续、总次数）。
- 连续天数计算在后端（daily：连续自然日；weekly：连续达标周）；同一天重复点击为取消打卡（确认后）。
- 卡片删除事件 → 删除打卡记录；导出适配器包含记录。
- Agent：`habit.checkin.set(instance_id, date, checked)`（"帮我在阅读习惯上打卡"），幂等，重复调用不会反过来取消；`habit.checkin.toggle` 只给卡片的点击用（仅 HTTP）。用 `layouts.card.list(program_id, card_id?)` 找实例：它查 Program 的总览、今天页、各学期和各课程看板，每张卡片带看板名和标签（习惯名、便签第一行）。

## 3. 番茄钟 `pomodoro`（default_installed: true）
- 卡片 `pomodoro.timer`（sizes: s/m/l）。
- 功能：专注/短休息/长休息三种模式（默认 25/5/15 分钟，每 4 个专注后长休息）、开始/暂停/跳过/重置（重置回初始专注）、模式标签、剩余时间大号显示、今日完成个数；l 尺寸额外显示今日专注时间与可选关联课程选择。
- 计时可靠性：状态 `{mode, ends_at | remaining_ms, cycle_index}` 存 `useUiPref('pomodoro.<instanceId>')`，以 `ends_at` 计算剩余时间（刷新、切换页面、后台标签页不漂移）；同一实例在多个标签页打开时以最新写入为准。
- 完成提醒：声音（可关）+ 系统通知（走 M18 的 `showLocal`，只在本设备已开启通知时显示；第一次开始计时会请求开启，可关）+ 标签页标题显示剩余时间。
- 状态条：计时进行中（含暂停）时贡献 `statusItems` 项 `pomodoro.running`，显示模式与剩余时间，点击回到所在页面；没有计时时返回 `null`。
- 设置：`{ focus_min: 25, short_break_min: 5, long_break_min: 15, long_break_every: 4, auto_start_next: false, sound: true, notify: true }`。
- 后端数据（用于统计与 Agent 查询）：
  ```
  plugin_pomodoro_sessions  id, user_id, instance_id, course_id?, started_at, ended_at, duration_sec, mode
  ```
  capability：`pomodoro.session.record`（专注完成时前端调用）、`pomodoro.session.summarize(range, course_id?)`（每日专注时长、按课程汇总）。
- Agent：`pomodoro.session.summarize`（"我这周在 APS105 上专注了多久"）。

## 4. 便签 `sticky-note`（default_installed: true）
- 卡片 `sticky.note`（scopes: program/term/course/today，sizes: s/m/l/xl，multiple，`bleed`：颜色铺满卡片，任何尺寸都没有标题行）。
- 功能：卡片内所见即所得编辑的 markdown 便签（粗体、斜体、列表、复选框列表、链接、表格），背景色可选 6 种便签色 token。
- 数据：内容存卡片设置 `{ content: str (≤ 10k 字符), color: token }`，输入 800ms 防抖保存，只在保存失败时显示红点。
- Agent：通过 `layouts.card.update_settings` 读写便签内容需要知道 instance；为此提供 `sticky.note.list(scope)`（scope 可以是 today）与 `sticky.note.update(instance_id, content, mode)` capability（"在这门课的便签里记一下期中考范围"）；`mode` 默认 `append`（接在原文后，空一行作为新的段落），`replace` 才整段覆盖，免得模型要把原文抄回来。

## 5. 世界时钟 `world-clock`（default_installed: false）
- 卡片 `clock.world`（sizes: s/m，multiple）。
- 功能：显示所选时区的时间与日期（按用户 locale 与 12/24 小时偏好格式化），可选显示秒（每秒刷新，否则每分钟对齐刷新），可选显示与本地时差；m 尺寸可显示最多 3 个时区。
- 设置：`{ zones: [IANA tz] (1-3), show_seconds: bool, show_offset: bool, label?: str }`，时区选择器支持搜索城市名（中英文）。
- 无后端。

## 6. 插件模板 `_template`（不注册到目录，仅作为开发参考）
- 目录 `apps/web/src/modules/_template-plugin/` 与 `apps/api/src/semestra/modules/plugins_builtin/_template/`：演示一个 Page、一张带设置的 Card、一个设置命名空间（account 与 course 级）、一个 read 和一个 write capability、一个 skill、导出适配器、中英文案。
- `apps/docs/content/docs/plugins.zh.mdx`（原 `docs/plugin-authoring.md`，已移入文档站）：插件开发指南（目录结构、manifest 字段、后端注册、Card 尺寸设计要求、设置 schema、测试要求、发布清单）。

## 7. 验收
- 五个插件都可在插件管理中安装/卸载；卸载后卡片消失、重装后数据恢复（选择删除数据时不恢复）。
- 番茄钟在刷新页面和切换标签后剩余时间准确。
- 习惯打卡连续天数在跨时区出行（修改 Program 时区不影响已记录日期）时保持正确。

## 8. 实现说明（M14 落地时补充）
以下是实现时做出的取舍与对上文的细化，以代码为准。

**习惯打卡**
- 连续天数：当天（或当周）还没打卡时，连续不会中断，只有错过完整的一天（一周）才归零；weekly 目标按"达到 `weekly_target` 的连续周"计算，周起点用 M11 的 `week_start`。
- `habit.streak.get` 额外返回 `goal`、`weekly_target`、`period_done`、`period_target`、`checked_today`、`today` 与 `week_start`：`today` 和周起点由后端按卡片所在 Program 的时区给出，前端不做时区计算；已记录的日期是纯日期，之后修改 Program 时区不影响它们。
- `habit.checkin.toggle` 的错误：`habit.date_out_of_range`（params `earliest`）、`habit.range_invalid`；`habit.checkin.list` 的区间最长 400 天。取消打卡的确认在前端（`useCheckinFlow`）。
- `plugins.purge`（卸载事务内的事件，订阅用 `in_transaction=True`）删除用户全部打卡；`layouts.card.deleted` 只删该实例的打卡。

**番茄钟**
- `pomodoro.session.record` 只有 HTTP（给前端用，不暴露给 Agent）；按 `(instance_id, started_at)` 幂等，重复上报同一次专注不会重复计数；校验错误 `pomodoro.session_invalid`。
- 删除卡片**不**删除专注记录（统计应当保留），只有 `plugins.purge` 清空；同时清掉 `settings_ui_state` 里 `pomodoro.` 开头的计时状态（经 `settings.service.purge_ui_state`）。导入（M13）时，找不到对应卡片的打卡与专注记录会被跳过。
- `pomodoro.session.summarize` 按 Program 时区分日：传了 `course_id` 用该课程的 Program，否则用 M11 的活动 Program，再退到第一个 Program，最后 UTC；区间错误 `pomodoro.range_invalid`。
- 计时状态存 `useUiPref('pomodoro.<instanceId>')`，`pomodoro.active` 指向状态条要显示的计时（最近一次开始的）；状态条项 `pomodoro.running` 在没有计时时返回 `null`。

**便签**
- 编辑器是 Tiptap（Sem 的输入框已在用）：StarterKit + 官方 `TaskList`/`TaskItem`（复选框用 shadcn `Checkbox` 的 React 节点视图）+ `TableKit` + `@tiptap/markdown`（marked，`gfm` + `breaks`：单个换行是换行，旧便签与 Agent 写入的逐行文本照原样显示）。内容读写都是 Markdown，Agent 与卡片共用一种格式；表格存为 GFM 管道表格。存储是普通 Markdown（`markdown.ts`）：不解析 HTML（只认表格单元格里的 `<br>`），`<`、`>`、`&` 原样保存，单个换行就是换行；Tiptap 默认会把它们存成实体，它的文本编码钩子是私有的，所以在 `NoteMarkdownManager` 实例上替换，`markdown.test.tsx` 钉住往返结果。schema 只允许存储格式能表达的结构：表格单元格只放一个段落（`TableCell`/`TableHeader` 的 `content: 'paragraph'`），单元格里列表按钮不可用，粘贴进单元格按纯文字（换行变成换行符）。字数上限在事务层拦截（`limit.ts`：让 Markdown 变长且超限的事务被拒，删减总是放行，提示一次 toast）。平时只读（`editable: false`）：链接是普通链接，点击由浏览器打开，复选框仍可勾选。进入编辑：标题栏按钮 `headerActions`（铅笔，编辑中变成对勾“完成编辑”）、双击文字（光标落在双击处），空便签单击即可；结束编辑：在卡片外按下指针或焦点移出卡片（工具栏的弹层不算）、Esc、对勾按钮。标题栏按钮与卡片正文是两个组件，经 `editing.ts` 的按实例标记共享状态。编辑中点击链接是把光标放进去编辑，⌘/Ctrl+点击或链接弹层里的按钮打开；没有选中文字时添加链接会插入网址本身。工具栏在编辑中从底部浮出，s 尺寸没有工具栏；空便签只读时也显示占位文字。光标在表格里时表格按钮变成菜单（插入/删除行列、删除表格）。直接输入 Markdown 也行（`markdown-input.ts`）：表头行下面输入分隔行（`| --- | --- |`）再回车就变成表格；粘贴的纯文本按 Markdown 解析，带 HTML 的粘贴只有含表格时才按 Markdown 解析。外部改动（Agent、其它标签页）只要本地没有未保存的修改就立即载入（有焦点时保留光标位置）；本地有未保存修改时不载入，保存后以本地内容为准（`useCardSettings` 的 `hasUnsaved`）。滚动区隐藏滚动条，用 `scroll-fade` 提示还有内容。
- 2026-11-16 起从 textarea + 自写渲染器（`markdown.tsx`）换成上面的 Tiptap 编辑器，原因是要支持表格与所见即所得编辑。
- 只读时不加载编辑器（2026-11-20）：Tiptap 连同 ProseMirror 约 160 kB gzip，便签平时只读，所以卡片先用 `NoteView` 显示，第一次进入编辑（或勾选清单项）时才加载 `NoteEditor`，之后这张卡片一直用编辑器（只读/编辑之间切换照旧）。`NoteView` 用同一套 `marked` 设置读 Markdown（`note-marked.ts`），编辑器与 GFM 读法不同的两处（清单、表格单元格代码里的 `|`）照 Tiptap 的分词规则（`editor-rules.ts`，从 Tiptap 3.32 复制，直接引入会把 ProseMirror 一起带进来），输出与编辑器相同的元素和属性，所以 `note.css` 同时作用于两者，换上编辑器时什么都不动；Tiptap 自带的样式表不注入（`injectCSS: false`），需要的规则写在 `note.css`，两边一致。`view.test.tsx` 对一组写法（以及编辑器保存后的写法）逐一比较两者的 DOM，Tiptap 升级后规则变化会在这里失败。双击时记下坐标，编辑器换上后在同一坐标放光标。只读时勾选清单项也交给编辑器的代码：在不显示的编辑器里解析、改第 n 项（阅读顺序）、再序列化，与编辑器里勾选的结果一致；代码还没到时先显示勾选状态。悬停或聚焦便签（含标题栏按钮）就开始加载编辑器的代码；加载失败时提示并保持只读。打字时 Markdown 只序列化一次（`limit.ts` 的 `noteMarkdown` 按文档缓存，字数上限和保存共用）。放一张便签的看板因此少下载约 158 kB（今天页实测：便签带来的额外下载 176.8 → 18.4 kB gzip）。
- `sticky.note.list(scope_type, scope_id)`（scope_type 可以是 today）与 `sticky.note.update(instance_id, content, mode)`：`mode` 默认 `append`（接在原文后空一行，同一调用重复两次会追加两次），`replace` 整体替换文本。

**计数器、世界时钟**：没有后端包，数据都在卡片设置里（计数器的 `value`）。世界时钟的时区选择器内置常用城市的中英文名，支持搜索。

**与 M10、M13 的接口**：插件读取卡片实例只通过 `plugins_builtin/instances.py`（`get_card_instance`、`list_card_instances`、`update_card_settings`、`instance_program`）；导出适配器按 M13 §3 的形态写在 `plugins_builtin/portability.py`，M13 落地时用其中的 `ADAPTER` 注册。前端的 `plugin-kit/useCardSettings` 封装"本地立即生效、延迟保存、失败回滚"。

**插件模板**：`hello-note`（前端 `_template-plugin/`，后端 `plugins_builtin/_template/`）；开发指南见 [apps/docs/content/docs/plugins.zh.mdx](../../apps/docs/content/docs/plugins.zh.mdx)。
