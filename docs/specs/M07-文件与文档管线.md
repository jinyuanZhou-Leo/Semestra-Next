# M07 文件与文档管线（Files & Document Pipeline）

> 依赖：M00、M02、M06（OCR 与 embedding，可选能力）、M11。被依赖：M08（抽取读取解析结果）、M09（Canvas 文件保存到课程文件）、M12（检索与引用）、M13（备份）。
> 核心模块（`kind: 'core'`）。替代旧版 `builtin-course-resources` 插件，并新增文档解析、全文检索与语义检索。

## 1. 目标与功能对齐
旧版功能（保留）：
- 课程文件管理：拖拽/多文件上传、保存外部链接、重命名、删除、文件夹浏览、排序；打开外部链接前确认。
- 账户级存储配额 50MB，上传读取有上限。
- 快速打开小部件：在仪表盘置顶若干文件/链接。
- 文件元数据（名称、类型、大小、时间）格式化显示。

新增：
- 文件预览（PDF、图片、文本/markdown、Office 转换后的 PDF）。
- 上传后自动进入**文档管线**：解析 → 按页文本（markdown）→ 切块 → 全文索引（总是）→ 向量索引（用户配置了 embedding 时）。
- 检索能力 `files.search`（关键词 + 语义混合），返回带页码的引用，供 Agent 回答与 M08 抽取使用。
- 重复文件检测（同课程内 sha256 相同提示）。

## 2. 领域模型
```
files_folders
  id, user_id, course_id, parent_id?, name, position, created_at, updated_at
  UNIQUE(course_id, parent_id, name)

files_items
  id, user_id, course_id, folder_id?, kind ('file'|'link'),
  display_name, original_name?, mime_type?, size_bytes, sha256?, storage_key?,
  url? (link 时), pinned (bool),
  source_kind? ('upload'|'lms'|'agent'), source_ref?,
  doc_status ('none'|'pending'|'processing'|'ready'|'failed'|'unsupported'),
  doc_error_code?, active_document_id?, created_at, updated_at

files_documents                     # 一次解析的产物（文件重新上传/重新解析会生成新版本）
  id, user_id, item_id, parser_fingerprint, page_count, char_count, language?,
  status ('building'|'ready'|'failed'), created_at

files_document_pages
  id, document_id, user_id, page_no (1-based), markdown, ocr_used (bool),
  image_storage_key? (页面缩略图, 预览与多模态复用)

files_chunks
  id, document_id, user_id, item_id, course_id, chunk_no, page_from, page_to,
  heading_path (JSON list), text, token_count, content_hash
files_chunks_fts   # FTS5 虚拟表 (text, heading_path), content='files_chunks', tokenize='trigram'
files_chunk_vectors # sqlite-vec 虚拟表 vec0(chunk_id TEXT PRIMARY KEY, user_id TEXT PARTITION KEY, course_id TEXT, embedding float[dim])，
                    # 按 user_id 分区，检索只扫描该用户自己的向量；每个 (embedding model, dim) 一张表，表名含模型指纹
                    # 向量库通过 VectorStore 接口访问（upsert / delete / knn(user_id, filters, k)），实现可替换为 Qdrant
files_index_state
  item_id (PK), user_id, fts_document_id?, vector_document_id?, vector_fingerprint?, updated_at
```
- FTS5 使用 `trigram` 分词器，同时支持中文与英文子串匹配。
- 文件夹只是课程内的组织方式，最多 3 层。

## 3. 文档管线
### 3.1 阶段与任务
上传完成（或 link 指向可下载的 PDF 并由用户选择"保存副本"）→ 入队 `files.process`（`dedupe_key=item_id:sha256`）：
1. **识别类型**：按 magic bytes 判断。支持：PDF、DOCX、PPTX、XLSX/CSV、TXT/MD、HTML、图片（PNG/JPEG/WebP/HEIC）、ICS（交给 M08，不进入文本索引）。其它类型 `doc_status=unsupported`。
2. **解析为按页 markdown**：
   - PDF：PyMuPDF（`pymupdf4llm`）逐页提取；某页文字少于 50 个字符且有图像 → 标记需要 OCR。
   - DOCX/PPTX/XLSX：MarkItDown；PPTX 每张幻灯片一页；DOCX 按分页符或每 3000 字符一页（记录为逻辑页）。
   - 图片：整张作为一页，需要 OCR。
   - OCR：若 `ai.available(vision)` → 页面渲染为 PNG（150 DPI）调用 M06 `complete(purpose="vision")`，提示词要求输出 markdown（表格保留为 markdown 表格）；不可用 → 该页文本为空，`doc_status` 仍为 ready 但标记 `ocr_skipped`，前端提示"配置 AI 后可识别扫描页"。
   - 生成每页缩略图（预览与后续多模态复用）。
3. **切块**：按标题层级和段落切分，目标 600 token、重叠 80 token，单块不跨越 3 页以上；记录 `heading_path`、页码范围。
4. **全文索引**：写入 FTS5。
5. **向量索引**（若 `ai.available(embedding)`）：批量 embed（每批 64），写入对应 vec0 表。
6. 原子切换：新 document 全部完成后更新 `files_items.active_document_id` 与 `files_index_state`，再删除旧 document 的 chunks/vectors。
- 每个阶段通过 `JobCtx.report` 报告进度与 step（`detecting|parsing|ocr|chunking|indexing|embedding`），并检查取消。
- **管线指纹**：`parser_fingerprint = hash(parser_version, ocr_model?, chunker_version)`；`vector_fingerprint = hash(embedding_provider, model, dim)`。用户更换 embedding 模型后，定时任务 `files.reindex_vectors` 为所有 ready 的文档补建新指纹的向量（旧表在完成后删除）；重新解析只在 parser 版本升级或用户手动"重新处理"时进行。
- 失败：`doc_status=failed`，`doc_error_code` ∈ `files.parse_failed`、`files.encrypted_pdf`、`files.too_many_pages`（上限 500 页）、`ai.*`。

### 3.2 检索 `files.search`
- 输入：`query`、范围（program_id 必填，term_id?/course_ids?/item_ids?）、`top_k`（默认 8，最大 20）、`mode`（`hybrid` 默认 / `keyword` / `semantic`）。
- 关键词：FTS5 bm25；语义：查询 embed 后 vec0 KNN（k=top_k×4），按范围过滤。
- 混合：Reciprocal Rank Fusion（k=60）合并；同一文件相邻块合并为一个结果。
- 结果：`[{item_id, display_name, course_id, page_from, page_to, heading_path, snippet (高亮), score, citation_id}]`。`citation_id = "<item_id>:p<page_from>-<page_to>"`，前端可据此打开预览定位到页。
- 范围内有文件仍在处理中时，结果附带 `pending_items: [...]`，由调用方决定如何提示；**不**降级为读取半成品。
- 语义模式但 embedding 不可用 → 自动退化为 keyword 并在结果中标记 `mode_used=keyword`。

### 3.3 读取接口（给 M08 和 Agent）
- `files.document.read(item_id, pages?)`：返回指定页的 markdown（最多 30 页一次），用于整份文档抽取；超出时返回 `next_page`。
- `files.document.outline(item_id)`：标题层级与对应页码。

## 4. 存储与配额
- 存储 key：`users/<user_id>/files/<item_id>`；页面缩略图 `users/<user_id>/files/<item_id>/pages/<n>.png`（计入配额的只有原文件）。
- 配额：`USER_STORAGE_QUOTA_BYTES`（托管默认 50MB，自部署可调或设为 0 表示不限）；单文件上限 25MB（配置项）。上传前前端先检查剩余空间，后端流式计数再次检查。
- 本模块向 M00 注册存储用量统计函数。

## 6. 前端
### 6.1 课程 Page `files`
- 工具栏：上传（按钮 + 整页拖拽覆盖层）、新建链接、新建文件夹、搜索（当前课程内，走 `files.search` 混合检索；无输入时为文件名过滤）、视图切换（列表/网格）、排序。
- 面包屑文件夹导航；列表列：图标（按类型）、名称、大小、修改时间、处理状态（处理中显示进度环，失败显示重试）、置顶星标、操作菜单（重命名、移动、下载、重新处理、删除）。
- 上传进度：每个文件一行进度条；超配额时阻止并提示剩余空间；同名/同 hash 提示"已存在，仍然上传？"。
- 预览抽屉/对话框：PDF 用 `pdf.js`（`react-pdf`），支持 `#page=` 定位与搜索结果高亮；图片原图；文本/markdown 渲染；不支持预览的显示下载按钮。外部链接点击时确认"即将打开外部网站"（可勾选不再提示该域名，存 UI 偏好）。
- 存储用量条显示在页脚。

### 6.2 学期 Page `files`
- 按课程分组展示本学期所有文件（只读浏览 + 搜索），跨课程搜索。

### 6.3 Cards
- `files.quickOpen`（term/course，s/m/l，`multiple=true`）：卡片设置中选择要置顶的文件（可从多个课程中选，term 作用域下），点击直接预览。
- `files.recent`（course，m）：最近上传。

### 6.4 引用组件
`<Citation id="item:p3-4" />`：显示文件名与页码的小标签，点击打开预览并定位，M12 的对话界面与 M08 的导入审核界面使用。

## 7. Agent 集成
- 暴露：`files.list`、`files.item.get`、`files.search`、`files.document.read`、`files.document.outline`、`files.link.create`、`files.item.update`（重命名/移动）、`files.folder.create`；删除类按 destructive 处理。
- Skill `answer-from-course-files.md`：回答课程内容问题时先 `files.search`（范围限定当前课程），回答必须附 citation；结果为空或有 `pending_items` 时如实告知；整份文档总结用 `files.document.read` 分页读取。

## 8. 错误码
`common.quota_exceeded`（params: used, quota）、`files.too_large`（params: max）、`files.unsupported_type`、`files.parse_failed`、`files.encrypted_pdf`、`files.too_many_pages`、`files.folder_not_empty`、`files.folder_depth`、`files.invalid_url`。

## 9. 测试
- 上传流式超配额中止且不留下孤儿对象。
- 各格式解析的快照测试（fixtures：数字版 PDF、扫描版 PDF、DOCX、PPTX、中文 PDF）。
- OCR 不可用时跳过并标记；可用时（mock M06）写入 OCR 文本。
- 原子切换：重新处理过程中搜索仍返回旧版本结果，完成后切换。
- 检索：中文子串匹配、课程号匹配（"APS105"）、RRF 合并、范围过滤、越权（不能检索他人文件）。
- embedding 模型变更触发向量重建。
- 前端：拖拽上传、预览定位到页、外链确认。

## 10. 验收
- 上传一份 20 页 syllabus PDF，30 秒内 `doc_status=ready`，在课程文件页能搜到其中的句子并跳转到页。
- 未配置 AI 时文件功能完整可用（只缺 OCR 与语义检索）。
