学期日历把三类内容放在一起：课、事件，以及有截止日期的待办。时间始终按 Program 所在的时区显示，人在哪里都不会错。

## 填写每周上课时间

在课程的课表里按 Section（如 LEC0101、TUT0203）填写上课时间：每个 Section 有类型、编号、授课教师和上课的周次，每节课有自己的星期、时间和地点。填好后，整个学期的课会自动出现在日历里，假期周不上课。

- 一个 Section 的各节课周次相同。某一节开始得比其他节晚时，可以停掉它不上的那几次，或者把它单独添加成一个 Section。
- 把 Section 的编号改成同类型已有的编号，保存时会把它的上课时间并入那个 Section。
- 不想在日历里看到某一节课时，可以把它隐藏。

上课时间也可以从日历文件或课表截图[导入](/docs/ai/imports)。

## 调课和停课

某一次课改了时间或取消了，在日历里选中它，选择**调课**或**取消本次**。之后随时可以恢复。

## 事件和待办

- 在日历上选一段时间，可以新建事件或待办。
- 勾选待办即完成；把待办拖到别的日期即可修改截止日期。考核的截止日期跟随成绩册，需要在成绩册里改。
- 从 [LMS](/docs/lms) 同步来的日历事件也会显示在这里。

选中日历上的一项可以查看详情，并跳到它所在的地方，例如课程课表、成绩册里的考核，或者 Canvas。

## 导出

### 图片或 PDF

把周视图存成图片或 PDF，方便打印或发给别人。可以选一周、几周，或者不带日期的每周课表。

### 日历文件

把整个学期或选定的几周下载成 `.ics` 文件，一次性导入 Apple 日历、Google 日历或 Outlook。之后在 Semestra 里的改动不会同步过去，需要自动更新请用订阅链接。

### 订阅链接

每个 Program 有一个只读的订阅链接。把它添加到日历应用后，Semestra 里的改动会自动出现（日历应用通常每隔几小时更新一次）。可以选择包含课程和事件、待办以及 LMS 日历。

知道链接的人都能看到其中的内容，只把它添加到你自己的日历里。误分享时，**重置链接**会换一个新地址，旧地址随即失效；**停用链接**后，所有使用它的日历都不再更新。
