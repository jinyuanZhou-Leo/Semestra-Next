所有 LMS 导入都会先打开审核，确认之后才写入：每个作业导入到哪个分类、进成绩簿还是待办，都可以在审核里改，改完再导入。和你手动添加的考核同名的作业，在审核里默认绑定到那一项（“绑定已有考核”）：考核保持原样，此后跟随这个作业同步。想单独导入一项时，在这一格里改选“作为新考核加入”。关掉审核后再次导入这门课的作业，会回到这次还没完成的导入，新选的作业会补进去。

## 课程

在新建学期向导里，或在学期的**添加课程**菜单里（学期页面的命令面板里也有），选**从 LMS 导入课程**。选择 Canvas 课程（默认是当前学期的，也可以显示全部），审核后提交。
每门课程的标题取自 Canvas 课程名，代码取自 Canvas 课程代码（同时保存为别名），网址取自 Canvas 链接，并在同一步里关联到对应的 Canvas 课程。

## 作业

可以在课程的**成绩**页打开**添加**，在“从已有资料添加”下选择 Canvas 作业；也可以在 Canvas 页签的**作业与成绩**里勾选作业，再选**导入**。有分值的作业成为成绩簿里的考核（有截止日期时带一条待办），没有分值的作业成为待办。“Semestra”一列写明每项作业的去向（“已加入成绩簿”或“已加入待办”，点击可跳过去），还没导入的显示“未加入”。

导入审核里，作业“导入到”一列是个下拉菜单：有分值的作业也可以选**待办**只作为待办导入，反过来选**成绩簿**。

进入学业项目时，如果当前学期的课程在 Canvas 上有新作业（还没导入、截止日期未过），右下角会弹出“Canvas 上有 N 个新作业”的通知：选**导入**一次导入，选**忽略**则这些作业不再提醒，有新作业时才会再提示。

只成为待办的作业，可以在行末的菜单里选**加入成绩簿**：它成为考核，原来的待办保留并归到这个考核下。

- 成为考核时，每个 Canvas 作业组会归入课程已有的成绩分类：先看这个组之前导入的作业现在在哪个分类（在成绩簿里改过分类，下次就照着来），再看名字相同或组名里包含的分类，再按同义词归入内置分类（“Term Tests”归入考试，“Problem Sets”归入作业）。组名看不出意思时（“Coursework”、Canvas 默认的“Assignments”），组里过半的作业指向同一个分类就归过去。都对不上才用组名新建分类。审核里会写明每个组归入哪里，可以改。作业的 Canvas 链接保存在备注里。
- 权重来自 Canvas 的作业组：考核的权重是所在作业组的权重乘以它在组内分值中的占比。课程没有给作业组设置权重时，权重留空，审核里由你填写。
- 在 Canvas 上已经有成绩的作业，导入时会把得分（得分 / 满分）一并带入考核。
- 每个作业在 Semestra 里只对应一项：一个考核（连同它的待办）或一个待办。
- 只导入作业组里的部分作业时，分类的权重和已导入考核的合计会不一样，剩下的可以以后再导入。

### 绑定手动添加的考核

手动添加的考核在 Canvas 上名称不同时，可以在成绩页该行的菜单里选**绑定 Canvas 作业…**，再从这门课还没导入的作业里选一项。绑定本身不会修改考核：下一次[同步](./index.mdx#后台同步)会补上它还没有的截止时间、权重或成绩，两边都有而且不同的会询问你。此后它和导入的考核一样（跟随 Canvas，在 Canvas 上提交后自动完成待办）。同一菜单里的**解除与 Canvas 的绑定**会保留考核原样，作业可以重新导入或绑定；导入的考核也可以解除。

## 导入之后的变化

导入的作业通过[后台同步](./index.mdx#后台同步)跟随 Canvas：Canvas 上的名称、截止日期、权重（包括分值变化引起的）或成绩变了，这里会跟着更新，除非这个值你自己改过；两边都改过的会询问你。每次更新都可以在侧边栏的状态行里撤销。开启[通知](/docs/notifications)后，应用没打开时新成绩和更新也会以通知送达。

## 课程大纲

在 Canvas 页签的课程大纲视图里，可以把 Canvas 上的课程大纲交给 AI 提取。课程信息、成绩构成和截止日期会进入审核，和上传课程大纲文件一样。这需要配置
[AI 服务商](/docs/ai)。

## 文件

Canvas 文件可以保存到课程自己的文件里，保存后会建立搜索索引，也可以用于提取。
