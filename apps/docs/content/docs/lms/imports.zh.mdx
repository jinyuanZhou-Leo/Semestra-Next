从 LMS 导入的内容都会先经过审核，你确认之后才会写入。导入之后，它们会通过[自动同步](./index.mdx#自动同步)跟随 Canvas 更新。

## 导入课程

新建学期时，或在学期里添加课程时，选择**从 LMS 导入课程**，再选要导入的 Canvas 课程。课程的名称、代码和网址取自 Canvas，并自动关联到对应的 Canvas 课程。

## 导入作业

在课程的成绩册里添加考核时选择 Canvas 作业，或者在 Canvas 标签页的**作业与成绩**里勾选作业后选择**导入**。

- 有分值的作业默认加入成绩册，成为考核；没有分值的作业成为待办。审核时可以改。
- 作业会自动归入课程已有的成绩分类，例如“Term Tests”归入考试。对不上时才会新建分类，审核时可以改。
- 权重按 Canvas 作业组的权重和作业的分值算出；Canvas 没有设置权重时，在审核里自己填写。
- 在 Canvas 上已经有的成绩会一起导入。

和你手动添加的考核同名的作业，会默认绑定到那个考核：考核本身不变，之后跟随这个作业同步。想单独导入时，改选**作为新考核加入**。

只作为待办导入的作业，之后也可以随时加入成绩册。

### 绑定手动添加的考核

手动添加的考核在 Canvas 上名称不同时，可以为它选择**绑定 Canvas 作业…**。绑定后，下一次同步会补上它还没有的截止日期、权重或成绩，两边不一样的会询问你。解除绑定时考核保持原样。

## 新作业

Canvas 上新出现的作业不会自动加入，而是在侧边栏的同步状态里等你处理：选择导入就会打开审核，选择忽略则不再提醒。

## 课程大纲

在 Canvas 标签页里打开课程大纲，可以用 AI 读取其中的课程信息、成绩构成和截止日期，审核后导入，和[上传课程大纲文件](/docs/ai/imports)一样。这需要先添加[模型服务商](/docs/ai)。

## 文件

Canvas 上的文件可以存入课程文件，之后就能搜索，也能让 Sem 读取。
