---
title: 从 Canvas 导入
description: 把 Canvas 的课程、作业和课程大纲导入 Semestra。
---

课程和课程大纲导入会先打开审核，确认之后才写入。作业导入在没有需要你决定的地方时直接保存；成绩簿里已有同名考核，或者考核没有权重时，才打开审核。已有同名考核的作业在审核里默认不勾选，标着“成绩簿中已有”，勾选后才会导入。关掉审核后再次导入这门课的作业，会回到这次还没完成的导入，新选的作业会补进去。

## 课程

在新建学期向导里，或在学期的**添加课程**菜单里（学期页面的命令面板里也有），选**从 LMS 导入课程**。选择 Canvas 课程（默认是当前学期的，也可以显示全部），审核后提交。
每门课程的标题取自 Canvas 课程名，代码取自 Canvas 课程代码（同时保存为别名），网址取自 Canvas 链接，并在同一步里关联到对应的 Canvas 课程。

## 作业

可以在课程的**成绩**页打开**添加**，在“从已有资料添加”下选择 Canvas 作业；也可以在 Canvas 页签的**作业与成绩**里勾选作业，再选**导入**。有分值的作业成为成绩簿里的考核（有截止日期时带一条待办），没有分值的作业成为待办。“在 Semestra 中”一列显示作业的待办（可以直接在这里勾掉），进了成绩簿的作业另有成绩簿图标。

进入学业项目时，如果当前学期的课程在 Canvas 上有新作业（还没导入、截止日期未过），右下角会弹出“Canvas 上有 N 个新作业”的通知：选**导入**一次导入，选**忽略**则这些作业不再提醒，有新作业时才会再提示。

只成为待办的作业，可以在行末的菜单里选**加入成绩簿**：它成为考核，原来的待办保留并归到这个考核下。

- 成为考核时，每个 Canvas 作业组会成为一个成绩分类（课程给作业组设置了权重时带上该权重），作业的 Canvas 链接保存在备注里。
- 权重来自 Canvas 的作业组：考核的权重是所在作业组的权重乘以它在组内分值中的占比。课程没有给作业组设置权重时，权重留空，审核里由你填写。
- 在 Canvas 上已经有成绩的作业，导入时会把得分（得分 / 满分）一并带入考核。
- 每个作业在 Semestra 里只对应一项：一个考核（连同它的待办）或一个待办。
- 只导入作业组里的部分作业时，分类的权重和已导入考核的合计会不一样，剩下的可以以后再导入。

## 导入之后的变化

导入是一次性的复制，不是镜像。Semestra 会把你导入的内容与 Canvas 比较；名称或截止日期变化、有权重的考核的权重变化（包括分值变化引起的），或者考核在 Canvas 上出分、改分时，成绩页和 Canvas 页签会显示“有变化的作业”提示。
查看它会打开新的导入审核，只有提交后你的数据才会改变。

## 课程大纲

在 Canvas 页签的课程大纲视图里，可以把 Canvas 上的课程大纲交给 AI 提取。课程信息、成绩构成和截止日期会进入审核，和上传课程大纲文件一样。这需要配置
[AI 服务商](/docs/ai)。

## 文件

Canvas 文件可以保存到课程自己的文件里，保存后会建立搜索索引，也可以用于提取。
