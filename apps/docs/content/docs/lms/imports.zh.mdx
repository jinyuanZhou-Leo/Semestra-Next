---
title: 从 Canvas 导入
description: 课程、作业和 syllabus 都要先经过审核才会写入。
---

从 Canvas 导入的每一项都会在 Semestra 的导入中心打开一个审核。你确认提交之前不会写入任何数据，提交前也可以修改或去掉任意一项。

## 课程

在新建学期向导里，或在学期的**添加课程**菜单里（学期页面的命令面板里也有），选**从 LMS 导入课程**。选择 Canvas 课程（默认是当前学期的，也可以显示全部），审核后提交。
每门课程的标题取自 Canvas 课程名，代码取自 Canvas 课程代码（同时保存为别名），网址取自 Canvas 链接，并在同一步里关联到对应的 Canvas 课程。

## 作业

在课程的**成绩**页打开**添加**，在“从已有资料添加”下选择 Canvas 作业。选好作业后，逐项决定它成为**成绩册中的考核**还是**待办**。

- 导入为考核时，每个 Canvas 作业组会成为一个成绩分类（课程给作业组设置了权重时带上该权重），作业的 Canvas 链接保存在备注里。
- 权重来自 Canvas 的作业组：考核的权重是所在作业组的权重乘以它在组内分值中的占比。课程没有给作业组设置权重时，权重留空，由你填写。
- 每个作业只能导入一次，已导入的作业会从列表中消失。

<Callout title="不会导入成绩">
  导入作业时带入的是名称、截止日期和权重，不包括分值和你的得分。你在 Canvas 上的成绩可以在 Canvas 页签里看到，Sem 也能读取，但成绩册只保留你自己录入的分数。
</Callout>

## 导入之后的变化

导入是一次性的复制，不是镜像。Semestra 会把你导入的内容与 Canvas 比较；名称或截止日期变化，或者有权重的考核的权重变化（包括分值变化引起的）时，成绩页和 Canvas 页签会显示“有变化的作业”提示。
查看它会打开新的导入审核，只有提交后你的数据才会改变。

## Syllabus

在 Canvas 页签的 syllabus 视图里，可以把 Canvas 上的 syllabus 交给 AI 提取。课程信息、成绩构成和截止日期会进入审核，和上传 syllabus 文件一样。这需要配置
[AI 服务商](/docs/ai)。

## 文件

Canvas 文件可以保存到课程自己的文件里，保存后会建立搜索索引，也可以用于提取。
