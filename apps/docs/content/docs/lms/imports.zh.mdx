从 LMS 导入的内容都会先经过审核，你确认之后才会写入。导入之后，它们会通过[自动同步](./index.mdx#自动同步)跟随 Canvas 更新。

## 导入课程

新建学期时，或在学期里添加课程时，选择**从 LMS 导入课程**，再选要导入的 Canvas 课程。课程的名称、代码和网址取自 Canvas，并自动关联到对应的 Canvas 课程。

## 导入作业

在课程的成绩册里添加考核时选择 Canvas 作业，或者在 Canvas 标签页的**作业与成绩**里勾选作业后选择**导入**。

- 有分值的作业默认加入成绩册，成为考核；没有分值的作业成为待办。审核时可以改。
- 作业会自动归入课程已有的成绩分类，例如“Term Tests”归入考试。对不上时才会新建分类，审核时可以改。
- 权重按 Canvas 作业组的权重和作业的分值算出；Canvas 没有设置权重时，在审核里自己填写。
- 在 Canvas 上已经有的成绩会一起导入。

和你手动添加的考核同名的作业，会默认绑定到那个考核：考核本身不变，之后跟随这个作业同步。想单独导入时，改选**作为新考核加入**。

只作为待办导入的作业，之后也可以随时加入成绩册。

### 绑定手动添加的考核

手动添加的考核在 Canvas 上名称不同时，可以为它选择**绑定 Canvas 作业…**。绑定后，下一次同步会补上它还没有的截止日期、权重或成绩，两边不一样的会询问你。解除绑定时考核保持原样。

## 新作业

Canvas 上新出现的作业不会自动加入，而是在侧边栏的同步状态里等你处理：选择导入就会打开审核，选择忽略则不再提醒。

## 课程大纲

在 Canvas 标签页里打开课程大纲，可以用 AI 读取其中的课程信息、成绩构成和截止日期，审核后导入，和[上传课程大纲文件](/docs/ai/imports)一样。离开这一页读取也会继续，按钮会显示进度，读完后显示“待审核”。这需要先添加[模型服务商](/docs/ai)。

## 课程资料

关联课程后，Canvas 上的文件、页面和录播链接会随同步出现在课程的[文件](/docs/files)里，并按类型放进文件夹：讲义、辅导与实验、习题与答案、往年考试、录播、阅读和课程资料，课程大纲放在最上层。

- 从名称和位置看不出或看不准类型的资料（例如名称里同时有“辅导”和“答案”），会由你设置的 AI 判断放进哪个文件夹。还没设置 AI 时会留在课程资料里，之后可以在文件页用[「整理」](/docs/files#上传与整理)把它们分好。
- 这些资料默认在打开时才从 Canvas 读取，不占用你的存储空间。它们和其他文件一样可以搜索，也能让 Sem 读取。
- 新资料的名称后面有一个圆点，打开后消失；装着新资料的文件夹也会显示。文件列表会标出资料来自 Canvas、是在线读取还是保留了本地副本，修改时间是它在 Canvas 上最后一次更新的时间。
- 资料里的扫描页默认不交给 AI 识别，以免关联课程后一次产生大量用量。需要时在文件的 **⋯** 菜单里选**重新处理**；想让同步来的资料都识别，在 Program 或课程设置 → **文件**里打开**识别同步资料中的扫描页**，已经同步的资料也会随即识别。
- Canvas 上的文件或页面更新后，这里也会跟着更新。新增、更新和删除的资料会和作业的变化一起列在侧边栏同步状态的**最近更新**里，点名称即可打开。Canvas 的通知设为**全部**时，有新资料也会通知你。
- 移动和改名由你决定，同步不会改回去。类别文件夹改了名，之后的同类资料仍会放进去；删掉的话，之后的同类资料会放在最外层。
- 你删掉的资料不会再加回来。它会列在同步状态最下面的**已移除的资料**里，选**恢复**就会重新同步回来。
- 在文件的 **⋯** 菜单里选**在 Canvas 中打开**，可以回到 Canvas 上的原文。

整个 Program 都不需要时，在 Program 设置 → **LMS** 里关闭**同步课程资料**；只改一门课，在课程设置 → **LMS** 里改。已经出现的资料会留下，但不再更新。

## 在线读取与本地副本

在线读取的资料打开时从 Canvas 读取，课程在 Canvas 上关闭后就打不开了；保留本地副本则会把文件存在这里。两种方式都会跟着 Canvas 更新。

- 整个 Program 或整门课：在 Program 或课程设置 → **LMS** 里把**资料保存方式**改成**保留本地副本**。改回**在线读取**时，副本占用的空间会释放。
- 单个文件：在文件的 **⋯** 菜单里选**保留本地副本**或**移除本地副本**。在 Canvas 标签页里把文件保存到课程文件，也会保留本地副本。
- 在 **⋯** 菜单里选**转存为我的文件**，文件就归你所有，不再随 Canvas 更新或删除。

资料在 Canvas 上被删除，或者你解除了课程关联时，保留了本地副本的资料会原地转存为你的文件，在线读取的资料则会移除，两种情况都会在同步状态里列出。解除关联前会先告诉你各有多少个。

本地副本占用你的存储空间。空间不够或文件太大时，没存下的资料仍然在线读取。Canvas 暂时连不上时，在线读取的文件会显示上次读取到的文字，并提供**重试**。
