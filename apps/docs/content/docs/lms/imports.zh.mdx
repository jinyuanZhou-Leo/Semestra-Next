title: 从 LMS 导入
description: 把 Canvas 上的课程、作业和课程大纲导入 Semestra。
---

从 LMS 导入的内容都会先经过审核，你确认之后才会写入。导入之后，它们会通过[自动同步](./index.mdx#自动同步)跟随 Canvas 更新。

## 导入课程

新建学期时，或在学期里添加课程时，选择**从 LMS 导入课程**，再选要导入的 Canvas 课程。课程的名称、代码和网址取自 Canvas，并自动关联到对应的 Canvas 课程。

## 导入作业

在课程的成绩册里添加考核时选择 Canvas 作业，或者在 Canvas 标签页的**作业与成绩**里勾选作业后选择**导入**。

- 有分值的作业默认加入成绩册，成为考核；没有分值的作业成为待办。审核时可以改。
- 作业会自动归入课程已有的成绩分类，例如“Term Tests”归入考试。对不上时才会新建分类，审核时可以改。
- 权重按 Canvas 作业组的权重和作业的分值算出；Canvas 没有设置权重时，在审核里自己填写。
- 在 Canvas 上已经有的成绩会一起导入。

和你手动添加的考核同名的作业，会默认绑定到那个考核：考核本身不变，之后跟随这个作业同步。想单独导入时，改选**作为新考核加入**。

只作为待办导入的作业，之后也可以随时加入成绩册。

### 绑定手动添加的考核

手动添加的考核在 Canvas 上名称不同时，可以为它选择**绑定 Canvas 作业…**。绑定后，下一次同步会补上它还没有的截止日期、权重或成绩，两边不一样的会询问你。解除绑定时考核保持原样。

## 新作业

Canvas 上新出现的作业不会自动加入，而是在侧边栏的同步状态里等你处理：选择导入就会打开审核，选择忽略则不再提醒。

## 课程大纲

在 Canvas 标签页里打开课程大纲，可以用 AI 读取其中的课程信息、成绩构成和截止日期，审核后导入，和[上传课程大纲文件](/docs/ai/imports)一样。离开这一页读取也会继续，按钮会显示进度，读完后显示“待审核”。这需要先添加[模型服务商](/docs/ai)。

## 课程资料

关联课程后，Canvas 上的文件、页面和录播链接会随同步出现在课程的[文件](/docs/files)里，并按类型放进文件夹：讲义、辅导与实验、习题与答案、往年考试、录播、阅读和课程资料，课程大纲放在最上层。

- 从名称和位置看不出类型的资料，会由你设置的 AI 判断放进哪个文件夹。还没设置 AI 时先放在课程资料里，设置好后下次同步会再归类一次，你已经移动过的不会再动。
- 这些资料默认在打开时才从 Canvas 读取，不占用你的存储空间。它们和其他文件一样可以搜索，也能让 Sem 读取。
- Canvas 上的文件或页面更新后，这里也会跟着更新；在 Canvas 上删掉的资料，这里也会删掉，你保存了离线副本的除外。
- 移动、改名或删除都由你决定：同步不会把它们改回去，删掉的也不会再加回来。把一类资料移到自己的文件夹后，之后的同类资料也会放到那里。
- 在文件的 **⋯** 菜单里选**在 Canvas 中打开**，可以回到 Canvas 上的原文。

不需要时，在课程设置 → **LMS** 里关闭**同步课程资料**。已经出现的资料会留下，但不再更新。

## 保存一份副本

课程在 Canvas 上关闭后，打开时读取的资料就打不开了。想一直留着，可以把它们存到本地：

- 整门课：在课程设置 → **LMS** 里把**资料保存方式**改成**保存到本地**。之后的资料也会自动保存，并且仍然跟着 Canvas 更新；在 Canvas 上删掉的，这里也会删掉。
- 单个文件：在文件的 **⋯** 菜单里选**保存离线副本**，或者在 Canvas 标签页里把文件存入课程文件。保存后这个文件就归你所有，不再跟着 Canvas 更新或删除。

保存的副本占用你的存储空间。空间不够或文件太大时，没存下的资料仍然在打开时读取。
