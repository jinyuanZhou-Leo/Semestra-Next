title: 从 LMS 导入
description: 把 Canvas 上的课程、作业和课程大纲导入 Semestra。
---

从 LMS 导入的内容都会先经过审核，你确认之后才会写入。导入之后，它们会通过[自动同步](./index.mdx#自动同步)跟随 Canvas 更新。

## 导入课程

新建学期时，或在学期里添加课程时，选择**从 LMS 导入课程**，再选要导入的 Canvas 课程。课程的名称、代码和网址取自 Canvas，并自动关联到对应的 Canvas 课程。

## 导入作业

在课程的成绩册里添加考核时选择 Canvas 作业，或者在 Canvas 标签页的**作业与成绩**里勾选作业后选择**导入**。

- 有分值的作业默认加入成绩册，成为考核；没有分值的作业成为待办。审核时可以改。
- 作业会自动归入课程已有的成绩分类，例如“Term Tests”归入考试。对不上时才会新建分类，审核时可以改。
- 权重按 Canvas 作业组的权重和作业的分值算出；Canvas 没有设置权重时，在审核里自己填写。
- 在 Canvas 上已经有的成绩会一起导入。

和你手动添加的考核同名的作业，会默认绑定到那个考核：考核本身不变，之后跟随这个作业同步。想单独导入时，改选**作为新考核加入**。

只作为待办导入的作业，之后也可以随时加入成绩册。

### 绑定手动添加的考核

手动添加的考核在 Canvas 上名称不同时，可以为它选择**绑定 Canvas 作业…**。绑定后，下一次同步会补上它还没有的截止日期、权重或成绩，两边不一样的会询问你。解除绑定时考核保持原样。

## 新作业

Canvas 上新出现的作业不会自动加入，而是在侧边栏的同步状态里等你处理：选择导入就会打开审核，选择忽略则不再提醒。

## 课程大纲

在课程成绩册里添加考核时选择 **Canvas 课程大纲**，或在 Canvas 标签页里打开课程大纲，可以用 AI 读取其中的课程信息、成绩构成和截止日期，审核后导入，和[上传课程大纲文件](/docs/ai/imports)一样。两处的按钮都是**读取大纲**；Canvas 上没有课程大纲时不会出现。离开这一页读取也会继续，两个入口都会显示进度，读完后显示“待审核”。这需要先添加[模型服务商](/docs/ai)。

## 课程资料

关联课程后，Canvas 上的文件、页面、课程大纲和录播链接会随同步出现在课程的[文件](/docs/files)里，目录和 Canvas 上一致：单元里的资料放在以单元命名的文件夹，文件页里的文件放在原来的文件夹，只由某个页面链接的文件放在以该页面命名的文件夹。作业说明、公告和日历事件里链接的课程文件也会带进来，只在这些地方出现的分别放在“作业”“公告”“日历”文件夹。跟随 Canvas 的文件夹会在文件列表里标出来源。
- 名称沿用 Canvas 上的标题，其中的斜杠显示为短横线（“Week 1/2” 显示为 “Week 1-2”）。指向网页以外地址（例如邮箱）的链接经 Canvas 打开。
- 这些资料默认在打开时才从 Canvas 读取，不占用你的存储空间。它们和其他文件一样可以搜索，也能让 Sem 读取。
- 新资料的名称后面有一个圆点，打开后消失；装着新资料的文件夹也会显示。文件列表会标出资料来自 Canvas、是从 Canvas 读取还是已保存在 Semestra，修改时间是它在 Canvas 上最后一次更新的时间。
- 资料和你自己的文件一样建立索引（扫描页也会识别），是否自动进行取决于课程设置 → **文件**里的**自动为新文件建立索引**。
- 关联后的第一次同步会把课程的资料一次带进来，资料很多的课程也一样。
- Canvas 上的文件或页面更新后，这里也会跟着更新。有的老师隐藏了文件页和页面列表，把资料都放在课程首页、课程大纲或作业说明的链接里，这些资料同样会带进来，每次同步都会更新。即使老师隐藏了这两个页面，在 Canvas 上删除或取消发布的资料也会在下一次同步时从这里移除。新增、更新和删除的资料会和作业的变化一起列在侧边栏同步状态的**最近更新**里，点名称即可打开。新资料和你自己的某个文件同名且大小相同时，会在这里标出，方便你只留一份。Canvas 的通知设为**全部**时，有新资料也会通知你。
- 移动和改名由你决定，同步不会改回去。跟随 Canvas 的文件夹改名或移动后，之后同一位置的资料仍会放进去；删掉的话，之后的资料会放在它的上一级。
- 资料在 Canvas 上换了文件夹时，这里不会自动移动。在文件页点[「整理」](/docs/files#上传与整理)可以把它移到新位置，每一项都会先给你核对。
- 你删掉的资料不会再加回来。它会列在同步状态最下面的**已移除的资料**里，选**恢复**（或标题旁的**全部恢复**一次恢复所有），下一次同步就会把它加回来；如果那时 Canvas 上已经没有它了，最近更新里会显示它已从 Canvas 删除。
- 在文件的 **⋯** 菜单里选**在 Canvas 中打开**，可以回到 Canvas 上的原文。
- Semestra 读不到某份资料时（例如老师关掉了“单元”栏目，或 Canvas 拒绝读取这份文件），不会删除它，而是列在同步状态的**未更新**里；栏目被关掉的，排在这个栏目下面。保存在 Semestra 的资料照常能打开，重新读得到后继续跟随 Canvas；从 Canvas 读取的资料暂时打不开，不需要的话可以**移除**，标题旁的**全部移除**一次移除所有这样的资料。Canvas 重新给出这些资料后，它们会自动从列表里消失。作业和公告的栏目被关掉时，已导入的作业逐项列出，未导入的作业和公告每门课各合成一行，内容保持关闭前的样子；点未导入的作业那一行可以直接导入。

所有课程都不需要时，在全局设置 → **LMS → 课程资料**里关闭**同步课程资料**；只改一门课，在课程设置 → **LMS** 里改。已经出现的资料会留下，但不再更新；不需要的话，选下方**已同步的资料**旁的**移除**，一次把它们从课程文件中删除，你单独保存的文件会保留。之后重新打开同步，它们会再同步进来。

## 保存在 Semestra

资料默认在打开时从 Canvas 读取，不占用存储空间，但在 Canvas 上删除或课程关闭后就打不开了。保存在 Semestra 的资料在这之后仍能打开。两种方式都会跟着 Canvas 更新。

- 所有课程或单门课：在全局设置 → **LMS → 课程资料**或课程设置 → **LMS** 里把**资料保存方式**改成**保存在 Semestra**。改回**从 Canvas 读取**后，下一次同步会释放占用的空间；课程在 Canvas 上打不开时，保存的资料会继续保留。
- 单个文件：在文件的 **⋯** 菜单里勾选或取消**保存在 Semestra**。在 Canvas 标签页里预览文件时也可以选**保存在 Semestra**；保存过的文件在 Canvas 标签页里直接从 Semestra 打开，打开更快。Canvas 上暂时打不开这个文件时不能取消保存，以免丢掉唯一的一份。

改动课程或全局的保存方式时，这些课程里单个文件的选择会被清除，所有资料按新的保存方式处理。

资料在 Canvas 上被删除或取消发布，或者你解除了课程关联时，保存过的资料会作为你的普通文件留在原处，从 Canvas 读取的资料则会移除，两种情况都会在同步状态里列出。解除关联前会先告诉你各有多少个。之后它在 Canvas 上重新出现时，会作为新资料再加进来；如果因此有了两份相同的文件，同步状态会标出来，方便你只留一份。只是在 Canvas 上被锁定的资料保持原样，等解锁后继续跟着更新。

保存的资料占用你的存储空间。文件列表的状态图标说明每份资料的情况：从 Canvas 读取、正在保存、已保存在 Semestra，或者本地副本还是旧版本。空间不够或文件太大时，没存下的资料仍然从 Canvas 读取，悬停图标或打开 **⋯** 菜单可以看到原因；Canvas 上有新版本而空间不够时，保留旧版本。Canvas 暂时连不上时，从 Canvas 读取的文件会显示上次读取到的文字，并提供**重试**。
