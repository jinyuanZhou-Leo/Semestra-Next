---
title: Import from your LMS
description: Bring Canvas courses, assignments and syllabi into Semestra.
---

Everything you import from your LMS goes through a review first, and nothing is saved until you
confirm. After that, it follows Canvas through [automatic sync](./index.mdx#automatic-sync).

## Import courses

When you create a term or add courses to one, choose **Import courses from LMS** and pick the Canvas
courses to bring in. Each course takes its name, code and website from Canvas and is linked to its
Canvas course.

## Import assignments

Choose Canvas assignments when adding assessments in a course's gradebook, or select assignments
under **Assignments & grades** in the Canvas tab and choose **Import**.

- Assignments worth points go into the gradebook as assessments by default, and assignments worth no
  points become tasks. You can change this in the review.
- Assignments are placed in the course's existing grade categories, so “Term Tests” goes into Exam,
  for example. A new category is created only when nothing matches, and you can change it in the
  review.
- Weights are worked out from the Canvas assignment group's weight and the assignment's points. If
  the course has no weights on Canvas, enter them in the review.
- Grades you already have on Canvas come along.

An assignment with the same name as an assessment you added yourself is bound to that assessment by
default: the assessment stays as it is and follows the assignment from then on. To import it
separately, choose **Add as a new assessment**.

An assignment imported only as a task can be added to the gradebook later.

### Bind an assessment you added yourself

If an assessment you added by hand has a different name on Canvas, choose **Bind Canvas
assignment…** for it. The next sync fills in any due date, weight or grade it doesn't have yet, and
asks about values that differ. Unbinding leaves the assessment as it is.

## New assignments

New assignments on Canvas aren't added on their own. They wait in the sync status in the sidebar:
choose to import them, which opens the review, or ignore them so you're not reminded again.

## Syllabus

Open the syllabus in the Canvas tab to have AI read its course details, grade breakdown and due
dates for you to review and import, just like [uploading a syllabus](/docs/ai/imports). This needs a
[provider](/docs/ai).

## Files

Save Canvas files to the course's files to search them and let Sem read them.
