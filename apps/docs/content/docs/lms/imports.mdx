---
title: Import from your LMS
description: Bring Canvas courses, assignments and syllabi into Semestra.
---

Everything you import from your LMS goes through a review first, and nothing is saved until you
confirm. After that, it follows Canvas through [automatic sync](./index.mdx#automatic-sync).

## Import courses

When you create a term or add courses to one, choose **Import courses from LMS** and pick the Canvas
courses to bring in. Each course takes its name, code and website from Canvas and is linked to its
Canvas course.

## Import assignments

Choose Canvas assignments when adding assessments in a course's gradebook, or select assignments
under **Assignments & grades** in the Canvas tab and choose **Import**.

- Assignments worth points go into the gradebook as assessments by default, and assignments worth no
  points become tasks. You can change this in the review.
- Assignments are placed in the course's existing grade categories, so “Term Tests” goes into Exam,
  for example. A new category is created only when nothing matches, and you can change it in the
  review.
- Weights are worked out from the Canvas assignment group's weight and the assignment's points. If
  the course has no weights on Canvas, enter them in the review.
- Grades you already have on Canvas come along.

An assignment with the same name as an assessment you added yourself is bound to that assessment by
default: the assessment stays as it is and follows the assignment from then on. To import it
separately, choose **Add as a new assessment**.

An assignment imported only as a task can be added to the gradebook later.

### Bind an assessment you added yourself

If an assessment you added by hand has a different name on Canvas, choose **Bind Canvas
assignment…** for it. The next sync fills in any due date, weight or grade it doesn't have yet, and
asks about values that differ. Unbinding leaves the assessment as it is.

## New assignments

New assignments on Canvas aren't added on their own. They wait in the sync status in the sidebar:
choose to import them, which opens the review, or ignore them so you're not reminded again.

## Syllabus

Open the syllabus in the Canvas tab to have AI read its course details, grade breakdown and due
dates for you to review and import, just like [uploading a syllabus](/docs/ai/imports). This needs a
[provider](/docs/ai). Reading carries on if you leave the page; the button shows its progress, then
“To review” once it's done.

## Course materials

Once a course is linked, its files, pages and recording links on Canvas appear in the course's
[files](/docs/files) as it syncs, in the same folders as on Canvas: a module's materials in a
folder named after the module, files in their folder from the Canvas Files page, and files that
only a page links to in a folder named after that page. Folders that follow Canvas show its name in
the Files list.
- By default, materials are read from Canvas when you open them and don't use your storage. Like
  other files, you can search them and Sem can read them.
- New materials have a dot after their name until you open them, and so do the folders they
  are in. The Files list shows each material's Canvas and whether it's read from there or saved
  in Semestra, with the time it last changed on Canvas.
- Materials are indexed like your other files, scanned pages included, as **Index new files
  automatically** in the course's **Files** settings says.
- When a file or page changes on Canvas, it changes here too. What's new, changed or deleted shows
  under **Recent updates** in the sidebar's sync status, next to assignment changes; choose a name
  to open it. With notifications for Canvas set to **All**, new materials notify you too.
- Moving and renaming are up to you: syncing never undoes them. If you rename or move a folder
  that follows Canvas, later materials of that place still go there; if you delete it, they go to
  the folder above it.
- When a material moves to another folder on Canvas, it stays where it is here. Choose
  [Organize](/docs/files#upload-and-organize) on the Files page to move it to its new place; you
  review every move first.
- A material you delete stays deleted. It's listed under **Removed materials** at the bottom of the sync
  status, where **Restore** brings it back.
- Choose **Open in Canvas** in a file's **⋯** menu to see the original on Canvas.

To turn this off for all courses, go to global settings → **LMS → Course materials** and turn off
**Bring in course materials**; for one course, change it in course settings → **LMS**. The
materials already here stay, but no longer update.

## Save materials in Semestra

Materials are read from Canvas when you open them, so they use no storage, but they can't be opened
once they are deleted on Canvas or the course closes there. Saving a material in Semestra keeps it
openable. Either way it follows Canvas: updated when it changes there.

- All courses or one course: in global settings → **LMS → Course materials** or in course
  settings → **LMS**, set **Material storage** to **Save in Semestra**. Setting it back to **Read
  from Canvas** frees the storage at the next sync; while the course can't be opened on Canvas,
  saved materials stay.
- A single file: check or uncheck **Save in Semestra** in its **⋯** menu, or choose **Save in
  Semestra** when previewing it in the Canvas tab. While Canvas can't give the file, you can't
  unsave it, so the only copy isn't lost.

When a material is deleted on Canvas, or you unlink the course, a saved one stays where it is as an
ordinary file of yours, and one read from Canvas is removed. The sync status lists either.
Unlinking tells you how many of each first.

Saved materials use your storage. If you run out of space or a file is too large, the rest are
still read from Canvas. While Canvas can't be reached, a file read from there shows the text read
last time, with **Retry**.
