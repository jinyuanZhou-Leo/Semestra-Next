---
title: 连接 Canvas
description: 把 Semestra 关联到你的 Canvas 账户、一个学业项目及其课程。
---

Semestra 通过服务商接入 LMS，目前只支持 Canvas。连接使用你自己的凭证读取 Canvas。除非你在全局设置 → **LMS → 平台权限**里开启“允许修改平台上的内容”，Semestra 不会修改 Canvas 上的任何内容；目前开启后也只会在你于 Semestra 中打开公告时，把它在 Canvas 上标为已读。

分为三层，每层设置一次：

| 层级     | 位置                                             | 内容                                       |
| -------- | ------------------------------------------------ | ------------------------------------------ |
| 连接     | 全局设置 → **LMS → LMS 连接**                    | Canvas 地址和凭证，可以有多个              |
| 学业项目  | 学业项目设置 → **LMS → LMS**                    | 这个学业项目的课程使用哪个连接            |
| 课程     | 课程设置 → **LMS → LMS**                        | 这门课程关联到哪门 Canvas 课程             |

新账户也可以在新用户引导里、创建第一个学期之前添加连接，它会成为新学业项目使用的连接，学期向导随后就能从 Canvas 导入课程。

## 1. 添加连接

<Steps>
<Step>

在 Canvas 里打开 **Account → Settings**，在 _Approved integrations_ 下选择 **New access token**。复制令牌，Canvas 只显示一次。

</Step>
<Step>

在 Semestra 里添加 LMS 连接，选择 **Canvas**，填入 Canvas 地址（例如 `https://school.instructure.com`；省略 `https://` 会自动补上）和令牌。

</Step>
<Step>

保存前 Semestra 会用 Canvas 验证令牌。令牌加密保存，之后只显示打码后的提示。修改地址时必须重新填写令牌，所以已保存的令牌永远不会发给另一个服务器。

</Step>
</Steps>

每次同步时也会检查连接。令牌被吊销或过期的连接会标记为错误，侧边栏的状态行会提示重新连接，直到你更新它。面板里待处理的项会变淡，右上角的**重新连接**按钮直接打开连接设置。

### 用学校账号登录

设置了 [`SEMESTRA_LMS_CANVAS_SIGN_IN`](/docs/self-hosting/features#canvas-学校账号登录) 的自部署实例可以不创建令牌就完成连接：添加连接时选择**学校账号**而不是 **API 令牌**，阅读风险提示，接受后继续，再按下面三步操作。是否使用请自行决定，Semestra 不承担由此带来的任何后果。

<Steps>
<Step>

填入 Canvas 地址，必须是 `https://`。

</Step>
<Step>

选择**打开 Canvas 登录**，在学校页面登录并完成验证。Semestra 看不到你的密码。

</Step>
<Step>

Canvas 最后会停在 `sso.canvaslms.com` 上一个显示“Page Not Found”的页面。这是正常的，授权码就在地址里。把完整地址复制到**登录后的地址**，再选择**验证并保存**。其中的授权码几分钟内有效，过期了就重新登录。

</Step>
</Steps>

Semestra 加密保存换到的令牌，并自动续期访问令牌，所以这个连接会一直有效，直到这次登录被结束。删除连接或更换登录时，也会尝试在 Canvas 上结束旧的登录。如果失败（例如连不上 Canvas），请自己到 Canvas 的 _Approved integrations_ 里移除 **Semestra**。在那里移除后，连接会显示错误，直到你重新登录。

这种方式使用 Canvas Android App 的 OAuth 客户端，并以该 App 的身份发起请求。Instructure 并未向第三方应用提供这种方式：它可能违反学校政策或 Canvas 条款，也可能随时失效。在这里登录还可能让手机上的 Canvas App 退出登录，反过来也一样。移动 App 不认识的 Canvas 站点（例如不少学校自建的站点）无法使用。如果不确定，请使用个人访问令牌。

## 2. 绑定学业项目

在学业项目设置里选择它的课程使用的连接。只要学业项目下还有关联的课程，绑定就不能修改或移除。

## 3. 关联课程

可以[从 Canvas 导入课程](./imports.mdx)，导入时就会建立关联；也可以在已有课程的设置 → **LMS → LMS** 里选择对应的 Canvas 课程。同一个学业项目里，一门 Canvas 课程只能关联一门课程；全年课只有一个关联。在同一处还可以立即同步这门课、更换关联的课程或解除关联。

每个关联都有一个**同步这门课**开关。关闭后，这门课程不再后台同步，它的 Canvas 日历事件也会从日历中移除；Canvas 页签和 Sem 仍然可以读取这门课程。

## 后台同步

已关联的课程在后台同步，不用打开某个页面，Semestra 也会发现 Canvas 上的变化。默认每六小时同步一次，可以在全局设置 → **LMS → 后台同步 → 检查频率**里改。打开学业项目时，半小时内没同步过的课程也会同步。可选的最短间隔由服务器决定（自部署时用 [`SEMESTRA_LMS_SYNC_MIN_INTERVAL`](/docs/self-hosting/configuration) 设置）。

- **导入的作业跟随 Canvas**：作业在 Canvas 上的名称、截止日期、权重或成绩变了，Semestra 会跟着更新，除非这个值你自己改过。两边都改过时，会问你保留哪一个。想先过目再改的类型，可以在全局设置 → **LMS → 自动更新**里关掉（名称、截止时间、权重、成绩），这类变化就会先出现在待处理里，由你选择保留或更新。
- **新作业只提醒，不自动加入**：还没导入、截止在之后的作业会出现在状态行面板的待处理里，可以**导入**或**忽略**。
- **在 Canvas 上删除的作业**：已导入的作业在 Canvas 上消失后会保留，由你决定保留还是删除。

侧边栏底部的状态行显示同步情况：上次同步的时间，或有几项等你处理。点开可以看到详情：**立即同步**、待处理的项、最近的更新，以及忽略过的作业，之后仍可导入或重新提醒。命令面板里的**同步 LMS**也一样。同步不会弹出提示，有事都显示在状态行上。

最近的更新（保留 14 天）可以**还原**，还原之后也可以**撤销还原**，前提是这是那个值最近的一次修改，并且你之后没有自己改过它。还原后的值算作你自己的：Canvas 再改它时，会问你保留哪一个。

## 关联后能得到什么

- **Canvas 页签**（插件，按账户安装）：实时读取已关联课程的公告、作业与成绩（作业、测验和成绩合在一个列表里）、单元、页面、文件和课程大纲。应用里不能直接显示的页签（如 People、Piazza）会在 Canvas 中打开。页面、公告、作业说明和课程大纲默认用 Semestra 的排版显示；选择 **Canvas 样式**可以保留 Canvas 里的颜色和排版（学校主题文件里的样式除外）。标题旁的菜单可以临时切换，默认方式在**设置 → 插件 → Canvas 页签**里修改。
- **日历**：开着“同步这门课”的课程，其 Canvas 日历事件会显示在学期日历里，带 Canvas 标记，详情里可以**在 Canvas 中打开**。作业导入后（成为考核或待办）以待办的形式出现在日历中。
- **提交后完成待办**：导入的作业在 Canvas 上显示已提交时，对应的待办自动勾掉（无论导入成待办还是考核）。每个作业只勾一次，之后取消勾选不会再被勾上。每次同步时检查。可在全局设置 → **LMS → 待办**里关闭。
- **公告卡片**，可放在课程和学期看板上。
- **Sem 和 MCP** 可以搜索和读取课程内容（见下文和 [MCP 工具](/docs/mcp/tools)）。

读取结果缓存五分钟；在 Canvas 页签里刷新会立即重新读取。Canvas 页签还会在当前浏览器里保留打开过的内容两周：再次打开时先显示上次的内容，同时在后台读取最新版本，读取期间刷新图标会转动。退出登录时会删除这些内容。

## 向 Sem 询问 Canvas 上的内容

Sem 知道哪些课程已经关联，会同时在 Canvas 和课程文件里查找。它可以：

- 一次搜索课程里的全部内容：页面（包括正文）、公告、作业、测验、讨论、课程大纲、文件名和链接；
- 读取其中任何一项的全文，包括作业的评分标准和老师的评语，或者你贴过来的 Canvas 链接；
- 列出一门课或整个学期的新动态（公告、成绩、新增或有变化的作业），以及要交和缺交的作业。

老师隐藏了课程的某一部分（例如页面或文件列表）时，Sem 仍会读取放在单元里的页面和文件，并说明哪些部分看不到。Sem 带进应用的内容（作业、课程、变更、大纲里的评分方案）都要先经过你审核的导入。

## 自建的 Canvas

位于内网或使用纯 `http://` 的 Canvas 服务器，需要 `SEMESTRA_ALLOW_PRIVATE_EGRESS=true`（自部署 compose 文件的默认值）。托管版只能使用公网的 `https://` 地址。

## 尚不支持

不会读取 New Quizzes 和讨论的 checkpoints。
