---
title: 连接 Canvas
description: 把 Semestra 关联到你的 Canvas 账户、一个学业项目及其课程。
---

Semestra 通过服务商接入学习平台，目前只支持 Canvas。连接使用你自己的凭证读取 Canvas；Semestra 从不向 Canvas 写入任何内容。

分为三层，每层设置一次：

| 层级     | 位置                                             | 内容                                       |
| -------- | ------------------------------------------------ | ------------------------------------------ |
| 连接     | 账户设置 → **集成 → LMS 连接**                   | Canvas 地址和凭证，可以有多个              |
| 学业项目  | 学业项目设置 → **集成 → LMS**                    | 这个学业项目的课程使用哪个连接            |
| 课程     | 课程设置 → **集成 → LMS**                        | 这门课程关联到哪门 Canvas 课程             |

## 1. 添加连接

<Steps>
<Step>

在 Canvas 里打开 **Account → Settings**，在 _Approved integrations_ 下选择 **New access token**。复制令牌，Canvas 只显示一次。

</Step>
<Step>

在 Semestra 里添加 LMS 连接，选择 **Canvas**，填入 Canvas 地址（例如 `https://school.instructure.com`；省略 `https://` 会自动补上）和令牌。

</Step>
<Step>

保存前 Semestra 会用 Canvas 验证令牌。令牌加密保存，之后只显示打码后的提示。修改地址时必须重新填写令牌，所以已保存的令牌永远不会发给另一个服务器。

</Step>
</Steps>

连接每六小时重新检查一次。令牌被吊销或过期的连接会标记为错误，直到你更新它。

### 用学校账号登录

设置了 [`SEMESTRA_LMS_CANVAS_SIGN_IN`](/docs/self-hosting/configuration#canvas) 的自部署实例可以不创建令牌就完成连接：添加连接时选择**学校账号**而不是 **API 令牌**，再按下面三步操作。

<Steps>
<Step>

填入 Canvas 地址，必须是 `https://`。

</Step>
<Step>

选择**打开 Canvas 登录**，在学校页面登录并完成验证。Semestra 看不到你的密码。

</Step>
<Step>

Canvas 最后会停在 `sso.canvaslms.com` 的页面。把完整地址复制到**登录后的地址**，再选择**验证并保存**。其中的授权码几分钟内有效，过期了就重新登录。

</Step>
</Steps>

Semestra 加密保存换到的令牌，并自动续期访问令牌，所以这个连接会一直有效，直到登录被终止。删除连接或更换登录时，也会尝试在 Canvas 上终止旧的登录。如果失败（例如连不上 Canvas），请自己到 Canvas 的 _Approved integrations_ 里移除 **Semestra**。在那里移除后，连接会显示错误，直到你重新登录。

这种方式使用 Canvas Android App 的 OAuth 客户端，并以该 App 的身份发起请求。Instructure 并未向第三方应用提供这种方式：它可能违反学校政策或 Canvas 条款，也可能随时失效。在这里登录还可能让手机上的 Canvas App 退出登录，反过来也一样。移动 App 不认识的 Canvas 站点（例如不少学校自建的站点）无法使用。如果不确定，请使用个人访问令牌。

## 2. 绑定学业项目

在学业项目设置里选择它的课程使用的连接。只要学业项目下还有关联的课程，绑定就不能修改或移除。

## 3. 关联课程

可以[从 Canvas 导入课程](./imports.mdx)，导入时就会建立关联；也可以在已有课程的设置 → **集成 → LMS** 里点开课程列表，搜索课程代码或名称，选中即关联。课程代码对得上的 Canvas 课程会排在最上面的**建议**里；往期课程默认不列出，勾选列表底部的**包括往期课程**即可。同一个学业项目里，一门 Canvas 课程只能关联一门课程，已被别的课程关联的会显示为不可选。全年课只有一个关联。

关联后，这门课程显示为一行：Canvas 课程、学期与所用连接、状态和上次刷新时间。行末的 **⋯** 菜单里有**刷新课程信息**（重新读取 Canvas 上的课程代码、名称、学期和网址，不影响作业和日历）、**更换课程…**（会先确认）和**解除关联…**。读不到这门课时，下面会说明原因；如果是令牌失效或没有权限，可以直接打开 LMS 连接去更新。

每个关联都有一个**日历与作业变化**开关。关闭后，这门课程的 Canvas 截止日期会从日历中移除，也不再检测作业变化；Canvas 页签和 Sem 仍然可以读取这门课程。

## 关联后能得到什么

- **Canvas 页签**（插件，按账户安装）：实时读取已关联课程的公告、作业、单元、页面、文件、测验、成绩和课程大纲。文件会列出大小和更新时间，可以按名称、大小或时间排序。应用里不能直接显示的页签（People、Piazza 等外部工具）列在课程菜单的**在 Canvas 中打开**下，点开会在新标签页打开 Canvas。
- **日历**：开着「日历与作业变化」的课程，其作业截止日期和 Canvas 日历事件会显示在学期日历里。已经导入的作业不会重复显示。
- **公告卡片**，可放在课程和学期看板上。
- **Sem 和 MCP** 可以读取同样的数据（见 [MCP 工具](/docs/mcp/tools)）。

读取结果缓存五分钟。Canvas 页签会显示这门课上次读取的时间：窗口较宽时在课程菜单底部，较窄时在菜单下拉框旁边；旁边的刷新按钮会跳过缓存。

## 自建的 Canvas

位于内网或使用纯 `http://` 的 Canvas 服务器，需要 `SEMESTRA_ALLOW_PRIVATE_EGRESS=true`（自部署 compose 文件的默认值）。托管版只能使用公网的 `https://` 地址。

## 尚不支持

不会读取 New Quizzes 和讨论的 checkpoints。
