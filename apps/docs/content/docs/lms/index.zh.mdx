---
title: 连接 LMS
description: 连接学校的 Canvas，让课程、作业和成绩自动保持同步。
---

连接学校的 LMS 后，可以直接导入课程和作业，Canvas 上的成绩和截止日期变了，Semestra 也会跟着更新。目前支持 Canvas。

Semestra 只读取 Canvas 上的内容，不会修改它。只有在全局设置 → **LMS → 常规**里打开**允许修改平台上的内容**后，才会把你在 Semestra 里看过的公告在 Canvas 上标为已读。

## 1. 添加连接

<Steps>
<Step>

在 Canvas 里打开 **Account → Settings**，在 _Approved integrations_ 下选择 **New access token**，复制生成的令牌。Canvas 只显示它一次。

</Step>
<Step>

在全局设置 → **LMS** 里添加连接，选择 **Canvas**，填入学校 Canvas 的地址（例如 `https://school.instructure.com`）和刚才复制的访问令牌。保存前 Semestra 会先检查它能否使用。

</Step>
<Step>

选择课程资料的同步方式：是否把 Canvas 上的课件放进课程文件，以及从 Canvas 读取还是保存在 Semestra（见[课程资料](/docs/lms/imports#课程资料)）。关联课程后的第一次同步就会按此进行，之后也可以在设置里修改。

</Step>
</Steps>

访问令牌加密保存。令牌过期或被撤销时，侧边栏和课程设置都会提示你重新连接。

新用户也可以在新用户引导里添加连接并选好课程资料的同步方式，之后就能在新建学期时从 Canvas 导入课程。

### 用学校账号登录

有些自部署的 Semestra 允许用学校账号登录 Canvas，不用创建令牌。添加连接时选择**学校账号**，填写 Canvas 地址，在学校页面登录后，把最后停留页面的完整地址粘贴回来即可。最后那个页面显示“Page Not Found”是正常的。

<Callout type="warn">
  这种登录方式不是 Canvas 为第三方应用提供的，可能违反学校规定，也可能随时失效，还可能让手机上的 Canvas App 退出登录。是否使用由你自己决定；不确定时，请使用访问令牌。
</Callout>

管理员如何开启这种方式，见[自部署 → 可选功能](/docs/self-hosting/features#canvas-学校账号登录)。

## 2. 为 Program 选择连接

在 Program 设置 → **LMS** 里，选择这个 Program 的课程使用哪个连接。

## 3. 关联课程

[从 Canvas 导入课程](./imports.mdx)时会自动关联。已有的课程可以在课程设置 → **LMS** 里选择对应的 Canvas 课程；选择之前，可以先在下面为这门课单独设置课程资料。

不想同步某门课时，关闭它的**同步这门课**。关闭后这门课不再自动更新，Canvas 的日历事件也不再显示，但仍然可以在 Canvas 标签页和 Sem 里查看它的内容。

## 自动同步

已关联的课程会在后台定期同步，不用打开任何页面。同步的频率可以在全局设置 → **LMS → 常规**里修改，也可以随时**立即同步**。同步相关的设置都在全局设置 → **LMS** 里；课程资料的设置可以在课程设置 → **LMS** 里为单门课另行调整。

- **导入的作业跟随 Canvas**：Canvas 上的名称、截止日期、权重或成绩变了，Semestra 会跟着更新；Canvas 上免交的作业不计入成绩。你自己改过的值不会被覆盖；两边都改过时，会问你保留哪一个。想先过目再更新的，在全局设置 → **LMS → 作业**里关掉对应的类型。
- **新作业先问你**：Canvas 上新出现的作业不会自动加入，你可以选择导入或忽略。
- **在 Canvas 上删除的作业**：会先保留，由你决定是否删除。
- **提交后完成待办**：作业在 Canvas 上提交后，对应的待办会自动完成。
- **课程资料进入文件**：Canvas 上的文件、页面和录播链接会出现在课程的文件里，并跟着 Canvas 更新；新资料在打开前会有标记。详见[课程资料](/docs/lms/imports#课程资料)。

同步的情况显示在侧边栏底部 Canvas 名称的那一行：上次同步的时间，以及有几项在等你处理。点了**立即同步**后，进度条会显示已同步了几门课。打开后可以看到需要处理的项和最近的更新（包括课程资料的新增、更新和删除）。最近 14 天的作业更新都可以撤销。

你自己改过、和 Canvas 不一样的值会单独列出，每一项都可以一键改回 Canvas 上的值。Canvas 上超出 Semestra 范围的值（例如超过 100% 的权重）不会写入，Semestra 保留自己的值，并在这里注明超出范围；过长的名称会被截短。

同步时某一部分出了问题，只影响那一部分，其余内容照常同步，没有更新的内容都会说明：

- **未更新**：这次没能从 Canvas 读到的内容，写明原因（Canvas 无响应、无访问权限、栏目已关闭）和上次更新的时间。Semestra 保留它上次的样子，Canvas 恢复后这一行自动消失。Canvas 无响应时会较快再试，持续越久，间隔越长。
- **同步出错**：Semestra 自己没能同步的内容。修复之前每次同步都会出现；可以复制错误编号反馈问题。

有未更新的内容或同步出错时，状态行和课程设置里都会显示。只有 Canvas 账户或连接本身出了问题（例如访问令牌失效、请求过于频繁）时，这一轮同步才会提前停下。

## 作业详情

在 Semestra 里任何出现作业的地方，都可以就地打开它的作业详情：Canvas 标签页里的作业行、成绩册「提交状态」列的按钮、待办上的「作业详情」按钮、日历条目、公告里的链接、同步状态里的更新，以及通知。

作业详情包括作业说明、截止时间和提交方式、目前的状态（未提交、已提交或得分）、你交的内容，以及老师的评语和评分细则得分。在这里可以跳到它在成绩册里的考核或对应的待办；还没导入的作业可以直接加入成绩册和待办。提交仍在 Canvas 上完成，点「去 Canvas 提交」即可前往。

作业的状态在作业详情、待办、Canvas 标签页、成绩册和 Sem 的回答里都一致：已评分的作业算已评分；Canvas 标了缺交或迟交的作业，状态旁边会显示「缺交」或「迟交」；免交的显示「免交」，不带标记；纸质提交或无需提交的显示「无需在线提交」。只有 Canvas 标为缺交的作业才算缺交，过了截止日期但 Canvas 没有标记的仍算待完成，显示「已逾期」。纸质提交的作业 Semestra 无从知道你是否完成，截止前它和其他要交的作业一起留在「待完成」里，过了截止日期移到「待出分」，只显示「已过截止时间」。

作业保存在 Semestra 里，每次同步时更新，所以打开很快，Canvas 连不上时也能打开。作业在最近一次同步中没能更新，或者老师关掉了作业栏目时，详情顶部会注明显示的是什么时候保存的内容；只有提交没能读到时，会注明提交状态的更新时间。点右上角的刷新会立即同步这门课的作业；关闭了同步的课程则直接从 Canvas 重新读取。作业已经从 Canvas 上删除时，详情会说明它已不在 Canvas 上。

## 关联之后还能做什么

- **Canvas 标签页**：在 Semestra 里直接查看课程的公告、作业与成绩、单元、页面、文件和课程大纲。默认用更易读的排版显示，也可以切换成 Canvas 原本的样式。
- **Canvas 卡片**：「Canvas 快速入口」卡片把 Canvas 标签页里的公告、单元、作业与成绩等放在课程概览上，点一下直接打开；放在学期概览上时，每门关联的课程占一行。「Canvas 单项入口」卡片只放一项，可以在卡片设置里选择打开哪一项，或回到上次看到的位置。有未读公告时，公告图标上有标记。
- **课程链接**：课程概览的课程信息卡片会列出这门课在其他网站上使用的工具，例如 Piazza、Gradescope，和 Canvas 课程菜单里的一致。
- **成绩册里的作业与反馈**：来自 Canvas 的考核在「提交状态」列里都有按钮，点开在作业详情里查看；有老师评语或评分细则得分的，按钮换成「查看反馈」，直接打开反馈。Canvas 标签页里，鼠标停在作业行上时作业名称会加下划线，点整行即可打开。反馈保存在 Semestra 里，课程在 Canvas 上关闭后仍可查看；有新评语时，会出现在同步状态的「最近更新」里，也会发通知。解除考核的绑定或解除课程的关联后，作业内容和反馈会保留下来，但不再更新，打开时会注明。
- **日历**：Canvas 的日历事件会显示在学期日历里，包括只给你所在 Section 的事件。它们随同步保存在 Semestra 里，Canvas 暂时连不上时日历照常显示。日历尚未同步或无法读取的课程，会在日历筛选面板中显示数量；同步状态的**未更新**里逐门列出原因。Canvas 的日历事件不会发提醒。
- **公告**：每门关联的课程都有「公告」页，学期也有一个，汇总本学期所有课程的公告，可以按课程筛选。未读的公告有标记，页面标签上显示未读数量。公告保存在 Semestra 里，Canvas 连不上时也能阅读。公告里指向课程文件、作业和页面的链接直接在 Semestra 里打开。课程文件里有的附件在文件预览中打开，其余的在新标签页打开，不用跳到 Canvas。公告的显示方式在全局设置 → **LMS → 常规**里选择。打开了**允许修改平台上的内容**时，两边的已读状态互相同步。也可以在命令面板（⌘K，Windows 上是 Ctrl + K）里搜索公告。
- **公告卡片**：把最新公告放在课程或学期的概览上，未读的有标记，点一条就在「公告」页打开阅读。
- **问 Sem**：Sem 能搜索和阅读课程在 Canvas 上的全部内容，包括作业要求、评分标准和老师的评语，也能告诉你最近有什么新公告、新成绩和要交的作业。已经在课程文件里的文件和页面，Sem 直接从课程文件读取，回答里像引用其他课程文件一样标出出处。保存在 Semestra 里的作业、公告和反馈，Canvas 连不上时 Sem 也能读到。Sem 带进来的内容都要经过你审核才会导入。

## 尚不支持

暂时不能读取 New Quizzes 和讨论的阶段截止（checkpoints）。
