---
title: 连接 LMS
description: 连接学校的 Canvas，让课程、作业和成绩自动保持同步。
---

连接学校的 LMS 后，可以直接导入课程和作业，Canvas 上的成绩和截止日期变了，Semestra 也会跟着更新。目前支持 Canvas。

Semestra 只读取 Canvas 上的内容，不会修改它。只有在全局设置 → **LMS → 平台权限**里打开**允许修改平台上的内容**后，才会把你在 Semestra 里看过的公告在 Canvas 上标为已读。

## 1. 添加连接

<Steps>
<Step>

在 Canvas 里打开 **Account → Settings**，在 _Approved integrations_ 下选择 **New access token**，复制生成的令牌。Canvas 只显示它一次。

</Step>
<Step>

在全局设置 → **LMS** 里添加连接，选择 **Canvas**，填入学校 Canvas 的地址（例如 `https://school.instructure.com`）和刚才复制的访问令牌。保存前 Semestra 会先检查它能否使用。

</Step>
</Steps>

访问令牌加密保存。令牌过期或被撤销时，侧边栏会提示你重新连接。

新用户也可以在新用户引导里添加连接，之后就能在新建学期时从 Canvas 导入课程。

### 用学校账号登录

有些自部署的 Semestra 允许用学校账号登录 Canvas，不用创建令牌。添加连接时选择**学校账号**，填写 Canvas 地址，在学校页面登录后，把最后停留页面的完整地址粘贴回来即可。最后那个页面显示“Page Not Found”是正常的。

<Callout type="warn">
  这种登录方式不是 Canvas 为第三方应用提供的，可能违反学校规定，也可能随时失效，还可能让手机上的 Canvas App 退出登录。是否使用由你自己决定；不确定时，请使用访问令牌。
</Callout>

管理员如何开启这种方式，见[自部署 → 可选功能](/docs/self-hosting/features#canvas-学校账号登录)。

## 2. 为 Program 选择连接

在 Program 设置 → **LMS** 里，选择这个 Program 的课程使用哪个连接。

## 3. 关联课程

[从 Canvas 导入课程](./imports.mdx)时会自动关联。已有的课程可以在课程设置 → **LMS** 里选择对应的 Canvas 课程。

不想同步某门课时，关闭它的**同步这门课**。关闭后这门课不再自动更新，Canvas 的日历事件也不再显示，但仍然可以在 Canvas 标签页和 Sem 里查看它的内容。

## 自动同步

已关联的课程会在后台定期同步，不用打开任何页面。同步的频率可以在全局设置 → **LMS → 后台同步**里修改，也可以随时**立即同步**。

- **导入的作业跟随 Canvas**：Canvas 上的名称、截止日期、权重或成绩变了，Semestra 会跟着更新。你自己改过的值不会被覆盖；两边都改过时，会问你保留哪一个。想先过目再更新的，在全局设置 → **LMS → 自动更新**里关掉对应的类型。
- **新作业先问你**：Canvas 上新出现的作业不会自动加入，你可以选择导入或忽略。
- **在 Canvas 上删除的作业**：会先保留，由你决定是否删除。
- **提交后完成待办**：作业在 Canvas 上提交后，对应的待办会自动完成。

同步的情况显示在侧边栏底部：上次同步的时间，或者有几项在等你处理。打开后可以看到需要处理的项和最近的更新。最近 14 天的更新都可以还原。

你自己改过、和 Canvas 不一样的值会单独列出，每一项都可以一键改回 Canvas 上的值。

## 关联之后还能做什么

- **Canvas 标签页**：在 Semestra 里直接查看课程的公告、作业与成绩、单元、页面、文件和课程大纲。默认用更易读的排版显示，也可以切换成 Canvas 原本的样式。
- **日历**：Canvas 的日历事件会显示在学期日历里。
- **公告卡片**：把最新公告放在课程或学期的页面上。
- **问 Sem**：Sem 能搜索和阅读课程在 Canvas 上的全部内容，包括作业要求、评分标准和老师的评语，也能告诉你最近有什么新公告、新成绩和要交的作业。Sem 带进来的内容都要经过你审核才会导入。

## 尚不支持

暂时不能读取 New Quizzes 和讨论的阶段截止（checkpoints）。
