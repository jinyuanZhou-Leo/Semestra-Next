Sem 是 Semestra 里的助手，需要一个能为 **Sem** 用途提供模型的 [AI 服务商](/docs/ai)。

## 批准修改

Sem 可以随意读取数据。创建或修改内容之前，它会显示一张确认卡片，你批准后才会执行。账户设置 → **AI → 权限**决定哪些修改不用询问：**每次批准**、**按模块设置**或**全部自动批准**。删除操作始终需要你批准。

## 记忆

Sem 会记住关于你的长期信息、你希望它怎样做事、你的计划，以及去哪里找东西。可以在账户设置 → **AI → 记忆**里查看和编辑。**临时对话**既不读取也不保存记忆。

## 长对话

对话快要占满模型的上下文时，Sem 会在回答前自动压缩：把较早的消息总结成摘要，最近的消息保留原文。也可以输入 `/compact` 手动压缩，后面可以写上摘要里要特别记住的内容。压缩进行时不能发送新消息。
