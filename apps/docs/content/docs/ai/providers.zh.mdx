| 类型                   | 接口地址                                           | 密钥 | 能力                                         |
| ---------------------- | -------------------------------------------------- | ---- | -------------------------------------------- |
| Anthropic              | 固定（`https://api.anthropic.com`）                | 必填 | 对话、工具调用、图片、结构化输出             |
| OpenAI                 | 固定（`https://api.openai.com/v1`）                | 必填 | 对话、工具调用、图片、结构化输出、向量       |
| Google Gemini          | 固定                                               | 必填 | 对话、工具调用、图片、结构化输出、向量       |
| OpenAI 兼容            | 必填                                               | 可选 | 自己勾选（默认：对话、工具调用）             |
| OpenAI Responses 接口  | 必填（用 OpenAI 官方时填 `https://api.openai.com/v1`） | 可选 | 自己勾选（默认：对话、工具调用、结构化输出） |
| Anthropic 兼容         | 必填                                               | 可选 | 自己勾选（默认：对话、工具调用）             |
| Ollama                 | 必填                                               | 可选 | 自己勾选（默认：对话、工具调用、结构化输出、向量） |

## 兼容接口

任何提供 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages 格式接口的服务都可以用兼容类型接入：DeepSeek、
OpenRouter、Kimi、智谱、vLLM 或 LiteLLM 网关等。Semestra 无法知道这类接口支持什么，所以能力由你自己勾选：

- **工具调用**：Sem 操作你的数据时需要。
- **图片**：让它能读取图片。
- **结构化输出**：提取时使用接口的 JSON schema 模式；不勾选时，Semestra 会要求返回 JSON 并自行校验。
- **向量**：启用文件搜索。

添加兼容接口或 Ollama 时可以填一个模型名；它会被分配给还没有模型可用的用途：Sem、读取文档和标题，勾选了图片时还有读取图片。

## 模型参数

在**模型**页，每种用途都可以覆盖温度（0 到 2）、输出 token 上限，以及支持推理的模型的推理强度（`minimal`、`low`、`medium`、`high`）。

## 内网地址

在 `SEMESTRA_ALLOW_PRIVATE_EGRESS` 为 `false` 的服务器上（托管版和直接运行的 `semestra dev`），解析到内网、回环或链路本地地址的接口地址会被拒绝，
提示“该地址指向私有网络，无法使用。”见 [Ollama](./ollama.mdx)。
