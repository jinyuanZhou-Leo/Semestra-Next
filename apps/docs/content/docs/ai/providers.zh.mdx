## 兼容接口

DeepSeek、OpenRouter、Kimi、智谱等服务，以及自己搭建的 vLLM、LiteLLM 网关，都可以用兼容类型添加。常见服务的接口地址和模型已经预先填好，只需填写 API 密钥。

Semestra 无法自动知道这类服务支持什么，所以需要你勾选它的能力：

- **调用工具**：Sem 修改你的数据时需要。
- **读取图片**：读取课表截图和扫描件。
- **按格式输出**：让导入的结果更稳定。不支持时也能导入。
- **文件搜索**：在文件里按意思搜索。

添加时可以顺便填一个模型名，还没有模型可用的用途会自动使用它。

## 调整模型

在 **AI → 模型**的**高级**里，可以限制每种用途单次最多输出多少。很长的课程大纲读不完整时，调高“读取文档”的上限。

## 请求太频繁时

Semestra 同时发给一个服务商的请求有上限，其余的会排队。服务商经常提示请求过于频繁时，在编辑服务商的**高级**里调低**最多同时请求数**。后台的导入和建立索引遇到限流会自动等待后重试。
