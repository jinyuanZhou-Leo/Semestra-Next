---
title: Ollama
description: Use models running on your own computer or server.
---

With [Ollama](https://ollama.com) you can run models on your own computer or server, with no API key
and no usage fees. In **AI → Providers**, add **Ollama** and enter its address, for example
`http://192.168.1.20:11434`.

## Which address to enter

The address is reached by the Semestra server, not by your browser:

- **Hosted version**: only an Ollama reachable at a public address works.
- **Self-hosted**: a LAN address works too. If Semestra runs in Docker on the same machine as
  Ollama, `localhost` means the container itself, so enter the machine's LAN address instead, or
  use the bundled Ollama container below.
- **Ollama on another machine**: start it with `OLLAMA_HOST=0.0.0.0` so it accepts connections from
  other machines, then enter that machine's address.

## Choose a model's capabilities

Ollama is set up for chat, tools, structured output and file search. Turn off **Use tools** if your
model doesn't support it, and turn on **Read images** only for a model that understands images.

## The bundled Ollama container

When self-hosting, the compose file can run Ollama next to Semestra:

```bash
docker compose --profile ai-local up -d
docker compose exec ollama ollama pull qwen3:8b
docker compose exec ollama ollama pull nomic-embed-text
```

Its address is then `http://ollama:11434`. You can also make it the
[instance-wide provider](/docs/self-hosting/instance-provider) so every user can use it without
setting anything up. To run Ollama on a GPU, see the Ollama documentation.
