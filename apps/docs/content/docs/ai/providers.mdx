| --------------------- | --------------------------------------- | ------------------------------------ |
| Anthropic             | API key                                 | Sem, reading documents and images    |

| Anthropic-compatible  | Base URL, API key if needed             | Depends on the service               |
| Ollama                | Address                                 | Depends on the model; see [Ollama](./ollama.mdx) |

## Compatible services

Use a compatible type for services such as DeepSeek, OpenRouter, Kimi or GLM, or your own vLLM or
LiteLLM gateway. For well-known services the address and models are filled in, so you only need
the API key.

Semestra can't tell what such a service supports, so you choose its capabilities:

- **Use tools**: needed for Sem to change your data.
- **Read images**: reads timetable screenshots and scanned pages.
- **Follow a set format**: makes imports more reliable. Imports still work without it.
- **File search**: searches your files by meaning.

You can also enter a model name when you add it; purposes that have no model yet use it.

## Adjust models

Under **Advanced** in **AI → Models**, you can limit how much each purpose writes per answer. If a
long syllabus is only partly read, raise the limit for reading documents.

## When a provider says “too many requests”

Semestra limits how many requests it sends to one provider at a time and queues the rest. If a
provider often reports too many requests, lower **Most requests at a time** under **Advanced** when
editing it. Background imports and indexing wait and retry on their own.
