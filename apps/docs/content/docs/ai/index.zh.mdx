Sem、从课程大纲和截图导入、识别扫描件，以及在文件里按意思搜索，都需要一个 AI 模型。Semestra 使用你自己添加的模型服务商（例如 Anthropic、OpenAI、Gemini 或 Ollama），费用由服务商直接向你收取，Semestra 不额外收费。

## 添加模型服务商

在全局设置 → **AI → 模型服务商**里添加。大多数服务商只需要选择类型并填入 API 密钥；保存前 Semestra 会先测试一次连接。也可以在新用户引导里添加。

支持哪些服务商、各自需要填什么，见[模型服务商类型](./providers.mdx)。

API 密钥加密保存，导出的备份里不会包含它；从备份恢复后需要重新填写。

## 选择模型

在全局设置 → **AI → 模型**里，可以为每种用途单独选择模型：

| 用途     | 用于                                   |
| -------- | -------------------------------------- |
| Sem      | 与 Sem 对话                            |
| 读取文档 | 从课程大纲中读取课程信息、截止日期和成绩构成 |
| 读取图片 | 读取课表截图                           |
| OCR      | 识别扫描版 PDF 和照片里的文字          |
| 搜索     | 在课程文件里按意思查找段落             |
| 轻量任务 | 生成对话标题和推荐问题，整理 Sem 的记忆 |

不单独选择时（**自动**），Semestra 会使用已添加服务商的推荐模型。某个用途没有可用的模型时，相关功能会提示你添加模型服务商。

## 文件索引

新添加的课程文件会立即建立索引，这时会用到 OCR 和搜索模型。想控制这部分费用，可以在 Program 或课程设置 → **文件**里关闭**自动为新文件建立索引**，需要时再为单个文件建立索引。

更换搜索模型后，已有的文件会用新模型重新建立索引，完成前搜索结果可能不完整。

## 用量与费用

全局设置 → **AI → 用量**显示各个用途用了多少，以及估算的费用。没有公开价格的模型不显示费用；Ollama 这类在自己电脑上运行的模型不产生费用。
