Sem、从课程大纲和截图导入、识别扫描件，以及在文件里按意思搜索，都需要一个 AI 模型。Semestra 使用你自己添加的模型服务商（例如 Anthropic、OpenAI、Gemini 或 Ollama），费用由服务商直接向你收取，Semestra 不额外收费。

## 添加模型服务商

在全局设置 → **AI → 模型服务商**里添加。大多数服务商只需要选择类型并填入 API 密钥；保存前 Semestra 会先测试一次连接。也可以在新用户引导里添加。

支持哪些服务商、各自需要填什么，见[模型服务商类型](./providers.mdx)。

API 密钥加密保存，导出的备份里不会包含它；从备份恢复后需要重新填写。

## 选择模型

在全局设置 → **AI → 模型**里，可以为每种用途单独选择模型：

| 用途     | 用于                                   |
| -------- | -------------------------------------- |
| Sem      | 与 Sem 对话                            |
| 读取文档 | 从课程大纲中读取课程信息、截止日期和成绩构成 |
| 读取图片 | 读取课表截图                           |
| OCR      | 识别扫描件、手写笔记和照片里的文字      |
| 搜索     | 在课程文件里按意思查找段落             |
| 轻量任务 | 生成对话标题和推荐问题，整理 Sem 的记忆 |

不单独选择时（**自动**），Semestra 会使用已添加服务商的推荐模型。某个用途没有可用的模型时，相关功能会提示你添加模型服务商。

## 文字识别

OCR 一行可以选两类模型：

- **视觉模型**：服务商的模型，能读手写、公式和图，会产生用量。手写笔记建议用它。
- **传统 OCR**：部分自托管服务器自带，在服务器上运行，不产生费用，适合印刷文字，手写识别效果有限。

打字课件上的手写批注也会被识别；图片或图形约占页面三分之一及以上的页面同样会识别。识别结果接在原有文字后面。使用视觉模型时，每个这样的页面计一次请求，插图多的课件用量也会相应增加。

之前读取过的 PDF 不会自动重新识别。OCR 一行下方会显示有多少个 PDF 是在旧版本读取的，点**重新识别**即可。

## 文件索引

新添加的课程文件会立即建立索引，这时会用到 OCR 和搜索模型。想控制这部分费用，可以在 Program 或课程设置 → **文件**里关闭**自动为新文件建立索引**，需要时再为单个文件建立索引。

更换搜索模型后，已有的文件会用新模型重新建立索引，完成前搜索结果可能不完整。

## 用量与费用

全局设置 → **AI → 用量**显示各个用途用了多少，以及估算的费用。没有公开价格的模型不显示费用；Ollama 这类在自己电脑上运行的模型不产生费用。

### 每月上限

在 **AI → 用量**顶部可以设置每月上限（美元），留空表示不限制。本月估算费用达到上限后，Semestra 会暂停在后台自动进行的 AI 工作，侧边栏显示“后台 AI 已暂停”：

- 从 LMS 同步来的文件不再识别扫描页、不再建立语义搜索索引，文件仍可按文字搜索；
- 重新建立搜索索引、Auto Dream 整理记忆、Sem 推荐问题的改写都会暂停。

你自己发起的操作不受影响：和 Sem 对话、导入、上传文件、手动重新识别都照常进行。下个月 1 日（按你所在 Program 的时区）自动恢复，暂停的工作会陆续补上；也可以随时调高或清空上限。期间未识别的扫描页可以在文件上手动重新识别。

上限按估算费用计算：没有公开价格的模型和在服务器上运行的本机模型不计入，也不会被暂停。实际费用以服务商的账单为准。
