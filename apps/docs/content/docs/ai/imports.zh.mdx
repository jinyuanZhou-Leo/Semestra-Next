---
title: 从文件导入
description: 从课程大纲、课表截图或日历文件读取课程、考核和上课时间，审核后再写入。
---

不用一项项手动录入：把课程大纲、课表截图或日历文件交给 Semestra，它会列出找到的内容，你审核后只导入保留的部分。读取课程大纲和截图需要先添加[模型服务商](./index.mdx)；日历文件（`.ics`）不需要 AI。

## 可以导入什么

| 来源                       | 导入的内容                       | 从哪里开始                           |
| -------------------------- | -------------------------------- | ------------------------------------ |
| 课程大纲                   | 成绩构成、考核、权重和截止日期   | 课程的成绩册                         |
| 日历文件或课表截图         | 每周上课时间                     | 课程的课表                           |
| 课程大纲、截图、日历文件或粘贴的文字 | 一个学期的全部课程及其内容 | 新建学期，或在学期里添加课程         |
| 课程大纲                   | 课程代码、名称、教师、学分和网站 | 课程设置 → **常规 → 从文件识别**     |

从 LMS 导入课程和作业见[从 LMS 导入](/docs/lms/imports)。

可以上传新文件，也可以直接选课程文件里已有的课程大纲。上传的课程大纲默认会同时保存到课程文件里。

## 审核后再导入

读取完成后会打开审核，在你确认之前不会写入任何内容。

- 每一项都写明会导入到哪里：成绩册、待办、课表或日历。
- 需要你核对的地方会标出来，例如读不出的日期、成绩册里已有的考核。
- 可以直接修改每一项，取消勾选的不会导入。
- 每门课程会显示导入后的权重合计，方便检查是否加起来是 100%。

“第 5 周周五”这类相对日期会按课程所在的学期推算。再次导入同一份课程大纲时，已经导入过的待办和事件不会重复添加。

关闭审核不会放弃这次导入：读取会在后台继续，下次从同一个地方打开就能回到这里。

## 日历文件

日历文件只读取目标学期内的日期，所以直接导出整个日历也能用。隔周上的课会被识别出来，中间隔着阅读周也没关系；文件里少了的那几次会记为停课。
