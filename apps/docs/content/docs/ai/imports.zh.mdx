---
title: 用 AI 从文件添加
description: 把课程大纲、课表截图或日历文件读进课程，写入前先审核。
---

AI 导入和手动添加放在一起：它读取文件，在审核界面里列出找到的内容，只写入你保留的部分。读取课程大纲
或截图需要先配置 [AI 服务商](./index.mdx)；日历文件（`.ics`）不经过 AI。

## 从哪里开始

| 位置                               | 选择                                       | 带入的内容                     |
| ---------------------------------- | ------------------------------------------ | ------------------------------ |
| 课程的**成绩**页，**添加**         | “从已有资料添加”下的 **课程大纲中的成绩构成** | 分类、考核、权重、截止日期     |
| 课程的**课表**页，**添加**         | **日历文件（ICS）** 或 **课表截图**        | 每周上课时间                   |
| 还没有上课时间的**课表**页         | **从已有资料添加**                         | 每周上课时间                   |
| 新学期向导的**从已有资料添加**     | 日历文件、课程大纲、截图或粘贴的文本       | 这个学期的课程及其内容         |
| 学期的**添加课程**菜单             | 与新学期向导相同的来源                     | 这个学期的课程及其内容         |

## 日历文件

日历文件只读取导入目标所在学期的日期（添加到学期时是这个学期，添加到课程时是学业项目的全部学期），所以日历应用的全量导出也能用。跨两个学期的课会在每个学期各成为一个每周上课时间。隔周的课按教学周识别，中间隔着阅读周也不受影响；文件里缺的那几周记为停课。

## 从文件识别课程信息

要从课程大纲填写课程代码、名称、教师、学分和网站，打开课程设置 → **常规 → 从文件识别**。会列出每个将要变化的字段及新旧值，只应用你保留的内容。

LMS 来源（Canvas 作业、Canvas 课程）也在同样的菜单里，见[从 Canvas 导入](../lms/imports.mdx)。

## 选择文件

上传新文件；如果是某门课的课程大纲，也可以直接选这门课**文件**里已有的文件。上传的课程大纲默认会同时保存到课程文件，取消勾选**同时保存到课程文件**则只用于这次导入。

选择**开始读取**。读取完成后打开审核界面，在那里提交之前不会写入任何内容。

## 审核

审核界面是一张按课程分组的表格，每一项都写明会导入到哪里（**成绩簿**、**待办**、**课表**、**日历**）。有问题的地方（例如读不出的日期、成绩簿里已有的考核）标在对应的格子上；点一行可以就地修改，取消勾选的项不会导入。每门课程的标题行显示导入后的权重合计，包括成绩簿里已有的考核。

**导入 N 项**写入勾选的内容。**放弃**会丢弃这次导入。关闭对话框不会丢弃：读取在后台继续，再次从同一个入口打开导入就会回到这次导入，也可以点状态栏里的读取任务回去。
