---
title: 用 AI 从文件添加
description: 把 syllabus、课表截图或日历文件读进课程，写入前先审核。
---

AI 导入和手动添加放在一起：它读取文件，在审核界面里列出找到的内容，只写入你保留的部分。读取 syllabus
或截图需要先配置 [AI 服务商](./index.mdx)；日历文件（`.ics`）不经过 AI。

## 从哪里开始

| 位置                               | 选择                                       | 带入的内容                     |
| ---------------------------------- | ------------------------------------------ | ------------------------------ |
| 课程的**成绩**页，**添加**         | “从已有资料添加”下的 **Syllabus 中的成绩构成** | 分类、考核、权重、截止日期     |
| 课程的**课表**页，**添加**         | **日历文件（ICS）** 或 **课表截图**        | 每周上课时间                   |
| 还没有上课时间的**课表**页         | **从已有资料添加**                         | 每周上课时间                   |
| 新学期向导的**从已有资料添加**     | 日历文件、syllabus、截图或粘贴的文本       | 这个学期的课程及其内容         |
| 学期的**添加课程**菜单             | 与新学期向导相同的来源                     | 这个学期的课程及其内容         |

## 从 syllabus 识别课程信息

课程代码、名称、教师、学分和网站在课程设置里识别：打开课程的**设置** → **常规**，在**从 syllabus 识别**一行点**选择文件…**，从这门课的文件里选一个（像大纲的排在最前），或者**上传新文件…**。文件就在原处读取，读完后列出会变化的字段和新旧值；取消勾选不要的，再点**应用**。在那之前不会改动任何内容。

LMS 来源（Canvas 作业、Canvas 课程）也在同样的菜单里，见[从 Canvas 导入](../lms/imports.mdx)。

## 选择文件

- **上传新文件**：把文件拖到框里，或点击选择。每个文件显示自己的上传进度，之后显示是否已读取。
- **从课程文件选择**（针对某门课的 syllabus 导入）：勾选这门课**文件**里已有的文件。不会重复上传；还在处理中的文件会等处理完再读取。
- **同时保存到课程文件**（默认勾选）：提交导入时，上传的 syllabus 会加入这门课的**文件**。取消勾选则只用于这次导入。

点击**开始读取**。按钮把上传和读取合成一个进度条；完成后打开审核界面，在那里提交之前不会写入任何内容。
