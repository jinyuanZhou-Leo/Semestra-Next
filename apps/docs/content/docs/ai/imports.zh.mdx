---
title: 从文件导入
description: 从课程大纲、课表截图或日历文件读取课程、考核和上课时间，审核后再写入。
---

不用一项项手动录入：把课程大纲、课表截图或日历文件交给 Semestra，它会列出找到的内容，你审核后只导入保留的部分。读取课程大纲和截图需要先添加[模型服务商](./index.mdx)；日历文件（`.ics`）不需要 AI。还不能读取时（没有服务商，或当前模型读不了图片），打开导入就会说明原因，并带你去设置里处理。服务商上次出了问题（例如密钥失效、余额不足）时也会提一句，但仍然可以开始。

## 可以导入什么

| 来源                       | 导入的内容                       | 从哪里开始                           |
| -------------------------- | -------------------------------- | ------------------------------------ |
| 课程大纲                   | 成绩构成、考核、权重和截止日期   | 课程的成绩册                         |
| 日历文件或课表截图         | 每周上课时间                     | 课程的课表                           |
| 课程大纲、截图、日历文件或粘贴的文字 | 一个学期的全部课程及其内容 | 新建学期，或在学期里添加课程         |
| 课程大纲                   | 课程代码、名称、教师、学分和网站 | 课程设置 → **常规 → 从文件识别**     |

从 LMS 导入课程和作业见[从 LMS 导入](/docs/lms/imports)。

可以上传新文件，也可以直接选课程文件里已有的课程大纲。上传的课程大纲默认会同时保存到课程文件里。

## 审核后再导入

读取完成后会打开审核，在你确认之前不会写入任何内容。

- 每一项都写明会导入到哪里：成绩册、待办、课表或日历。
- 需要你核对的地方会标出来，例如读不出的日期、成绩册里已有的考核。
- 不太确定的值下面有虚线，指上去能看到原文和页码，可以点**没问题**或**修改**。展开一项时其余要确认的值也会标出，可以一次点**都没问题**。底部的“N 项需要确认”会带你逐个查看；不看也可以直接导入。
- 可以直接修改每一项，取消勾选的不会导入。
- 每门课程会显示导入后的权重合计，方便检查是否加起来是 100%。

“第 5 周周五”这类相对日期会按课程所在的学期推算。再次导入同一份课程大纲时，已经导入过的待办和事件不会重复添加。

## 关掉也不会丢

读取时可以点**在后台继续**，或者直接关掉，读取不会停。侧边栏底部会显示进度，读完后显示“待审核”，点它就回到离开时的那一步；原来的入口也会显示“读取中”或“待审核”。读完时不会弹出任何东西打断你。只有**放弃**才会结束这次导入。

文件没能读出来时，侧边栏会一直显示“读取失败”，直到你看过为止。点开能看到原因；如果是服务商的问题，点**检查服务商**直接去处理。关掉它，这次导入就结束了。

## 日历文件

日历文件只读取目标学期内的日期，所以直接导出整个日历也能用。隔周上的课会被识别出来，中间隔着阅读周也没关系；文件里少了的那几次会记为停课。
