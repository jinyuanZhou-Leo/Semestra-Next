---
title: Ollama
description: 使用在你自己的电脑或服务器上运行的模型。
---

用 [Ollama](https://ollama.com) 可以在自己的电脑或服务器上运行模型，不需要 API 密钥，也没有用量费用。在 **AI → 模型服务商**里添加 **Ollama**，填入它的地址，例如 `http://192.168.1.20:11434`。

## 填哪个地址

这个地址是由 Semestra 服务器访问的，而不是你的浏览器：

- **托管版**：只能使用公网可以访问的 Ollama。
- **自部署**：局域网地址也可以。Semestra 在 Docker 里、Ollama 在同一台机器上时，`localhost` 指的是容器自己，请填这台机器的局域网地址，或使用下面内置的 Ollama 容器。
- **Ollama 在另一台机器上**：用 `OLLAMA_HOST=0.0.0.0` 启动它，让其他机器能连上，再填那台机器的地址。

## 选择模型的能力

Ollama 默认勾选对话、调用工具、按格式输出和文件搜索。模型不支持工具调用时取消勾选**调用工具**；只有能看懂图片的模型才勾选**读取图片**。

## 内置的 Ollama 容器

自部署时，compose 文件可以在 Semestra 旁边运行 Ollama：

```bash
docker compose --profile ai-local up -d
docker compose exec ollama ollama pull qwen3:8b
docker compose exec ollama ollama pull nomic-embed-text
```

这时它的地址是 `http://ollama:11434`。也可以把它设为[全实例模型服务商](/docs/self-hosting/instance-provider)，让每个用户不用设置就能使用。在 GPU 上运行 Ollama 请参考 Ollama 的文档。
