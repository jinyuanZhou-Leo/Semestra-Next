---
title: Adding from files with AI
description: Read a syllabus, timetable screenshot or calendar file into your courses, with a review before anything is written.
---

AI imports sit next to adding things by hand. They read a file, show what they found in a review,
and write only what you keep. Reading a syllabus or a screenshot needs an [AI provider](./index.mdx);
calendar files (`.ics`) are read without AI.

## Where to start

| Where                                       | Choose                                                   | Brings in                                  |
| ------------------------------------------- | -------------------------------------------------------- | ------------------------------------------ |
| A course's **Grades** page, **Add**          | **Syllabus grading scheme**, under From existing material | Categories, assessments, weights, due dates |
| A course's **Schedule** page, **Add**        | **Calendar file (ICS)** or **Timetable screenshot**       | Weekly meetings                            |
| An empty **Schedule** page                   | **From existing material**                               | Weekly meetings                            |
| The new-term wizard, **From existing material** | A calendar file, syllabi, a screenshot or pasted text  | The term's courses and what belongs to them |
| A term's **Add course** menu                 | The same sources as the new-term wizard                  | Courses for that term and what belongs to them |

## Course details from a syllabus

A course's code, title, instructors, credits and website are filled in from its settings: open the
course's **Settings**, **General**, and under **Read from syllabus** click **Choose file…**. Pick one
of the course's files (likely syllabi are listed first) or **Upload a file…**. The file is read
right there; a dialog then lists the fields that would change, with the old and new value. Untick
what you don't want and click **Apply**. Nothing changes before that.

LMS sources (Canvas assignments, Canvas courses) appear in the same menus; see
[Import from Canvas](../lms/imports.mdx).

## Picking the files

- **Upload new files**: drop files on the box or click it. Each file shows its own upload
  progress, then whether it has been read.
- **From course files** (syllabus imports for a course): tick files already in the course's
  **Files**. Nothing is uploaded again, and a file still being processed is read once it is
  ready.
- **Also save to the course files** (on by default): an uploaded syllabus is added to the
  course's **Files** when you commit the import. Untick it to use the file for this import only.

Click **Read**. The button shows the upload and the reading as one progress bar; when it finishes,
the review opens. Nothing is written until you commit it there.
