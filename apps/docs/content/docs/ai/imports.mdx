---
title: Adding from files with AI
description: Read a syllabus, timetable screenshot or calendar file into your courses, with a review before anything is written.
---

AI imports sit next to adding things by hand. They read a file, show what they found in a review,
and write only what you keep. Reading a syllabus or a screenshot needs an [AI provider](./index.mdx);
calendar files (`.ics`) are read without AI.

## Where to start

| Where                                       | Choose                                                   | Brings in                                  |
| ------------------------------------------- | -------------------------------------------------------- | ------------------------------------------ |
| A course's **Grades** page, **Add**          | **Syllabus grading scheme**, under From existing material | Categories, assessments, weights, due dates |
| A course's **Schedule** page, **Add**        | **Calendar file (ICS)** or **Timetable screenshot**       | Weekly meetings                            |
| An empty **Schedule** page                   | **From existing material**                               | Weekly meetings                            |
| The new-term wizard, **From existing material** | A calendar file, syllabi, a screenshot or pasted text  | The term's courses and what belongs to them |
| A term's **Add course** menu                 | The same sources as the new-term wizard                  | Courses for that term and what belongs to them |

## Course details from a file

To fill in a course's code, title, instructors, credits and website from its syllabus, open the
course's settings → **General → Read from a file**. You see each field that would change, with the
old and new value, and apply only what you keep.

LMS sources (Canvas assignments, Canvas courses) appear in the same menus; see
[Import from Canvas](../lms/imports.mdx).

## Picking the files

Upload new files, or for a course's syllabus, pick files already in its **Files**. An uploaded
syllabus is also saved to the course's files unless you untick **Also save to the course files**.

Select **Read**. When reading finishes, the review opens; nothing is written until you commit it
there. A course file that is still being processed is read once it is done; until then the import
shows **Waiting for files**.

## The review

The review is one table, grouped by course, that says where each item goes (**Gradebook**,
**To-do**, **Timetable**, **Calendar**). A problem, such as a date that could not be worked out or
an assessment already in the gradebook, is marked on the cell it concerns; select a row to change
the item in place, and untick what you do not want. Each course's heading shows what its weights
add up to with this import, counting the assessments already in its gradebook.

**Import N items** writes what is ticked. **Discard** drops the import. Closing the dialog
doesn't: reading goes on in the background, and opening the same import again (or clicking the
reading task in the status bar) brings you back to it.
