Sem, importing from syllabi and screenshots, reading scanned pages and searching your files by
meaning all need an AI model. Semestra uses providers you add yourself (such as Anthropic, OpenAI,
Gemini or Ollama). Your provider bills you directly; Semestra charges nothing extra.

## Add a provider

Add one in global settings → **AI → Providers**. Most providers need only a type and an API key;
Semestra tests the connection before saving. You can also add one during onboarding.

For the providers you can use and what each needs, see [Provider types](./providers.mdx).

API keys are stored encrypted and are never included in backups, so enter them again after
restoring one.

## Choose models

In global settings → **AI → Models**, choose a model for each purpose:

| Purpose           | Used for                                                   |
| ----------------- | ---------------------------------------------------------- |
| Sem               | Conversations with Sem                                     |
| Reading documents | Course details, deadlines and grade breakdowns from syllabi |
| Reading images    | Timetable screenshots                                      |
| OCR               | Text in scanned PDFs and photos                            |
| Search            | Finding passages in your course files by meaning           |
| Light tasks       | Conversation titles, suggested questions and tidying Sem's memory |

Leave a purpose on **Auto** to use the recommended model of a provider you added. When no model can
serve a purpose, the features that need it ask you to add a provider.

## File indexing

New course files are indexed as soon as you add them, which uses your OCR and search models. To
keep that cost down, turn off **Index new files automatically** in program or course settings →
**Files**, and index individual files when you need them.

After you change the search model, your files are indexed again with the new one; until that
finishes, search results may be incomplete.

## Usage and cost

Global settings → **AI → Usage** shows how much each purpose used and an estimated cost. Models
without a public price show no cost, and models running on your own machine, such as Ollama, cost
nothing.
