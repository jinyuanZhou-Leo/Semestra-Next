Semestra 是面向学生的学期规划工具：学业项目、学期与课程，成绩与 GPA，课表和日历，待办，课程文件，Canvas
集成，以及名为 Sem 的 AI 助手。日常功能在应用里就有说明，这份文档只讲进阶内容：自己部署实例，接入 AI
服务商、MCP 客户端和 Canvas，以及 HTTP API。

## 两种使用方式

|                  | 托管版                       | 自部署                                             |
| ---------------- | ---------------------------- | -------------------------------------------------- |
| 谁来运行         | Semestra 项目                | 你自己，用 Docker Compose                          |
| AI               | 你自己的服务商密钥（BYOK）   | 你自己的密钥，或一个全实例共用的服务商，例如 Ollama |
| 访问内网地址     | 不允许                       | 默认允许（局域网里的 Ollama、学校自建的 Canvas）   |
| 邮件             | 由服务发送                   | 配置 SMTP 或 Resend 之前打印在日志里               |

其他功能，包括 API 和 MCP，两者完全一样。
