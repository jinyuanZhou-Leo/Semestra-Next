Semestra 帮你管好整个学期：Program、学期与课程，成绩与 GPA，课表与日历，待办，课程文件，与 LMS 的同步，以及能替你查资料、改数据的 AI 助手 Sem。

“使用 Semestra”下的每一页讲一个功能能帮你做什么、怎么用。想在自己的服务器上运行 Semestra，看“自部署”；想用 API 或编写插件，看“开发者”。

## 两种使用方式

|              | 托管版                     | 自部署                                       |
| ------------ | -------------------------- | -------------------------------------------- |
| 谁来运行     | Semestra 项目              | 你自己，用 Docker Compose                    |
| AI           | 使用你自己的 API 密钥      | 你自己的 API 密钥，或整个实例共用的模型服务商 |
| 访问内网地址 | 不允许                     | 默认允许（例如局域网里的 Ollama、学校自建的 Canvas） |

其他功能两者完全一样，包括 API 和 MCP。
