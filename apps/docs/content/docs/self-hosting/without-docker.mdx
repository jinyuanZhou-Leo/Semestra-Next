---
title: Without Docker on a small VM
description: Run the API with uv and systemd on a 1 GB VM, and the web app on a static host.
---

The hosted instance runs this way on a free Google Cloud e2-micro: the API on the VM with uv and
systemd, the web app on Vercel. The scripts and the full runbook are in
[`deploy/vm`](https://github.com/jinyuanZhou-Leo/Semestra-Next/tree/main/deploy/vm) (in Chinese).
They are written for Google Cloud and Cloudflare, but the pieces carry over to any Debian VM.

## What runs where

| Piece | Where |
|---|---|
| Web app | A static host (`apps/web`, built with `VITE_API_ORIGIN` set to the API's URL; `apps/web/vercel.json` has the SPA fallback and security headers for Vercel) |
| API | `semestra serve` on `127.0.0.1:8000`, a systemd service, code in `/opt/semestra/current` |
| Data | `/var/lib/semestra`: SQLite databases and uploaded files |
| Public access | Cloudflare Tunnel to `127.0.0.1:8000` (no open ports, no IPv4 address needed) |
| Backups | Litestream replicates the databases to Google Cloud Storage; a daily timer mirrors the files |

## Web app and API on two hostnames

Keep both under one registrable domain (for example `app.example.com` and `api.example.com`),
so they are the same site and the session cookie works. Then in the API's environment:

```bash title="/etc/semestra/semestra.env"
SEMESTRA_PUBLIC_WEB_ORIGIN=https://app.example.com
SEMESTRA_PUBLIC_API_ORIGIN=https://api.example.com
SEMESTRA_CORS_ORIGINS=["https://app.example.com"]
SEMESTRA_COOKIE_DOMAIN=example.com     # the web app reads the CSRF cookie
SEMESTRA_SERVE_WEB=false
SEMESTRA_TRUSTED_PROXY_HOPS=1          # Cloudflare -> cloudflared -> the API
```

The API reads this file through a `.env` symlink in its working directory, so the service and
deploy-time commands (migrations, `semestra backup`) see the same values.

## Sizing for 1 GB of RAM

- Add 2 GB of swap (the bootstrap script does).
- `SEMESTRA_JOB_CONCURRENCY=1` and `SEMESTRA_FILES_PARSE_MEMORY_BYTES=1073741824`.
- Build the web app elsewhere; the VM only installs the locked Python dependencies.

## An IPv6-only VM

An IPv4 address is not part of Google Cloud's free tier, while IPv6 is free. Without IPv4 the VM
reaches services that have IPv6 addresses (PyPI and most AI providers) but not IPv4-only ones,
which include Canvas, GitHub and some AI providers. The runbook routes only IPv4 traffic through
Cloudflare WARP and copies the code from your machine over IAP instead of cloning it on the VM.
