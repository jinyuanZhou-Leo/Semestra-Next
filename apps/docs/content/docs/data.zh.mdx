以下操作都在**设置 → 数据**里。它们可以在应用里使用，也可以用会话或访问令牌通过 HTTP 调用；Sem 和 MCP
客户端不能使用，个人 API 令牌也不能调用。

## 导出

**导出全部数据**会在后台生成一个 `.zip` 备份，包括 Program、学期、课程、成绩、课表、待办、设置和插件数据。
打开**包含文件**会把上传的文件也一起打包。

<Callout type="warn">
  密钥不会离开服务器：AI 服务商密钥、Canvas 令牌和 API 令牌都不在备份里，恢复后需要重新填写。
</Callout>

- 每个备份可在 24 小时内下载，之后会被删除。
- 列表显示最近 5 个尚未过期的导出。

| 请求                                    | 作用                               |
| --------------------------------------- | ---------------------------------- |
| `POST /me/exports`                      | 开始导出（`include_files`）        |
| `GET /me/exports`                       | 最近的导出及其状态                 |
| `GET /me/exports/{export_id}/download`  | 下载已生成的备份                   |

## 恢复

<Steps>
<Step>

### 上传备份

把 `.zip` 拖到**从备份恢复**。服务器会检查文件，并显示其中的内容：导出时间、各类数据的数量和包含的
Program。上传的备份会保留 24 小时，直到你导入或放弃。

</Step>
<Step>

### 选择要导入的内容

- **Program**：全部，或只选其中几个。
- **合并**：把备份作为新数据添加，保留现有数据。每一行都会得到新的 id，所以同一个备份导入两次会得到两份。
- **替换**：先删除当前全部数据。需要输入 `替换我的数据`（或 `replace my data`）确认。
- **同时导入偏好与布局**：主题、语言、标签页顺序、默认布局、已安装的插件和 AI 服务商（不含密钥）。默认关闭。

</Step>
<Step>

### 导入

导入在后台进行，完成后显示导入和跳过的数量。某一项所属的内容没有导入（例如没选中的 Program 下的课程），
或数据无效时，会被跳过。导入失败时不会改动任何数据。

</Step>
</Steps>

### 限制

| 情况                                   | 结果                                                       |
| -------------------------------------- | ---------------------------------------------------------- |
| 上传大小                               | 存储配额加 50 MB；没有配额时为 1 GB 加 50 MB               |
| 备份中的文件超出配额                   | 不能合并，仍然可以替换                                     |
| 备份来自更新的版本                     | 拒绝，错误码 `portability.unsupported_version`             |
| 备份里有当前版本没有的功能的数据       | 略过这部分，其余照常导入                                   |
| 旧版 Semestra 的 JSON 备份             | 拒绝，错误码 `portability.legacy_backup`                   |

| 请求                            | 作用                                                                 |
| ------------------------------- | -------------------------------------------------------------------- |
| `POST /me/imports`              | 上传备份（multipart 字段 `file`），返回预览                          |
| `GET /me/imports/{id}`          | 状态、预览和导入结果                                                 |
| `POST /me/imports/{id}:start`   | 开始导入（`mode`、`program_ids`、`include_preferences`、`confirmation`） |
| `DELETE /me/imports/{id}`       | 放弃上传的备份                                                       |

## 删除账户

**删除账户**会永久删除账户及其中的全部数据。确认步骤：

1. 输入 `删除我的账户`（或 `delete my account`），并勾选“我已了解此操作无法撤销”。
2. 如果登录已超过 10 分钟，需要输入密码，或者重新登录后在 10 分钟内删除。没有密码的账户（邮箱验证码或
   Google 登录）需要重新登录。

账户会立即锁定：所有设备退出登录，所有令牌被吊销，无法再登录。数据（包括存储的文件）由后台任务删除，删除完成后
会给你发一封邮件。如果任务中断，服务器会在一小时内完成删除。

对应的请求是 `POST /me:delete`，字段为 `confirmation`、`acknowledged`，需要时加上 `password`。如需保留数据，请先导出备份。
