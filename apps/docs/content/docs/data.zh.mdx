这些操作都在全局设置 → **数据**里，那里也会显示你用了多少存储空间、各部分占多少。想腾出空间，可以删除不再需要的课程文件，或带附件的 Sem 对话。

## 导出

**导出全部数据**会生成一个 `.zip` 备份，包括学业项目、学期、课程、成绩、课表、待办、设置和插件数据。打开**包含文件**会把上传的文件也一起打包。每个备份可在 24 小时内下载。

<Callout type="warn">
  备份里永远不包含 AI 服务商密钥、Canvas 令牌和 API 令牌，恢复后需要重新填写。
</Callout>

## 恢复

<Steps>
<Step>

### 上传备份

把 `.zip` 拖到**从备份恢复**。导入之前可以先看到备份里有什么。

</Step>
<Step>

### 选择要导入的内容

- **学业项目**：全部，或只选其中几个。
- **合并**：把备份添加到现有数据旁边。同一个备份导入两次会得到两份。
- **替换**：先删除当前全部数据。需要输入 `替换我的数据` 确认。
- **同时导入偏好与布局**：主题、语言、页面顺序、布局、已安装的插件和 AI 服务商（不含密钥）。

</Step>
<Step>

### 导入

导入在后台进行，完成后显示导入和跳过了哪些内容。导入失败时不会改动任何数据。在状态栏停止导入同样不会改动数据，之后可以重新开始。

</Step>
</Steps>

| 情况                                   | 结果                                                       |
| -------------------------------------- | ---------------------------------------------------------- |
| 备份大小                               | 最多为存储配额加 50 MB（没有配额时为 1 GB 加 50 MB）       |
| 备份中的文件超出配额                   | 不能合并，仍然可以替换                                     |
| 备份来自更新的版本                     | 拒绝                                                       |
| 备份来自旧版本（1.x）                  | 先转换成当前格式，再照常导入                               |
| 备份里有当前版本没有的功能的数据       | 略过这部分，其余照常导入                                   |
| 旧版 Semestra 的 JSON 备份             | 拒绝                                                       |

1.x 的备份按升级到 2.0 时转换现有数据的方式转换：教学班代码相同的每周课程合并成一个教学班，每个有截止日期的考核都有对应的待办（已评分或已过截止日期的标为完成）。

## 本地模型

在自己跑 OCR 或搜索模型的自部署服务器上（见[本机 OCR](/docs/self-hosting/images#本机-ocr)），**本地模型**列出每个模型和它占用的空间，你正在用的会标出**正在使用**。在模型的 **⋯** 菜单里下载或删除。这些模型由服务器上的所有账户共用；删除后下次用到时会重新下载，如果它是你的搜索模型，在那之前文件搜索只按关键词匹配。

## 删除账户

**删除账户**会永久删除账户及其中的全部数据。输入 `删除我的账户` 并确认此操作无法撤销。如果登录已超过 10 分钟，还需要用密码、邮箱验证码或 Google 确认是你本人。

所有设备会立即退出登录，所有令牌失效。之后数据在后台删除，删除完成后你会收到一封邮件。如需保留数据，请先导出备份。

## 通过 API

导出、恢复和删除账户可以用会话或访问令牌通过 HTTP 调用，但 Sem、MCP 客户端和 API 令牌不能使用。见 API 参考里的[数据导出](/docs/api/reference/portability)和[存储](/docs/api/reference/storage)。
