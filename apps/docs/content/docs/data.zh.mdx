这些操作都在全局设置 → **数据**里。那里也会显示你用了多少存储空间；想腾出空间，可以删除不再需要的课程文件，或带附件、引用了文件的 Sem 对话。

## 备份

**导出全部数据**会生成一个 `.zip` 备份，包括 Program、学期、课程、成绩、课表、待办、设置和插件数据。打开**包含文件**会把上传的文件也一起打包。备份生成后 24 小时内可以下载。

<Callout type="warn">
  为了安全，备份不包含模型服务商的 API 密钥、LMS 的访问令牌和 API 令牌。恢复后需要重新填写。
</Callout>

## 恢复

<Steps>
<Step>

### 上传备份

把 `.zip` 拖到**从备份恢复**，先看一下备份里有什么。

</Step>
<Step>

### 选择要导入的内容

- 导入全部 Program，或只选其中几个。
- **合并**：把备份加到现有数据旁边。同一个备份导入两次会得到两份。
- **替换**：先删除当前的全部数据，需要输入 `替换我的数据` 确认。
- **同时导入偏好与布局**：主题、语言、页面顺序、布局、已安装的插件和模型服务商。

</Step>
<Step>

### 导入

导入在后台进行，完成后会列出导入和跳过了哪些内容。导入失败或被停止时，不会改动任何数据。

</Step>
</Steps>

可以恢复本版本或更早版本的备份；更新版本生成的备份需要先升级 Semestra。备份里如果有当前版本没有的功能，这部分会被跳过，其余照常导入。

## 删除账户

**删除账户**会永久删除你的账户和其中的全部数据，无法撤销。需要输入 `删除我的账户` 确认；距离上次登录较久时，还需要再验证一次身份。

确认后，所有设备会立即退出登录，数据随后在后台删除，删除完成后你会收到一封邮件。需要保留数据的话，请先导出备份。

不需要的 Program 可以在它的设置里删除，但账户里至少要保留一个 Program。

开发者可以通过 API 导出和恢复，见 [API 参考](/docs/api/reference/portability)。
