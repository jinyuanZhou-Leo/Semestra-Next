每门课程都有自己的文件，用来放课件、作业要求、课程大纲和常用链接。学期的文件页把每门课显示为一个文件夹。

## 上传与整理

- 把文件拖进来或选择上传，就会放进当前的文件夹。课程里已有同样的文件时（内容相同，或文件名和大小都相同），会先问你跳过还是仍然上传。
- 打开的文件夹和正在预览的文件会记在地址里：后退、前进或刷新都回到原处，也可以收藏这个地址。
- 文件夹之间可以用面包屑左侧的「后退」「前进」「上一级」按钮移动，后退和前进只在这个文件页走过的文件夹之间切换。快捷键：Mac 上 ⌘[ 与 ⌘]，Windows 和 Linux 上 Alt+← 与 Alt+→，上一级是 ⌥↑（Alt+↑）。
- 在文件或文件夹的「⋯」菜单里选「属性」，可以看到它的类型、大小、位置和时间。
- 可以新建文件夹、保存链接，也可以把常用的文件置顶。打开其它网站的链接（包括 PDF、公告和课程信息里的）前会先确认，信任的网站可以设为以后不再提示。
- 课程关联了 [LMS](/docs/lms) 时，那里的课程资料会自动出现在这里，可以从那里读取，也可以保存在 Semestra；新资料在打开前会有一个圆点，见[课程资料](/docs/lms/imports#课程资料)。
- 可以一次选中多个文件或文件夹，一起下载、移动或删除；也可以直接把它们拖到另一个文件夹里。多个文件会打包成一个 zip 下载；其中有文件无法从来源读取时，zip 里会附一份清单，列出没有下载到的文件。文件只能在同一门课程内移动。
- 文件多了可以点「整理」：你放在最外层的文件会放进课程里合适的文件夹，同一类的几个文件会放进一个新文件夹，这需要先添加[模型服务商](/docs/ai)；在 Canvas 上换了文件夹的课程资料会移到新位置，旧版本按类型归档的资料也能这样移到 Canvas 上的位置（在课程下一次同步之后）。Semestra 先列出每个文件要去的文件夹，你确认后才移动，核对前你自己挪过的文件会留在原处。读取时可以关掉窗口，读完后从侧边栏回来核对。也可以让 Sem 帮你整理某门课的文件，它会先列出每个文件要去的文件夹，你批准后才移动。

## 在内容里搜索

搜索会同时匹配文件夹名、文件名和文件里的文字，扫描件也能搜到。结果按文件夹、文件和文件内容分组，并标出所在的位置。选中文件夹会进入该文件夹，选中文件或段落会打开预览，并跳到对应的页面。

建立索引后，Sem 也能读取这些文件并据此回答，回答里会标出出处，点开即可看到原文。配置了搜索模型时，搜索还能找到意思相近的段落，而不只是字面相同的；没有配置时按关键词匹配。

新文件添加后会自动建立索引。不想这样时，在 Program 或课程设置 → **文件**里关闭**自动为新文件建立索引**，之后需要时再为单个文件建立索引。从 LMS 同步来的资料也遵循这个设置。

正在读取文件时，侧边栏会显示一行「处理文件」和已完成的数量。点开可以看到每个文件、所属课程和当前步骤：悬停在文件上可以停止处理，处理失败或已停止的可以重新处理；「全部停止」会停止所有正在读取和等待中的文件，之后可以用「全部重新处理」继续。未能读取的文件会一直列出，直到你看过为止。

## 预览

预览里可以按目录跳转、只在这个文件里搜索、翻页和缩放。PDF 还可以切换到识别出的文字，方便选中复制。由支持图片的模型识别的扫描页，以及 Canvas 页面里用公式编辑器插入的公式，在识别文字里会排版显示。

点标题栏里的 Sem 图标，可以在文件旁边就这份文件向 Sem 提问，边看边问，也可以从「总结要点」「解释核心概念」「出几道练习题」开始。回答里引用这份文件的地方，点一下就翻到对应的页。再次打开这份文件时，面板显示上次在这里开始的对话，换一台设备也一样；这些对话也在 Sem 的历史记录里，点「新对话」可以重新开始。和目录一样，面板打开后，之后预览其他文件时也会打开。文件读取完成后才能提问，在此之前按钮暂时不可用，提示里会说明原因。

文件处理失败时会显示原因，可以重新处理。
