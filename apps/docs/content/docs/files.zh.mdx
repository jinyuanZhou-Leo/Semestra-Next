每门课程的**文件**页存放这门课的文件和链接。学期的**文件**页把每门课显示为一个文件夹，打开后与课程文件页相同。

## 上传与整理

- 点**上传**，或把文件拖到页面上，文件会放进当前打开的文件夹；拖到某个文件夹上则放进那个文件夹。
- **新建**菜单可以建文件夹或保存链接。文件夹最多嵌套三层。
- 列表和网格两种视图都可以排序，置顶的文件始终排在最前面。

## 选择、移动和删除

- 勾选文件或文件夹前面的复选框即可多选（网格视图中把指针移到卡片上会出现复选框）。选中后，搜索框的位置会换成选择栏，可以一起**移动到…**或**删除**，点**取消选择**或按 Esc 退出。
- 单个文件或文件夹的 **⋯** 菜单里也有**移动到…**。对话框列出这门课程的整棵文件夹树，可以搜索文件夹，也可以在里面直接新建文件夹。当前所在的位置，以及文件夹自身和它下面的文件夹不能作为目标。
- 也可以直接把文件或文件夹拖到另一个文件夹上，或者拖到上方路径中的某一级。拖动已选中的项目时，所有选中的项目会一起移动。
- 文件只能在同一门课程内移动。一次移动或删除多项时，要么全部完成，要么都保持原样（例如目标文件夹里已有同名文件夹）。

## 搜索与预览

搜索框同时匹配文件名和文件内容。点击内容结果会打开预览并定位到相应页面。不能预览的文件可以下载后打开。

预览里：

- 左侧是文件的**目录**（按文中的标题生成），点击跳到对应页面；左上角的按钮可以收起或展开目录。
- 右上角的**在此文件中搜索**只搜这个文件（也可以按 Ctrl+F / ⌘F），结果在右侧列出，点击跳到对应页面并高亮查询词。按 Esc 清空搜索。
- PDF 可以在**原文**和**识别文字**之间切换。识别文字是 Semestra 从文件里读出的文字（扫描件经过识别），也是搜索和 Sem 读到的内容，可以直接选中复制。
- 底部的页码条可以翻页、输入页码跳转；PDF 还可以缩放：点按钮、直接输入百分比，或按住 Ctrl/⌘ 滚动鼠标滚轮。
- 顶部的按钮可以在新标签页打开或下载文件。

新文件会在后台处理，处理完才能搜索内容。处理失败或被停止时，文件会显示原因，**⋯** 菜单里可以**重新处理**。
