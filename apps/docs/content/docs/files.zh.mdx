每门课程都有自己的文件，用来放课件、作业要求、课程大纲和常用链接。学期的文件页把每门课显示为一个文件夹。

## 上传与整理

- 把文件拖进来或选择上传，就会放进当前的文件夹。
- 可以新建文件夹、保存链接，也可以把常用的文件置顶。
- 课程关联了 [LMS](/docs/lms) 时，那里的课程资料会自动出现在这里，见[课程资料](/docs/lms/imports#课程资料)。
- 可以一次选中多个文件或文件夹，一起下载、移动或删除；也可以直接把它们拖到另一个文件夹里。多个文件会打包成一个 zip 下载。文件只能在同一门课程内移动。

## 按周浏览

每个文件都属于学期的某一周，或者整个学期。Semestra 会根据文件名（如“Week 3”“第 5 讲”）、它在 LMS 里的位置和你的课表判断。

- 在搜索框旁选一周，就能看到那一周所有文件夹里的文件。
- 放错了周，可以在文件菜单里选**更改周次…**，也可以选中多个文件一起改。你改过的周次会保留，再次同步也不会变。
- 在课程概览里添加**本周资料**卡片，一眼看到这一周的资料。

## 在内容里搜索

搜索会同时匹配文件名和文件里的文字，扫描件也能搜到。选中一条结果会打开预览，并跳到对应的页面。

建立索引后，Sem 也能读取这些文件并据此回答，回答里会标出出处，点开即可看到原文。配置了搜索模型时，搜索还能找到意思相近的段落，而不只是字面相同的；没有配置时按关键词匹配。

新文件添加后会自动建立索引。不想这样时，在 Program 或课程设置 → **文件**里关闭**自动为新文件建立索引**，之后需要时再为单个文件建立索引。

## 预览

预览里可以按目录跳转、只在这个文件里搜索、翻页和缩放。PDF 还可以切换到识别出的文字，方便选中复制。

文件处理失败时会显示原因，可以重新处理。
