Each course has its own files for slides, assignment handouts, the syllabus and useful links. A
term's files page shows each course as a folder.

## Upload and organize

- Drag files in or upload them, and they go into the folder you have open. If the course already
  has the same file (the same contents, or the same name and size), you're asked whether to skip
  it or upload it anyway.
- The folder you have open and the file you preview are part of the page's address: back, forward
  and reload return there, and you can bookmark the address.
- Move between folders with the Back, Forward and Up one folder buttons left of the breadcrumb.
  Back and Forward step through the folders you've opened on this files page. Shortcuts: ⌘[ and ⌘]
  on Mac, Alt+← and Alt+→ on Windows and Linux; ⌥↑ (Alt+↑) goes up one folder.
- Create folders, save links, and pin the files you use most. Links to other sites, here, in PDFs,
  and in announcements and course info, ask before opening; you can stop asking for a site you trust.
- Choose Properties in the ⋯ menu of a file or folder to see its type, size, location and dates.
- When the course is linked to an [LMS](/docs/lms), its course materials appear here on their own,
  read from there or saved in Semestra, and new ones are marked with a dot until you open them;
  see [Course materials](/docs/lms/imports#course-materials).
- Select several files or folders to download, move or delete them together, or drag them onto
  another folder. Several files download as one zip; if some of them can't be read from where
  they're kept, the zip includes a list of the ones it left out. Files can only move within the
  same course.
- When files pile up, choose **Organize**. Files you added at the top level go into the course's
  folder that fits them, or a new folder for files that belong together; this needs an
  [AI provider](/docs/ai). Course materials that moved to another folder on Canvas go to their new
  place, and so do materials synced by earlier versions, which were sorted by type (after the
  course's next sync). You see where each file would go first, and nothing moves until you confirm; files you've
  moved yourself meanwhile stay put. You can close the window while it reads and come back from
  the sidebar to review. You can also ask Sem to organize a course's files: it shows you where
  each file would go and moves them only after you approve.

## Search inside files

Search matches folder names, file names and the text inside files, scanned pages included. Results
are grouped as folders, files and passages, with where each one is kept. Select a folder to open
it, or a file or passage to open the preview at that page.

Once a file is indexed, Sem can read it and answer from it, citing its sources so you can open the
original. With a search model set up, search also finds passages with a similar meaning, not just
the same words; without one, it matches keywords.

New files are indexed as soon as you add them. To change that, turn off **Index new files
automatically** in program or course settings → **Files**, and index individual files when you
need them. Materials synced from the LMS follow the same setting.

While files are being read, the sidebar shows one **Processing files** line with how many are
done. Open it to see each file with its course and current step: hover a file to stop it, or to
process it again if it failed or was stopped. **Stop all** stops every file still waiting or being
read; afterwards, **Process all again** picks them up where you left off. Files that couldn't be
read stay listed until you've looked at them.

## Preview

In the preview you can jump through the outline, search within the file, turn pages and zoom.
PDFs can also switch to their recognized text, which is easy to select and copy. Formulas on
scanned pages read by a model that reads images, and those inserted with the equation editor on
Canvas pages, are typeset in the recognized text.

Select the Sem icon in the title bar to ask Sem about the file right beside it, or start from
"Summarize", "Explain key concepts" or "Practice questions". Where an answer cites this file,
selecting the citation turns the preview to that page. Reopen the file later and the
conversation is still there; it is also in Sem's history.

If a file can't be processed, the reason is shown and you can process it again.
