Each course's **Files** page holds the course's files and links. A term's **Files** page shows each
course as a folder; opening one gives you the same page as the course's own.

## Uploading and organizing

- Choose **Upload**, or drop files onto the page, to add them to the folder that's open. Drop them
  on a folder to put them in that folder.
- The **New** menu creates a folder or saves a link. Folders nest up to three levels.
- Both the list and grid views can be sorted; pinned files always stay on top.

## Selecting, moving and deleting

- Tick the checkbox in front of files or folders to select several (in the grid, the checkbox
  appears when you point at a card). While anything is selected, the search box turns into a
  selection bar with **Move to…** and **Delete**.
- A file's or folder's **⋯** menu also has **Move to…**. The dialog shows the course's whole folder
  tree; you can search it and create a folder from there. The current location, and a folder itself
  or anything inside it, can't be picked.
- You can also drag files or folders onto another folder, or onto a level of the path above the
  list. Dragging a selected item moves the whole selection.
- Files move within the same course only. Moving or deleting several items is all or nothing:
  if one can't go (say, a folder of the same name is already there), nothing changes.

## Searching and previewing

The search box matches both file names and file contents. Opening a content result shows the
preview at that page. Files that cannot be previewed can be downloaded.

In the preview:

- The **Contents** on the left list the file's headings; click one to go to its page. The button at
  the top left shows or hides them.
- **Search this file** at the top right searches only this file (or press Ctrl+F / ⌘F). Matches
  are listed on the right; click one to go to its page with your words highlighted. Esc clears the
  search.
- PDFs switch between **Original** and **Recognized text**: the text Semestra read from the file
  (scanned pages included), which is also what search and Sem see, and which you can select and
  copy.
- The page bar at the bottom turns pages or jumps to a page number; for PDFs it also zooms: use the
  buttons, type a percentage, or hold Ctrl/⌘ and scroll.
- The buttons at the top open the file in a new tab or download it.

New files are processed in the background so their contents can be searched. If processing fails
or is stopped, the file says why, and its **⋯** menu offers **Process again**.
