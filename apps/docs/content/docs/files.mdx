Each course has its own files for slides, assignment handouts, the syllabus and useful links. A
term's files page shows each course as a folder.

## Upload and organize

- Drag files in or upload them, and they go into the folder you have open.
- Create folders, save links, and pin the files you use most.
- Select several files or folders to move or delete them together, or drag them onto another
  folder. Files can only move within the same course.

## Search inside files

Search matches both file names and the text inside files, scanned pages included. Select a result
to open the preview at that page.

Once a file is indexed, Sem can read it and answer from it, citing its sources so you can open the
original. With a search model set up, search also finds passages with a similar meaning, not just
the same words; without one, it matches keywords.

New files are indexed as soon as you add them. To change that, turn off **Index new files
automatically** in program or course settings → **Files**, and index individual files when you
need them.

## Preview

In the preview you can jump through the outline, search within the file, turn pages and zoom.
PDFs can also switch to their recognized text, which is easy to select and copy.

If a file can't be processed, the reason is shown and you can process it again.
