Each course has its own files for slides, assignment handouts, the syllabus and useful links. A
term's files page shows each course as a folder.

## Upload and organize

- Drag files in or upload them, and they go into the folder you have open.
- The folder you have open and the file you preview are part of the page's address: back, forward
  and reload return there, and you can bookmark the address.
- Create folders, save links, and pin the files you use most. Links to other sites, here, in PDFs,
  and in announcements and course info, ask before opening; you can stop asking for a site you trust.
- When the course is linked to an [LMS](/docs/lms), its course materials appear here on their own,
  each read online or kept as a local copy, and new ones are marked with a dot until you open them;
  see [Course materials](/docs/lms/imports#course-materials).
- Select several files or folders to download, move or delete them together, or drag them onto
  another folder. Several files download as one zip; if some of them can't be read from where
  they're kept, the zip includes a list of the ones it left out. Files can only move within the
  same course.
- When files pile up, choose **Organize**. Files you added at the top level go into the course's
  folder that fits them, or a new folder for files that belong together; this needs an
  [AI provider](/docs/ai). Course materials that moved to another folder on Canvas go to their new
  place. You see where each file would go first, and nothing moves until you confirm; files you've
  moved yourself meanwhile stay put. You can close the window while it reads and come back from
  the sidebar to review. You can also ask Sem to organize a course's files: it shows you where
  each file would go and moves them only after you approve.

## Search inside files

Search matches both file names and the text inside files, scanned pages included. Select a result
to open the preview at that page.

Once a file is indexed, Sem can read it and answer from it, citing its sources so you can open the
original. With a search model set up, search also finds passages with a similar meaning, not just
the same words; without one, it matches keywords.

New files are indexed as soon as you add them. To change that, turn off **Index new files
automatically** in program or course settings → **Files**, and index individual files when you
need them. Materials synced from the LMS follow the same setting.

## Preview

In the preview you can jump through the outline, search within the file, turn pages and zoom.
PDFs can also switch to their recognized text, which is easy to select and copy.

If a file can't be processed, the reason is shown and you can process it again.
