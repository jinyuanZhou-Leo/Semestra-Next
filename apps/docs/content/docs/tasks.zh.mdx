待办记录你要做的事：作业、复习计划、要去办的手续。每条待办可以有截止日期和时间、优先级、课程和标记，有截止日期的会显示在[日历](/docs/calendar)里。

## 整理待办

- **今天**、**计划中**、**已标记**、**未归类**等视图会按截止日期和状态自动归类。
- 可以新建自己的列表，选择它在整个 Program 都可见，还是只在某个学期可见。
- 在课程页里看到的是这门课的待办，在学期页里看到的是这个学期的待办。

在某个列表或课程里新建的待办会沿用它的设置，比如在**今天**里新建的默认今天截止。

有截止日期的考核会自动对应一条待办，录入分数后它就自动完成。从 [LMS](/docs/lms) 导入的作业在平台上提交后，对应的待办也会自动完成。

## 在标题里写日期、优先级和课程

新建待办时，可以把截止时间、优先级和课程直接写进标题，Semestra 会自动识别：

| 输入 | 设置 |
|---|---|
| `周五`、`明天下午5点`、`下周一 23:59`、`11月20日`、`3天后` | 截止日期和时间 |
| `!`、`!!`、`!!!` | 低、中、高优先级 |
| 课程代码，如 `APS105` | 课程 |

例如 `周五下午5点 APS105 lab 报告 !!!` 会添加“lab 报告”，周五 17:00 截止，属于 APS105，优先级为高。英文也可以：`Fri 5pm lab report !!`。

- 识别出的词会高亮显示，保存时不会写进标题。选中高亮的词可以把它保留为普通文字。
- 只写钟点时要带上下午或日期（`下午3点`、`明天3点`），单独的`3点`不会被识别。
- 课程代码只有唯一对上一门课时才会识别。
- 只有新建待办时才会识别，修改已有待办的标题不会改动它的日期。

不需要时，在 Program 设置 → **待办**里关闭**智能解析**。
