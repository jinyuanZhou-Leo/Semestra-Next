点**新待办**或列表末尾的空心圆圈，会就地打开一条新待办：标题、备注，以及截止日期、时间、优先级、课程和标记几个小块。新待办沿用所在列表的设置，在**今天**里新建的默认今天截止，在课程页里新建的属于这门课。按**回车**添加并留在这一行继续输入，按 **Esc** 放弃。

## 在标题里写日期、优先级和课程

把这些信息直接写进标题，下面的小块会随输入同步变化：

| 输入 | 设置 |
|---|---|
| `周五`、`明天下午5点`、`下周一 23:59`、`11月20日`、`3天后` | 截止日期；写了时间的话还有时间 |
| `!`、`!!`、`!!!`（全角 `！` 也可以；紧跟在汉字后面时要写两个以上，如`交作业！！`） | 低、中、高优先级 |
| 课号，如 `APS105`、`aps 105h1` | 课程 |

`周五下午5点 APS105 lab 报告 !!!` 会添加“lab 报告”，周五 17:00 截止，属于 APS105H1，优先级为高。英文也可以：`Fri 5pm lab report !!`。

- 识别出的词会加上底色，它设置的小块也会显示同样的底色。保存时这些词不会写进标题。
- 点一下带底色的词，它就保留为普通文字。
- 手动修改小块时，以手动选择的值为准。
- 日期按学业项目所在时区的今天计算。只写钟点时要带上下午或日期（`下午3点`、`明天3点`），单独的`3点`、`一点`或只写月份不会被识别。
- 课号只有唯一对上一门课时才识别：同时有 MAT135H1 和 MAT135H5 时，`MAT135` 不会被识别。在课程页里新建时课程已经确定。
- 整个标题只有一个日期时（如`明天`），按原样作为标题。
- 只有新建待办时才识别。修改已有待办的标题不会改动它的日期。
- 不需要时可以关闭：学业项目设置 → **待办 → 智能解析**。
