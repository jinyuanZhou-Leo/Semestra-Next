## 课程成绩

课程的**成绩**页列出它的考核。直接在**得分**列输入分数：`82` 或 `82%` 是百分比，`18/20` 是分数制。权重也这样输入。

每个有截止日期的考核都有一个跟随它的待办：标题、截止日期和课程取自考核，显示在日历和**待办**页里。录入分数或舍弃考核时待办自动完成，删除考核时待办一起删除。表格的**待办**列可以直接勾选完成；待办详情里显示考核的权重和成绩，并能跳回成绩册中的这一行。

表格上方可以只看**全部**、**已出分**或**未出分**的考核，也可以按名称搜索。**添加**用来新建考核，或从课程大纲、LMS 导入。**⋯** 菜单里可以按分类分组，也可以填写官方成绩。

要一次修改多个考核，勾选它们前面的复选框（表头的复选框勾选当前显示的全部行，分组视图里每个分类行勾选整组）。这时筛选的位置会换成批量操作：**分类**把它们归到同一个分类；**权重**给每项设相同的权重，或把一个总权重平均分给它们（精确到 0.01，加起来正好等于总数）；**不计入成绩**或**计入成绩**一起切换；**删除**会先确认再删除。点**取消选择**或按 Esc 恢复筛选。只有当前显示的已勾选行才会被修改，规划模式下没有复选框。

右侧：

- **成绩构成**：当前成绩与 GPA，以及每个分类的权重和平均分。
- **预测**：预测的最终成绩，每个还没出分的考核一条。每项按所在分类目前的平均分推算，并向全课平均分靠拢，分类里分数越少靠得越多，所以一两个偶然的高分或低分不会决定整个分类；还没有分数的分类按全课的平均分推算。每条上的刻度是达到目标需要的平均分。
- **目标 GPA**：从学业项目的换算表里选目标，下面显示剩余考核需要的平均分。学业项目隐藏了 GPA 时，这里叫**目标成绩**，只列出每档需要的百分比。

## 规划

**规划**可以试填分数，不会保存。没填的考核会用灰字显示预测分，输入分数就会替换它。预测卡片会变成**规划成绩**。**自动填充至目标**会填入刚好达到目标的分数，**清空假设**会清掉填过的分数，**退出规划**回到真实成绩。假设分数会保留到下次。

## 学期成绩

学期的**成绩**页列出本学期的课程，以及每门课的百分比和 GPA。可以筛选**进行中**或**已结课**的课程，也可以搜索。**未结课课程**卡片显示每门未结课课程目前的平均分。填写**目标学期 GPA** 后，会显示未结课课程需要的平均分。**规划**和课程页一样：为每门未结课的课程填上预期的最终百分比。

未结课的课程是否按当前平均分计入学期 GPA，是学业项目的设置：学业项目设置 → **成绩 → 学期成绩 → 计入未结课**。

连续上两个或更多学期的课程（如全年课）只有一个最终成绩。在课程设置 → **常规**里打开**跨学期课程**，再选开始和结束学期；结束学期还没添加时，选**下学期（尚未添加）**。
