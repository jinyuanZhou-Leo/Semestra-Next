每门课程的成绩册列出它的全部考核。录入分数后，Semestra 会算出当前成绩和 GPA，预测最终成绩，并告诉你要达到目标还需要多少分。

## 录入分数

在成绩册里直接输入分数：`82` 或 `82%` 是百分比，`18/20` 是按分数计。权重也这样输入。

考核可以手动添加，也可以从[课程大纲](/docs/ai/imports)或 [LMS](/docs/lms/imports) 导入。有截止日期的考核会自动对应一条待办，显示在日历和待办里；录入分数后，这条待办自动完成。

## 一次修改多个考核

勾选多个考核后，可以一起修改分类、权重或是否计入成绩，也可以一起删除。权重可以给每项设成一样，也可以把一个总权重平均分给它们。

## 看清成绩的走向

- **成绩构成**：当前成绩与 GPA，以及每个分类的权重和平均分。
- **预测**：根据你目前的表现推算最终成绩，并列出每个还没出分的考核大概能拿多少。分数少的分类会参考整门课的平均分，所以一次偶然的高分或低分不会左右整个分类。
- **目标 GPA**：选一个目标，看剩下的考核平均需要多少分。

## 规划剩下的成绩

打开**规划**，可以给还没出分的考核试填分数，看最终成绩会怎样变化，不会改动真实成绩。**自动填充至目标**会填入刚好达到目标的分数。试填的分数会保留到下次规划。

## 学期成绩

学期的成绩页列出本学期每门课的成绩和 GPA。填写**目标学期 GPA** 后，会显示未结课的课程平均需要多少分；**规划**可以为每门未结课的课程填上预期成绩。

未结课的课程是否按当前成绩计入学期 GPA，在 Program 设置 → **成绩**里选择（**计入未结课**）。

## 跨学期的课程

全年课这类连续上两个学期以上的课程只有一个最终成绩。在课程设置 → **常规**里打开**跨学期课程**，再选择开始和结束的学期。

## 隐藏成绩

不想一打开就看到成绩时，在 Program 设置 → **成绩**里打开**隐藏成绩**。GPA 和百分制成绩会显示为“•••”，把指针移到上面即可查看。各项考核的分数不受影响。
