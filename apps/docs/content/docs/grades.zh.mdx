## 课程成绩

课程的**成绩**页列出它的考核。直接在**得分**列输入分数：`82` 或 `82%` 是百分比，`18/20` 是分数制。权重也这样输入。

表格上方可以只看**全部**、**已出分**、**未出分**或**已逾期**的考核，也可以按名称搜索。**添加**用来新建考核，或从课程大纲、LMS 导入。**⋯** 菜单里可以按分类分组，也可以填写官方成绩。

右侧：

- **成绩构成**：当前成绩与 GPA，以及每个分类的权重和平均分。
- **预测**：预测的最终成绩，每个还没出分的考核一条。每项按所在分类目前的平均分推算；还没有分数的分类按全课的平均分推算。虚线是达到目标需要的平均分。
- **目标 GPA**：从学业项目的换算表里选目标，下面显示剩余考核需要的平均分。

## 规划

**规划**可以试填分数，不会保存。没填的考核会用灰字显示预测分，输入分数就会替换它。预测卡片会变成**规划成绩**。**自动填充至目标**会填入刚好达到目标的分数，**清空假设**会清掉填过的分数，**退出规划**回到真实成绩。假设分数会保留到下次。

## 学期成绩

学期的**成绩**页列出本学期的课程，以及每门课的百分比和 GPA。可以筛选**进行中**或**已结课**的课程，也可以搜索。**未结课课程**卡片显示每门未结课课程目前的平均分。填写**目标学期 GPA** 后，会显示未结课课程需要的平均分。**规划**和课程页一样：为每门未结课的课程填上预期的最终百分比。

未结课的课程是否按当前平均分计入学期 GPA，是学业项目的设置：学业项目设置 → **成绩 → 学期成绩 → 计入未结课**。
