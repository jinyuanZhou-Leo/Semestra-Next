Semestra keeps your whole semester in one place: programs, terms and courses, grades and GPA, your
timetable and calendar, tasks, course files, LMS sync, and Sem, an AI assistant that can look things
up and make changes for you.

Each page under “Using Semestra” covers one feature: what it does for you and how to use it. To run
Semestra on your own server, see “Running your own”. To use the API or write a plugin, see “Developers”.

## Two ways to use it

|                           | Hosted                       | Self-hosted                                                 |
| ------------------------- | ---------------------------- | ----------------------------------------------------------- |
| Who runs it               | The Semestra project         | You, with Docker Compose                                    |
| AI                        | Your own API keys            | Your own API keys, or a provider shared by the whole instance |
| Reaching private networks | Not allowed                  | Allowed by default (for example a LAN Ollama or an on-premises Canvas) |

Everything else works the same in both, including the API and MCP.
