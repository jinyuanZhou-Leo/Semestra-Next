All of this is in global settings → **Data**, which also shows how much of your storage you use
and what takes the space. To free some, delete course files you no longer need, or Sem chats with
attachments.

## Export

**Export all data** builds a `.zip` backup with your programs, terms, courses, grades, schedules,
tasks, settings and plugin data. Turn on **Include files** to add your uploaded files. Each backup
can be downloaded for 24 hours.

<Callout type="warn">
  AI provider keys, Canvas tokens and API tokens are never in a backup. Enter them again after
  restoring.
</Callout>

## Restore

<Steps>
<Step>

### Upload the backup

Drop the `.zip` on **Restore from backup**. You see what it holds before anything is imported.

</Step>
<Step>

### Choose what to import

- **Programs**: all of them, or only some.
- **Merge** adds the backup next to what you have. Importing the same backup twice gives you two
  copies.
- **Replace** deletes all your current data first. Type `replace my data` to confirm.
- **Also import preferences and layouts**: theme, language, page order, layouts, installed plugins
  and AI providers (without keys).

</Step>
<Step>

### Import

The import runs in the background and reports what it imported and skipped. If it fails, nothing
changes.

</Step>
</Steps>

| Case                                              | Result                                                                  |
| ------------------------------------------------- | ----------------------------------------------------------------------- |
| Backup size                                       | Up to your storage quota plus 50 MB (1 GB plus 50 MB without a quota)   |
| The backup's files do not fit your quota          | Merge is refused; Replace still works                                   |
| The backup comes from a newer version             | Refused                                                                 |
| It holds data of a feature this version lacks     | That data is left out; the rest imports                                 |
| A JSON backup from the old Semestra app           | Refused                                                                 |

## Local models

On a self-hosted server that runs OCR or search models itself
([Local OCR](/docs/self-hosting/images#local-ocr)), **Local models** lists each model with its
size, the ones you use marked **In use**. Download or delete a model from its **⋯** menu. Models
are shared by every account on the server; a deleted model downloads again the next time it is
needed, and until then file search only matches keywords if it was your search model.

## Delete your account

**Delete account** permanently deletes the account and everything in it. Type `delete my account`
and confirm that it cannot be undone. If you signed in more than 10 minutes ago, you also enter
your password or sign in again.

You are signed out everywhere at once, and every token stops working. The data is then deleted in
the background, and you get an email when it is gone. Export a backup first if you want to keep
anything.

## Over the API

Export, restore and account deletion work over HTTP with a session or access token, but not for
Sem, MCP clients or API tokens. See [Export, import and account deletion](/docs/api/reference/portability) and
[Storage](/docs/api/reference/storage) in the API reference.
