插件为 Semestra 添加额外的功能，大多是可以放在页面上的卡片。所有插件都由 Semestra 提供，按账户安装，安装后在所有 Program 中都可以使用。

## 安装与卸载

在**设置 → 插件**中，插件分为**已安装**和**未安装**两组，可以按名称或简介搜索。点**安装**即可添加插件；点卡片可以查看它包含哪些页面和卡片，以及插件自己的设置。

安装卡片类插件后，在页面的卡片编辑里把它添加到看板上。

要卸载，点插件右上角的 **⋯**，选择**卸载**。卸载后它的页面和卡片会消失，重新安装时会恢复；如果勾选**同时删除插件数据**，它的卡片、设置和记录会被永久删除。
