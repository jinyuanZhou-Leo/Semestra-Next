A term's calendar brings together three things: classes, events, and tasks with a due date. Times
always follow your program's time zone, so they're right wherever you are.

## Enter your weekly meetings

In a course's schedule, add meetings by section (such as LEC0101 or TUT0203). A section has a type,
a code, an instructor and the weeks it runs; each meeting has its own day, time and location. Once
they're in, every class for the term appears in the calendar, skipping holiday weeks.

- All meetings of a section run in the same weeks. If one starts later than the rest, cancel the
  classes it misses, or add it as a section of its own.
- If you change a section's code to one another section of the same type already has, saving
  merges its meetings into that section.
- Hide a meeting if you don't want it in the calendar.

You can also [import](/docs/ai/imports) meetings from a calendar file or a timetable screenshot.

## Move or cancel a class

When a class moves or is cancelled, select it in the calendar and choose **Move this class**
or **Cancel this class**. You can restore it at any time.

## Events and tasks

- Select a time in the calendar to add an event or a task.
- Check off a task to complete it, or drag it to another day to change its due date. An
  assessment's due date follows the gradebook, so change it there.
- Calendar events synced from your [LMS](/docs/lms) show here too.

Select anything in the calendar to see its details and jump to where it lives, such as the course
schedule, the assessment in the gradebook, or Canvas.

## Export

### Image or PDF

Save the week view as an image or a PDF to print or send. Choose one week, several weeks, or a
weekly timetable without dates.

### Calendar file

Download the term, or the weeks you choose, as an `.ics` file to import once into Apple Calendar,
Google Calendar or Outlook. Later changes in Semestra don't reach the imported copy; use a
subscription link to stay up to date.

### Subscription link

Each program has one read-only subscription link. Add it to your calendar app and changes in
Semestra show up on their own (calendar apps usually check every few hours). Choose whether it
includes classes and events, tasks, and your LMS calendar.

Anyone with the link can see what it includes, so add it only to your own calendars. If you shared
it by mistake, **Reset link** gives it a new address and the old one stops working; **Turn off
link** stops updates for every calendar that uses it.
