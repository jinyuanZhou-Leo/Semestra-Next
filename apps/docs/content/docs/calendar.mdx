On a term's **Calendar** page, the **Export** menu in the toolbar has three choices.

## Image or PDF

Saves the week view as a PNG or an A4 PDF, for printing or sending to someone. Pick one week, a
range of weeks, or a weekly timetable without dates; choose what to include, how cancelled
classes look, and a light or dark theme. The preview on the left shows the first page as you
change the options.

## Calendar file (.ics)

Downloads the term (or the weeks you pick) as a `.ics` file to import once into Apple Calendar,
Google Calendar or Outlook. Courses hidden in the calendar's filters are left out. Later changes
in Semestra do not reach the imported copy; use a subscription link for that.

## Subscription link

Each program has one read-only subscription link. Calendar apps check it on their own schedule
(usually every few hours), so changes in Semestra show up without doing anything.

- **Turn on** the link the first time you open it. After that it is always shown here: copy it,
  open it in your calendar app, or add it to Google Calendar.
- **Include** classes and events, assessment due dates, tasks and LMS calendar items. Changes
  apply to the same link.
- **Reset link** gives it a new address if it was shared by mistake; calendars subscribed to the
  old one stop updating and need the new link.
- **Turn off link** stops it for every calendar that uses it.

Anyone with the link can see what it includes, so share it only with calendars you own.
