title: Claude Desktop
description: Semestra 不能通过 HTTPS 访问时，用 API 令牌连接 Claude Desktop。
---

Semestra 的地址不是 HTTPS（例如部署在局域网里的自部署服务器）时，按这一页连接。地址是 HTTPS 时，请改为把 Semestra 添加为 [Claude](./claude.mdx) 连接器：登录一次，网页版、桌面版和手机版都能用。

## 在 Semestra 中连接

1. 在 Semestra 中打开设置里的 **AI**，进入 **API 与 MCP**，点 **新建连接**。
2. 选择 **Claude Desktop**，选 **只读** 或 **读写**，点 **创建 API 令牌**。
3. 下一步显示已填好令牌的配置，复制到其中注明的文件里。文件中已有其他服务器时，把 `semestra` 一项并列加入，不要覆盖整个文件。
4. 重启 Claude Desktop。Semestra 的窗口里会从“等待连接”变成“已连接”。

令牌以 Claude Desktop 命名，只在该窗口中显示一次。要断开时，在 **客户端与 API 令牌** 中撤销它。

## 手动设置

先创建 API 令牌：在 **新建连接** 中选择 **其他客户端或脚本**。把下面的 `<token>` 换成它，示例地址换成 **MCP 服务** 中显示的地址。

Claude Desktop 的配置文件只能启动本机上的程序，所以通过 [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) 连接 Semestra，需要已安装 [Node.js](https://nodejs.org) 18 或更高版本。

1. 在 Claude Desktop 的设置中进入 **开发者**，点 **编辑配置**，它会打开 `claude_desktop_config.json`：
   - macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`
   - Windows：`%APPDATA%\Claude\claude_desktop_config.json`
2. 在 `mcpServers` 下加入 `semestra`（与已有的服务器并列）：

```json
{
  "mcpServers": {
    "semestra": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://192.168.1.10:8000/mcp", "--allow-http", "--header", "Authorization:${AUTH_HEADER}"],
      "env": { "AUTH_HEADER": "Bearer <token>" }
    }
  }
}
```

3. 保存文件，完全退出 Claude Desktop 后重新打开。

`--allow-http` 让 `mcp-remote` 可以连接不是 HTTPS 的地址，只在你信任的网络里使用；地址是 HTTPS 时去掉它。令牌放在 `env` 里，请求头的冒号后不加空格，这样在 Windows 上参数不会被拆开。

## 检查连接

点输入框下方的工具按钮，列表里应出现 **semestra** 及其工具。没有出现时，到设置的 **开发者** 中查看错误日志。

## 断开

从配置文件删除 `semestra` 一项并重启。在 **客户端与 API 令牌** 中撤销对应令牌也会立即断开。
