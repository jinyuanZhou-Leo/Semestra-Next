title: Gemini CLI
description: Add Semestra to Gemini CLI with one command.
---

## Connect from Semestra

1. In Semestra, open Settings → **AI → API & MCP** and click **New connection** next to **Clients and API tokens**.
2. Choose **Gemini CLI**, pick **Read only** or **Read and write**, and click **Create token and continue**.
3. The next step shows the command with your token filled in. Copy it and run it in a terminal.

The token is created for Gemini CLI and shown only in that window. To disconnect, revoke it under **Clients and API tokens**.

## Set it up by hand

Create an API token first: Settings → **AI → API & MCP → New connection → Other client or script**. Replace `<token>` below with it, and the example address with the one shown under **MCP server**.

Run this in a terminal:

```bash
gemini mcp add --scope user --transport http semestra https://semestra.example.com/mcp \
  --header "Authorization: Bearer <token>"
```

`--scope user` writes it to `~/.gemini/settings.json`, so it works in every directory. Without it, the server goes into `.gemini/settings.json` in the current directory; do not commit a token there. Editing the file by hand works too. Note the key is `httpUrl`:

```json
{
  "mcpServers": {
    "semestra": {
      "httpUrl": "https://semestra.example.com/mcp",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

## Check the connection

In Gemini CLI, type `/mcp`. **semestra** should be connected with its tools listed.

## Disconnect

`gemini mcp remove semestra` Revoking its token under **Clients and API tokens** also cuts it off right away.
