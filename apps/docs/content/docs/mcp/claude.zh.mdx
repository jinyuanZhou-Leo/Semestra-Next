Claude 通过登录连接 Semestra，不需要 API 令牌。添加一次后，网页版、桌面版和手机版都能使用。

## 连接

1. 在 Semestra 中打开设置里的 **AI**，进入 **API 与 MCP**，点 **新建连接**，选择 **Claude**，复制服务地址。
2. 在 Claude 中打开 **自定义**，进入 **连接器**，点 **添加自定义连接器**。
3. 粘贴地址，点 **添加**，再点 **连接**。
4. 浏览器会打开 Semestra 的授权页，没有登录时先登录。选择 **只读** 或 **读写**，点 **允许**。
5. 页面会回到 Claude，连接完成。Semestra 的窗口里也会显示“已连接”。

## 权限

- **只读**：Claude 可以查看你的课程、课表、成绩、待办和文件。
- **读写**：还可以添加和修改。删除数据需要另外在 **客户端权限** 中打开。

Claude 调用工具前会按它自己的设置请你批准。要换一种权限，断开后重新连接即可。

## 断开

在 Semestra 的 **客户端与 API 令牌** 中找到 Claude，点 **⋯**，选 **断开**，Claude 会立即失去访问权限。也可以在 Claude 的连接器列表里移除。连续 90 天没有使用的连接会自动断开。

## 说明

- 免费版可以添加 1 个自定义连接器。Team 和 Enterprise 由组织所有者在组织设置的 **连接器** 中添加，成员再各自连接。
- Claude 从它自己的服务器连接 Semestra，所以自部署的 Semestra 需要能从互联网通过 HTTPS 访问。在此之前，**新建连接** 里不会出现 **Claude**。只在局域网里使用时，可以改用 [Claude Code](./claude-code.mdx) 等本机客户端。
