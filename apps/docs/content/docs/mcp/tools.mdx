Generated from the server's registry (`packages/api-client/capabilities.json`, refreshed by
`pnpm gen:api`). What a given client sees is narrower: it depends on the token's access, the
**Delete data** permission for MCP clients and the plugins installed on the account.

## Skills

The client's AI loads them with the `load_skill` tool; they are also listed as MCP prompts.

<McpPrompts lang="en" />

## Tools

Tokens that can read course files also get `view_pages`, which returns the original pages of a
course file as images so the AI can check handwriting, figures and formulas. The client's model
needs to see images to use it.
