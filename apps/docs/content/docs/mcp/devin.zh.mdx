title: Devin Desktop (Windsurf)
description: 连接 Devin Desktop（原 Windsurf）。
---

## 在 Semestra 中连接

1. 在 Semestra 中打开设置 → **AI → API 与 MCP**，点 **新建连接**。
2. 选择 **Devin Desktop**，选 **只读** 或 **读写**，点 **创建令牌并继续**。
3. 下一步显示已填好令牌的配置，复制到其中注明的文件里。

令牌以 Devin Desktop 命名，只在该窗口中显示一次。要断开时，在 **客户端与 API 令牌** 中撤销它。

## 手动设置

先创建 API 令牌：设置 → **AI → API 与 MCP → 新建连接 → 其他客户端或脚本**。把下面的 `<token>` 换成它，示例地址换成 **MCP 服务** 中显示的地址。

在 `~/.config/devin/mcp_config.json`（Windows：`%APPDATA%\devin\mcp_config.json`）或项目里的 `.devin/mcp_config.json` 中加入 `semestra`：

```json
{
  "mcpServers": {
    "semestra": {
      "url": "https://semestra.example.com/mcp",
      "transport": "http",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

## 检查连接

重启 Devin Desktop，MCP 服务器列表中应出现 **semestra** 及其工具。

## 断开

删除该项并重启。 在 **客户端与 API 令牌** 中撤销对应令牌也会立即断开。
