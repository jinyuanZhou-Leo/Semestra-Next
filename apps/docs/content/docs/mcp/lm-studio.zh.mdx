title: LM Studio
description: 一键把 Semestra 安装到 LM Studio。
---

## 在 Semestra 中连接

1. 在 Semestra 中打开设置 → **AI → API 与 MCP**，点 **客户端与 API 令牌** 旁的 **新建连接**。
2. 选择 **LM Studio**，选 **只读** 或 **读写**，点 **创建令牌并继续**。
3. 点 **在 LM Studio 中打开**。LM Studio 会打开并请你确认安装。

令牌以 LM Studio 命名，只在该窗口中显示一次。要断开时，在 **客户端与 API 令牌** 中撤销它。

## 手动设置

先创建 API 令牌：设置 → **AI → API 与 MCP → 新建连接 → 其他客户端或脚本**。把下面的 `<token>` 换成它，示例地址换成 **MCP 服务** 中显示的地址。

在 LM Studio 右侧栏打开 **Program** 标签，选择 **Install → Edit mcp.json**（`~/.lmstudio/mcp.json`），加入：

```json
{
  "mcpServers": {
    "semestra": {
      "url": "https://semestra.example.com/mcp",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

需要 LM Studio 0.3.17 或更高版本，并使用支持工具调用的模型。

## 检查连接

在聊天中的集成列表里会出现 **semestra** 开关。打开后提问，LM Studio 会在每次调用工具前询问。

## 断开

从 `mcp.json` 删除该项。 在 **客户端与 API 令牌** 中撤销对应令牌也会立即断开。
