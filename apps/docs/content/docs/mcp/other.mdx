title: Other clients
description: Connect any MCP client that supports Streamable HTTP and custom headers.
---

Any client that can reach a remote MCP server over **Streamable HTTP** and send a custom header can use Semestra.

## Connect from Semestra

1. In Semestra, open Settings → **AI → API & MCP** and click **New connection**.
2. Choose **Other client or script**, enter a name, pick **Read only** or **Read and write**, and click **Create API token**.
3. Copy the address and the token into your client.

## What to enter

| Field | Value |
| --- | --- |
| Transport | Streamable HTTP (sometimes called "HTTP"; not SSE) |
| URL | The address under **MCP server**, e.g. `https://semestra.example.com/mcp` |
| Header | `Authorization: Bearer <token>` |

Most clients take a JSON entry like this one; the top-level key and the URL field name vary by client:

```json
{
  "mcpServers": {
    "semestra": {
      "url": "https://semestra.example.com/mcp",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

A client that can only start local (stdio) servers can connect through [`mcp-remote`](https://www.npmjs.com/package/mcp-remote), which passes the header on.

A client that signs in to MCP servers (OAuth), as [ChatGPT](./chatgpt.mdx) and [Claude](./claude.mdx) do, needs only the address: it opens Semestra's consent page, where you choose what it may do.
