ChatGPT 通过登录连接 Semestra，不需要 API 令牌。

## 连接

1. 在 Semestra 中打开设置里的 **AI**，进入 **API 与 MCP**，点 **新建连接**，选择 **ChatGPT**，复制服务地址。
2. 在 ChatGPT 中打开 **插件**，点 **＋**，选择 **添加自定义 MCP 服务器**。
3. 名称填 Semestra，粘贴地址。需要选择认证方式时选 OAuth。确认提示后创建。
4. 浏览器会打开 Semestra 的授权页，没有登录时先登录。选择 **只读** 或 **读写**，点 **允许**。
5. 页面会回到 ChatGPT，连接完成。Semestra 的窗口里也会显示“已连接”。

## 权限

- **只读**：ChatGPT 可以查看你的课程、课表、成绩、待办和文件。
- **读写**：还可以添加和修改。删除数据需要另外在 **客户端权限** 中打开。

ChatGPT 在执行修改前会在对话里请你确认。要换一种权限，断开后重新连接即可。

## 断开

在 Semestra 的 **客户端与 API 令牌** 中找到 ChatGPT，点 **⋯**，选 **断开**，ChatGPT 会立即失去访问权限。也可以在 ChatGPT 的插件里删除它。连续 90 天没有使用的连接会自动断开。

## 说明

- 能否添加自定义 MCP 服务器取决于你的 ChatGPT 套餐和工作区设置。
- ChatGPT 从它自己的服务器连接 Semestra，所以自部署的 Semestra 需要能从互联网通过 HTTPS 访问。在此之前，**新建连接** 里不会出现 **ChatGPT**。只在局域网里使用时，可以改用 [Codex](./codex.mdx) 等本机客户端。
