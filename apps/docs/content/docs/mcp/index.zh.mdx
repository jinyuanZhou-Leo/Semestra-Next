Semestra 提供一个 [MCP](https://modelcontextprotocol.io) 服务器，让应用之外的 AI 客户端可以读取你的课表、成绩和待办，并在你允许时修改它们。
它提供的操作和应用内助手 Sem 相同。

- **地址**：`<你的 Semestra 地址>/mcp`，例如 `https://semestra.example.com/mcp`。全局设置 → **AI → API 与 MCP → MCP 服务** 显示准确地址
- **传输方式**：Streamable HTTP（无状态，返回 JSON）
- **认证**：`Authorization: Bearer spat_…`，使用 API 令牌。不接受会话 cookie

## 连接客户端

最快的方式：全局设置 → **AI → API 与 MCP**，点 **客户端与 API 令牌** 旁的 **新建连接**，选择客户端和权限。Semestra 会为它创建一个以客户端命名的 API 令牌，并直接给出填好令牌的安装链接、命令或配置，不需要来回复制令牌。

| 客户端 | 方式 |
| --- | --- |
| [Cursor](./cursor.mdx)、[LM Studio](./lm-studio.mdx) | 一键打开 |
| [Claude Code](./claude-code.mdx)、[Gemini CLI](./gemini-cli.mdx) | 运行一条命令 |
| [VS Code](./vscode.mdx)、[Claude Desktop](./claude-desktop.mdx)、[Codex](./codex.mdx)、[Devin Desktop（原 Windsurf）](./devin.mdx) | 粘贴一段配置 |
| [Cline](./cline.mdx)、[Zed](./zed.mdx) | 手动设置 |
| [其他客户端](./other.mdx) | 填写地址和令牌 |

每个客户端的页面都写了手动设置的步骤、配置文件位置和检查连接的方法。

### API 令牌

手动设置时先创建令牌：全局设置 → **AI → API 与 MCP**，点 **新建连接**，选 **其他客户端或脚本**，填写名称并选择：

- **权限**：_只读_ 或 _读写_。
- **有效期**：永不过期、30 天、90 天或 365 天。

令牌只显示一次。每个客户端用一个单独的令牌，不用时在 **客户端与 API 令牌** 中撤销即可断开；删除账户会撤销全部令牌。

## 客户端能做什么

| 令牌 / 设置                                  | 读取类工具 | 修改类工具 | 删除类工具 |
| -------------------------------------------- | ---------- | ---------- | ---------- |
| 只读                                         | 可以       | 不可以     | 不可以     |
| 读写                                         | 可以       | 可以       | 不可以     |
| 读写，并打开**删除数据**                     | 可以       | 可以       | 可以       |

- **修改类工具会直接执行。** Sem 会显示确认卡片，而 MCP 调用依赖客户端自己的批准提示。
- **删除数据**默认关闭，在全局设置 → **AI → API 与 MCP** 的 **客户端权限** 一节里打开。它对令牌的所有调用生效，包括 REST 接口。
- 插件的工具只有在你的账户安装了该插件时才会出现。
- 通过 MCP 做的修改会立即显示在已打开的浏览器标签页里。

## Prompt 和资源

- **Prompt**：Sem 的每个技能都是一个 MCP prompt，即一套分步骤的流程，例如导入课表。只有当令牌能调用某个 prompt 用到的全部工具时，它才会列出。
- **资源**：`semestra://programs`（你的学业项目和学期）、`semestra://terms/{id}`（一个学期及其课程）和 `semestra://courses/{id}`（一门课程及其学期）。

## 注意事项

- 工具名是把能力名里的点换成 `__`，例如 `academics__course__create_many`。
- 时间使用学业项目所在时区，并带有偏移量。
- 如果你只有一个学业项目，需要 `program_id` 的工具可以不传它。
- 别人写的文本（Canvas 页面、文件内容）会作为数据返回，请按数据对待。
- 调用失败时返回 `{"error": {"code", "params", "hint"}}`；有 `hint` 时，它是一句说明下一步怎么做的英文。
- 添加条目的工具接受列表（`*_create_many`），只加一条也一样；排序只在应用里做。

完整列表见[工具与 prompt](./tools.mdx)。
