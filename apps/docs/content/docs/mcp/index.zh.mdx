Semestra 提供一个 [MCP](https://modelcontextprotocol.io) 服务器，让应用之外的 AI 客户端可以读取你的课表、成绩和待办，并在你允许时修改它们。
它提供的操作和应用内助手 Sem 相同。

- **地址**：`<你的 Semestra 地址>/mcp`，例如 `https://semestra.example.com/mcp`。全局设置 → **AI → API 与 MCP → MCP 服务** 显示准确地址
- **传输方式**：Streamable HTTP（无状态，返回 JSON）
- **认证**：ChatGPT 和 Claude 通过登录你的账户连接（OAuth）；其他客户端用 API 令牌，即 `Authorization: Bearer spat_…`。不接受会话 cookie

## 连接客户端

最快的方式：全局设置 → **AI → API 与 MCP**，点 **新建连接**，选择客户端。ChatGPT 和 Claude 只需要服务地址：在应用里添加后登录 Semestra，选择它能做什么。其他客户端先选择权限，Semestra 会为它创建一个以客户端命名的 API 令牌，并直接给出填好令牌的安装链接、命令或配置，不需要来回复制令牌。

| 客户端 | 方式 |
| --- | --- |
| [ChatGPT](./chatgpt.mdx)、[Claude](./claude.mdx) | 粘贴地址并登录（需要 HTTPS 地址） |
| [Cursor](./cursor.mdx)、[LM Studio](./lm-studio.mdx) | 一键打开 |
| [Claude Code](./claude-code.mdx)、[Gemini CLI](./gemini-cli.mdx) | 运行一条命令 |
| [VS Code](./vscode.mdx)、[Codex](./codex.mdx)、[Claude Desktop](./claude-desktop.mdx)（没有 HTTPS 时）、[Devin Desktop（原 Windsurf）](./devin.mdx) | 粘贴一段配置 |
| [Cline](./cline.mdx)、[Zed](./zed.mdx) | 手动设置 |
| [其他客户端](./other.mdx) | 填写地址和令牌 |

窗口最后一步会显示连接状态：客户端第一次连上后，“等待连接”会变成“已连接”。可以开着窗口去客户端里设置，回来就能看到结果。

每个客户端的页面都写了手动设置的步骤、配置文件位置和检查连接的方法。

### API 令牌

手动设置时先创建令牌：全局设置 → **AI → API 与 MCP**，点 **新建连接**，选 **其他客户端或脚本**，填写名称并选择：

- **权限**：_只读_ 或 _读写_。
- **有效期**：永不过期、30 天、90 天或 365 天。

令牌只显示一次。每个客户端用一个单独的令牌，不用时在 **客户端与 API 令牌** 中撤销即可断开；删除账户会撤销全部令牌。

## 客户端能做什么

| 令牌 / 设置                                  | 读取类工具 | 修改类工具 | 删除类工具 |
| -------------------------------------------- | ---------- | ---------- | ---------- |
| 只读                                         | 可以       | 不可以     | 不可以     |
| 读写                                         | 可以       | 可以       | 不可以     |
| 读写，并打开**删除数据**                     | 可以       | 可以       | 可以       |

- **修改类工具会直接执行。** Sem 会显示确认卡片，而 MCP 调用依赖客户端自己的批准提示。Semestra 也会要求客户端里的 AI 在删除数据、批量修改或提交导入之前先征得你的同意。
- **删除数据**默认关闭，在全局设置 → **AI → API 与 MCP** 的 **客户端权限** 一节里打开。它对所有连接生效，包括通过 API 令牌调用的 REST 接口。
- 插件的工具只有在你的账户安装了该插件时才会出现。
- 通过 MCP 做的修改会立即显示在已打开的浏览器标签页里。
- **最近更改** 列出客户端在 Semestra 中做过的修改，保留 90 天，已撤销的连接也在内，可以按连接筛选。读写连接的 **⋯ → 最近更改** 直接打开这个连接的修改。

## 技能

Sem 的技能，例如录入成绩、导入课程大纲、根据课程文件回答，在 MCP 客户端里同样可用。客户端里的 AI 会按你的请求自行加载合适的技能，按与 Sem 相同的步骤完成。只有当连接能使用某个技能需要的全部工具时，这个技能才会出现。

在列出 MCP prompt 的客户端里（Claude 的 **+** 菜单、Claude Code 的斜杠命令），也可以自己选用：每个技能都是一个 prompt。支持 MCP Skills 扩展的客户端会把它们识别为技能。

## 注意事项

- 工具名是把能力名里的点换成 `__`，例如 `academics__course__create_many`。
- 时间使用 Program 所在时区，并带有偏移量。
- 如果你只有一个 Program，需要 `program_id` 的工具可以不传它。
- 别人写的文本（Canvas 页面、文件内容）会作为数据返回，请按数据对待。
- 调用失败时返回 `{"error": {"code", "params", "hint"}}`；有 `hint` 时，它是一句说明下一步怎么做的英文。`common.internal` 表示服务器出错而不是参数不对，重试没有用；报告问题时附上 `params.request_id`。
- 添加条目的工具接受列表（`*_create_many`），只加一条也一样；排序只在应用里做。
