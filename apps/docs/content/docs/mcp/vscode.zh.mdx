title: VS Code
description: 在 VS Code 的 GitHub Copilot 代理模式中使用 Semestra。
---

## 在 Semestra 中连接

1. 在 Semestra 中打开设置 → **AI → API 与 MCP**，点 **MCP 服务** 旁的 **连接客户端**。
2. 选择 **VS Code**，选 **只读** 或 **读写**，点 **创建令牌并继续**。
3. 下一步显示已填好令牌的配置，复制到其中注明的文件里。

令牌以 VS Code 命名，只在该窗口中显示一次。要断开时，在 **API 令牌** 中撤销它。

## 手动设置

先创建 API 令牌：设置 → **AI → API 与 MCP → API 令牌 → 创建 API 令牌**。把下面的 `<token>` 换成它，示例地址换成 **MCP 服务** 中显示的地址。

1. 打开命令面板，运行 **MCP: Open User Configuration**（对所有工作区生效）。只想用于一个工作区时，改用 `.vscode/mcp.json`。
2. 在 `servers` 下加入 `semestra`：

```json
{
  "servers": {
    "semestra": {
      "type": "http",
      "url": "https://semestra.example.com/mcp",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

3. 点文件中服务器上方的 **Start**。

不想把令牌写进文件时，可以让 VS Code 询问一次并安全保存：

```json
{
  "inputs": [
    { "type": "promptString", "id": "semestra-token", "description": "Semestra API token", "password": true }
  ],
  "servers": {
    "semestra": {
      "type": "http",
      "url": "https://semestra.example.com/mcp",
      "headers": { "Authorization": "Bearer ${input:semestra-token}" }
    }
  }
}
```

## 检查连接

在 **Agent** 模式下打开聊天，点工具按钮，应列出 **semestra** 及其工具。**MCP: List Servers** 可查看状态和输出。

## 断开

删除该项，或运行 **MCP: List Servers** 选择 **Remove**。 在 **API 令牌** 中撤销对应令牌也会立即断开。
